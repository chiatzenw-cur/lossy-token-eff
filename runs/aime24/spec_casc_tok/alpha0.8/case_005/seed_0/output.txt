### 1.  Determining the prime \(p\)

The congruence

\[
n^{4}\equiv -1 \pmod{p^{2}}
\]

has a solution iff \(-1\) is a fourth power residue modulo \(p^{2}\).

For an odd prime \(p\) the multiplicative group  
\((\mathbb Z/p^{2}\mathbb Z)^{\times}\) is cyclic of order  

\[
\varphi(p^{2}) = p(p-1).
\]

Let \(g\) be a generator of this group.  
If \(-1\) is a fourth power, then \(-1=g^{k}\) for some \(k\) and  
\(k\) must be congruent to \(0\pmod{4}\) after dividing by \(\gcd(4,\varphi(p^{2}))\).

Write  

\[
N=p(p-1), \qquad d=\gcd(4,N).
\]

Because \(p\) is odd, \(p-1\) is even, so \(d\) is either \(2\) or \(4\).

*If \(p-1\equiv 2\pmod 4\) (\(p\equiv 3\pmod 4\)), then \(d=2\).  
The congruence \(4k\equiv N/2\pmod N\) would require \(2\mid N/2\), which is false because \(N/2\) is odd.  
Thus no solution exists.*

*If \(p-1\equiv 0\pmod 4\) (\(p\equiv 1\pmod 4\)), then \(d=4\).  
We need \(4k\equiv N/2\pmod N\).  
Since \(N/2=p(p-1)/2\) is divisible by \(4\) only when \(p-1\equiv 0\pmod 8\), we must have \(p-1\equiv 0\pmod 8\).*

Hence the smallest prime with \(p-1\equiv 0\pmod 8\) is \(p=17\).

--------------------------------------------------------------------
### 2.  Solving \(n^{4}\equiv-1\pmod{289}\)

With \(p=17\) we have \(p^{2}=289\).  
Working modulo \(17\) first:

\[
n^{4}\equiv-1\pmod{17}\quad\Longrightarrow\quad n^{4}\equiv 16\pmod{17}.
\]

The residues \(n\equiv 2\pmod{17}\) and \(n\equiv 15\pmod{17}\) satisfy this
because \(2^{4}=16\equiv-1\pmod{17}\).

Use Hensel’s lemma to lift each solution to a unique solution modulo \(289\).

---

**Lift of \(n\equiv 2\pmod{17}\).**  
Let \(n=2+17k\).  
\[
n^{4}=(2+17k)^{4}\equiv 16+544k\pmod{289}
          \equiv 16+255k\pmod{289},
\]
since \(544\equiv 255\pmod{289}\).  
Set \(16+255k\equiv-1\pmod{289}\Rightarrow255k\equiv272\pmod{289}\).  
Because \(255=17\cdot 15\), divide by \(17\):
\[
15k\equiv 16\pmod{17}\;\Longrightarrow\;k\equiv 9\pmod{17}.
\]
Hence \(n=2+17\cdot 9=155\).

---

**Lift of \(n\equiv 15\pmod{17}\).**  
Let \(n=15+17k\).  
\[
n^{4}\equiv 50+34k\pmod{289}\quad\Longrightarrow\quad
34k\equiv 238\pmod{289}\;( \text{since }-1\equiv 288).
\]
Because \(34=17\cdot 2\), dividing by \(17\) gives
\[
2k\equiv 14\pmod{17}\;\Longrightarrow\;k\equiv 7\pmod{17},
\]
so \(n=15+17\cdot 7=134\).

These two numbers give the two distinct solutions modulo \(289\) that are
congruent to \(2\) and \(15\) modulo \(17\), respectively.

### 3.  The other two solutions

The congruence \(x^{4}\equiv-1\pmod{289}\) has at most four solutions.
Because \(-1\) is a fourth power residue, there are exactly four.
If \(x\) is a solution, then \(x\zeta\) is also a solution for every
