* that sums to \(30\),
* whose unique mode is \(9\),
* and whose median is a positive integer that does **not** appear in the list.

---

### 1.  The list must have an even number of elements  

The median of a list with an odd number of elements is an element of the list.  
Since the median is required to be a positive integer **not** in the list, the list must contain an even number of elements.  
Let the number of elements be \(n\).

---

### 2.  Explore even \(n\)

#### \(n=2\)

Sum \(30\Rightarrow a+b=30\).  
The median would be \((a+b)/2=15\), which is not in the list only if \(a\neq b\).  
But then there is no mode, so condition fails.

#### \(n=4\)

We need a mode of \(9\).  
Let the number of 9’s be \(k\).

*If \(k=1\):* All other numbers must be distinct, but any such set of three numbers leads to a median that is not an integer (or the median would be an element of the list).  
*If \(k=3\):* The remaining number would be \(3\), yielding a list \([3,9,9,9]\) whose median is \(9\), which is in the list.  
*If \(k=4\):* \(4\times9=36>30\).

So \(k=2\).

Let the remaining two numbers be \(x\) and \(y\) (\(x\neq y\neq 9\)).  
We have

\[
x+y+9+9=30\quad\Longrightarrow\quad x+y=12.
\]

The numbers must be distinct and not equal to \(9\).  
The only pair of distinct positive integers that sums to \(12\) and is not \(9\) is \(x=5,\; y=7\).

The sorted list is \([5,7,9,9]\).

* **Mode:** \(9\) occurs twice; \(5\) and \(7\) each occur once → unique mode \(9\).  
* **Median:** The middle two entries are \(7\) and \(9\).  
  \[
  \text{Median}=\frac{7+9}{2}=8,
  \]
  which is an integer and **not** in the list.  
* **Sum:** \(5+7+9+9=30\).

Thus the list \([5,7,9,9]\) satisfies all conditions.

Higher even values of \(n\) (e.g., \(n=6,8,\dots\)) cannot work because the sum \(30\) makes it impossible to have the required mode and median simultaneously.

\[
5^2+7^2+9^2+9^2 = 25+49+81+81 = 236.
\]
