## a)  What does a path of length 16 look like?

A step can be either

* **R** (right) or *U* (up), each move taking one unit of the grid.

Because the total horizontal distance from \((0,0)\) to \((8,8)\) is \((8,0)+(0,8)\),

\[
\text{no path that stays on \(\mathcal{cells}\) can use a back‑track.}\\   
\Longrightarrow\,\text{every step must be either right or up, and
an entire path must contain exactly }8\text{ R beams and }8\text{ U beams.}
\]

Hence a path fulfilling the problem statement consists of
\(\boxed{16}\) steps, each step being either **R** or **U**.

---

## b)  Exactly 4 changes of direction

Let \(r\) be the number of different segments (continues of the same direction).
Every colour change separates two segments.  
If the path changes direction exactly **four** times,
there are
\(r-1 = 4\Rightarrow r=5\) segments.

Thus the pattern must be a sequence of five consecutive runs of equal
direction.  
Because the runs alternate, the pattern must be either

\[
RURUR\; \text{(3 runs of R and 3 U with one running twice), or
}URURU\; \text{(symmetrical)} .
\]

If we start with \(R\) the sequence of run lengths is

\[
(a,b,c,d,e) \qquad
\text{(R – U – R – U – H)}
\]

where \(a,c,e\) are lengths of the first, third and fourth horizontal runs,
and \(b,c\) are vertical runs.  
The restrictions

* \(a,c,e\ge1\) (each run must have at least one step),\;
* \(b,d\ge1\) (same rule for vertical runs),
* sum \(a+c+e = 8\) (total of \(R\)’s),\;
* sum \(b+d = 8\) (total of \(U\)’s).

Similarly if we start with \(U\) the pattern is \(U,R,U,R,U\) and the
same counting holds.

Thus the number of admissible paths is

\[
\text{#(ways of dividing 3 horizontal runs) }\times
\text{#(ways of choosing the two vertical runs)}.
\]

### 1. Counting the horizontal runs  
Number of positive integer solutions \((a,e,c)\) of  

\[
a+c+e=8
\]

is the stars‑and‑bars number

\[
\binom{8-1\,}{\,2\,}= \binom{21}?
\]

The well‑known denominator: \(C(8-1,3-1)=\binom{7}{2}=21\).

### 2. Numbers of vertical runs

Two positive integers \(b,d\) with  

\[
b+d=8
\]

have \(7\) possible solutions: \(b=1,2,\dots,7\).

Since the two patterns \(RURUR\) and \(URURU\) have the same number of
split‑ways, the count for each pattern is

\[
21\times 7=147.
\]

Adding the two patterns,

\[
\boxed{147+147=294}.
\]

## Final answer

There are \(\boxed{294}\) different 16‑step paths from the lower left corner
to the upper right of an \(8\times8\) grid that change direction exactly
