### 1.  The least prime \(p\)

For a prime \(p\) we need some integer \(n\) with  

\[
f(n)\equiv 0\pmod {p^{2}}.
\]

Firstly, \(f(n)\equiv 0\equiv -1 \pmod p\); hence \(-1\bmod p\) must be a fourth
power modulo \(p\).  
Thus \(-1\) is a quadratic residue, so \(p\equiv 1 \pmod 4\).

Check the primes \(\equiv1\pmod4\) in increasing order.

* \(p=5\):  \(x^4\pmod5\in\{0,1\}\Rightarrow -1\not\equiv 4\).
* \(p=13\):  fourth powers are only \(1,3,9\); again none equals \(12=-1\).
* \(p=17\):  \(2^4=16\equiv-1\pmod{17}\).

Thus \(p=17\) satisfies \(f(2)\equiv 0 \pmod{17}\).

Now ask whether the solution lifts to a solution modulo \(17^{2}\).
If \(x_{0}\) is a root modulo \(p\), Hensel’s lemma gives a root modulo \(p^{2}\)
provided \(f'(x_{0})\not\equiv 0\pmod p\).

For \(x_{0}=2\),

\[
f'(x)=4x^{3}\;\Longrightarrow\; f'(2)=4\cdot 8=32\not\equiv0\pmod{17}.
\]

Hence there is a unique integer \(n\) with  
\[
n\equiv 2\pmod{17},\qquad f(n)\equiv 0\pmod{17^{2}}.
\]

Therefore the least prime is  

\[
\boxed{ p=17 } .
\]
