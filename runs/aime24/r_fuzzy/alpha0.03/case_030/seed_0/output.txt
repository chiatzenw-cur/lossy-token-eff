### 1.  Conditions that force a maximal placement

* Every row that contains a chip must contain chips of **one colour only**  
  → all chips in a row must have the same colour.

* Every column that contains a chip must contain chips of **one colour only**  
  → all chips in a column must have the same colour.

From these two rules a chip can appear **only** in a cell where the
row‑colour equals the column‑colour.  
All such cells that are allowed must be occupied; otherwise a further
chip could be added there without breaking either rule.

Consequently the full set of chips on the board is determined by
\((w_R,w_C)\):
\[
\text{white chips used}=w_R\,w_C ,\qquad
\text{black chips used}=b_R\,b_C .
\]

--------------------------------------------------------------------

### 2.  Maximality (no empty rows or columns)

If a row is non‑empty, every column must also be non‑empty, because an
empty column could be given a chip that matches the row’s colour.
Hence **every row is non‑empty** and **every column is non‑empty**.
For this to hold we must have

* if a colour is present among the rows, it must also be present among the columns,
* if a colour is present among the columns, it must also be present among the rows.

Thus either

* no row is white and no column is white   \(\; (w_R,w_C)=(0,0)\);
* all rows and all columns are white      \((w_R,w_C)=(5,5)\); or
