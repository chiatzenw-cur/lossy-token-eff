### 1.  Maximality condition  

If there is a row \(i\) with no chip and a column \(j\) with a chip of
colour \(c_j\), then we could put a chip of colour \(c_j\) in
\((i,j)\).  This would still satisfy the two colouring conditions.

column.  
Consequently every row and every column must contain at least one chip.

The requirement “every row contains a chip” is equivalent to

\[
\forall i\;\exists j\quad r_i=c_j\quad\Longleftrightarrow\quad
\text{for each colour used in the rows there is a column of that colour}.
\]

Similarly, every column must contain a chip, so for each colour used in
the columns there is a row of that colour.

Hence

* either both colours are present in **both** the rows and the columns,
* or one colour is present in the rows and also in the columns
