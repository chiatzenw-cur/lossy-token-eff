A path from the lower‑left corner \((0,0)\) to the upper‑right corner \((8,8)\) on an \(8\times 8\) lattice must consist of  
\(8\) horizontal steps (Right = \(R\)) and \(8\) vertical steps (Up = \(U\)).  
The length of a path is \(2\times 8 = 16\) steps.

Denote a path by a sequence of \(R\)’s and \(U\)’s.
A *direction change* occurs whenever a step is followed by a step in the

We want exactly **four** direction changes.

---

**Step 2 –  How many blocks of equal directions?**

With \(k\) changes we have \(k+1\) blocks of consecutive equal directions.
Hence \(4\) changes ⇒ \(5\) blocks.

The blocks must alternate directions, so each block is either all \(R\)’s or all \(U\)’s.

Two possibilities for the first block:

1. Start with \(R\): pattern \(R,U,R,U,R\)  
   → 3 \(R\) runs and 2 \(U\) runs.

2. Start with \(U\): pattern \(U,R,U,R,U\)  
   → 3 \(U\) runs and 2 \(R\) runs.

---

**Step 3 –  Distribute the steps among the blocks**

*Case 1 – start with \(R\)*  
Let the three \(R\)-blocks have lengths \(r_1,r_2,r_3\) (\(r_i>0\)).  
Their total must be 8:

\[
r_1+r_2+r_3 = 8 \qquad (r_i\ge 1)
\]

The number of ways to choose \(r_1,r_2,r_3\) is the number of compositions of
\(8\) into \(3\) positive parts:

\[
\binom{8-1}{3-1}=\binom{7}{2}=21 .
\]

Similarly, the two \(U\)-blocks have lengths \(u_1,u_2\) with

\[
u_1+u_2 = 8,\qquad u_1,u_2\ge 1
\]

giving

\[
\binom{8-1}{2-1}=\binom{7}{1}=7
\]

possible choices.

Thus the number of paths beginning with \(R\) is \(21\cdot 7=147\).

*Case 2 – start with \(U\)*  
Now the paths have 3 \(U\)-blocks and 2 \(R\)-blocks.  
The count of ways to distribute the steps is the same way as above:

\[
( \text{U‑blocks}) : \binom{7}{2}=21,\qquad
( \text{R‑blocks}) : \binom{7}{1}=7 .
\]
