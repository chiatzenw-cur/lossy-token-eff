### Counting the admissible \(k\)

Let \(B=b-1\).  
For \(b-1\) to divide \(k(k-1)\) we need that any prime factor of \(B\) divides
either \(k\) or \(k-1\), because \(\gcd(k,k-1)=1\).  
Therefore for each prime \(p\mid B\) we have \(k\equiv 0\pmod p\) or \(k\equiv 1\pmod p\).

Therefore the number of solutions modulo \(B\) is

\[
2^{\omega(B)}\quad\text{with } \omega(B)=\text{the number of distinct primes dividing }B .
\]

All \(k\) with \(B\mid k(k-1)\) lie in \([1,B]\).  
The number of \(k>1\) (since \(k=1\) we would get \(a=0\) and the number would
not be two‑digit) is precisely \(2^{\omega(B)}-1\).

### Counting \(b\)-eautiful numbers

For any base \(b\ge 2\) the number of \(b\)-eautiful integers is

\[
N(b)\;=\;2^{\omega(B)}-1 ,\qquad B=b-1 .
\]

We need \(N(b)>10\); i.e.  

\[
2^{\omega(b-1)}-1>10 \Longleftrightarrow
2^{\omega(b-1)}\ge 12\Longrightarrow \omega(b-1)\ge 4 .
\]

Hence \(b-1\) must have at least four distinct prime factors.

### Minimal \(b\)
