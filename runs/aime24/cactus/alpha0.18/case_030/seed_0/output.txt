### 2.  What colour patterns can exist?

Because a row’s kinase dictates the color of every chip it carries and a column’s tone dictates the color of every chip it carries, a cell that we occupy **immediately fixes** a colour for both its row  and its column.

So consider:  
1. If the board contains a row with a black chip and a column with a white chip, then at their intersection is a cell that is black *and* white – impossible.  
2. Therefore **all rows that contain a chip must all share the same colour** and likewise all columns that contain a chip must share that colour.

This clearly forces every chip on the board to be **monochrome**: either all black *or* all white.

### 3.  Why the board has to be completely filled

If there is any empty cell left on the board, we can add technology to it without violating layout or pixel-unity limits – the cell’s empty row and empty column each contain no other chips, so we can place a chip of the same colour as a neighbouring row (or column) and still satisfy adjacency rules.  
Consequently the board can be enlarged until **every cell has a chip**.

Thus the board in a maximal configuration is a **full \(5\times5\) board of one colour**.
