\[
N(n)=n^{4}+1 .
\]

If a prime \(p\) divides \(N(n)\) with multiplicity \(1\) we have a
root of the polynomial  

\[
f(x)=x^{4}+1\equiv 0\pmod{p}.     \tag{P1}
\]

The condition in the problem is that we need \(p^{2}\mid N(n)\), i.e. a
root of (P1) that lifts to a root modulo \(p^{2}\).  
For odd primes \(p\) we can use Hensel’s lemma:

*If \(f(r)\equiv 0 \pmod{p}\) and \(f'(r)\not\equiv 0\pmod{p}\),  
the congruence \(f(x)\equiv0\pmod {p^{2}}\) has a unique root
\(x\equiv r\pmod{p^{2}}\).*

Here \(f'(x)=4x^{3}\) and for a prime \(p\neq 2\) the derivative is never
zero modulo \(p\).  
Thus for every odd prime \(p\) for which congruence
\(x^{4}\equiv-1\pmod{p}\) is solvable, there is a solution modulo \(p^{2}\).

--------------------------------------------------------------------

### 1.  The smallest prime \(p\) with a \(p^{2}\)–divisor of \(N(n)\)

We test successive odd primes.  
For \(p\le 13\) we find for every integer \(x\) modulo \(p\) that

\[
x^{4}\equiv0,1,2,3,4,5,6,9\pmod{p},
\]

not \(p-1\).  
Thus \(x^{4}\equiv-1\pmod{p}\) has no solution for \(p=3,5,7,11,13\).

Then
\(p\!=\!17\) gives

\[
2^{4}=16\equiv-1\pmod{17},
\]

so \(17\) allows \(x^{4}\equiv-1\pmod{17}\).
Hence \(p=17\) is the least prime that satisfies the requirement.

--------------------------------------------------------------------

### 2.  Finding the smallest \(m\) with \(17^{2}\mid(m^{4}+1)\)

Let \(p\!=\!17\).  Reduce to
\[r \equiv m  \pmod {17}\quad\text{with}\quad r^{4}\equiv-1 \pmod{17}.\]
The ring \(\mathbb Z/17\mathbb Z\) has four fourth‑roots of \(-1\):

\[
78\;(\text{new note})\quad r\in\{2,8,9,15\}.
\]

Write \(m=r+17k\) (\(0\le k<17\)).  
Track \(m^{4}+1\) modulo \(289\):

\[
m^{4}+1\;=\;(r^{4}+1)+4 r^{3}\cdot17k   \pmod{289}
          =17\!\bigl( a+4 r^{3}k \bigr)\!\pmod{289},
\]
with  

\[
a=\frac{r^{4}+1}{17}\;  
   (\text{an integer}).
\]

Therefore,
\(289\mid m^{4}+1\) iff  

\[
a+4 r^{3}k \equiv 0\pmod{17}.
\]
