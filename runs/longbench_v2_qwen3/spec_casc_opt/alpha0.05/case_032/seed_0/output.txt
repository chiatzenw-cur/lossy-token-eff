When you are in the **Statistical Editor mode** on the **fx-911EX** calculator, pressing keys **AC**, **SHIFT**, and **AC** one by one triggers a sequence of operations.
  
### Step-by-Step.
1. **AC (Clear Entry)**: This key clears the current entry or active data cell in the editor.
2. **SHIFT + AC (All Clear or Clear All Data)**: In the **Statistical Editor type** (e.g., for inputting data.
3. **Final.
4. **After** clearing the data, the calculator.
5. **Eventually**, if you do not continue editing or entering data, the calculator.
6. **Thus**, the final result.
   - Option **D**: *Finish the data input and make the screen ready for calculation, then exit the statistical editor.*.
