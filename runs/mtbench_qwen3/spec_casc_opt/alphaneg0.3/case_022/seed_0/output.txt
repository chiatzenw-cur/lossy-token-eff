Here's a well-structured C++ program that calculates the **n-th Fibonacci number using recursion**, based on the standard definition where:

- `F(0) = 0`
- `F(1) = 1`
- `F(n) = F(n-1) + F(n-2)` for `n = 2, 3, 4, ...`

This program includes basic input validation to ensure the user enters a non-negative integer.

---

### ✅ C++ Recursive Fibonacci Number Finder

```cpp
#include <iostream>
using namespace std;

// Function to compute the nth Fibonacci number recursively
int fibonacci(int n) {
    // Base cases
    if (n <= 1) {
        return n;
    }
    // Recursive case: F(n) = F(n-1) + F(n-2)
    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main() {
    int n;

    cout << "Enter the position (n): ";
    cin >> n;

    // Input validation
    if (n < 0) {
        cout << "Error: Fibonacci numbers are defined for non-negative integers only." << endl;
        return 1;
    }

    // Output the result
    cout << "The " << n << "th Fibonacci number is: " << fibonacci(n) << endl;

    return 0;
}
```

---

### 📌 Explanation

- **Recursive Function (`fibonacci`)**: This function is the core of the solution. It computes the nth Fibonacci number by recursively calculating the previous two values.
- **Base Cases**: When `n == 0` or `n == 1`, the function simply returns those values, as these are the definitions from the starting point of the sequence.
- **Recursive Case**: For `n >= 2`, it follows the Fibonacci property `fib(n) = fib(n-1) + fib(n-2)`.
- **Input validation**: The code checks if the input is a non-negative integer. If not, it prints an error and exits.
