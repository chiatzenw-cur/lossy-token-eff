### 📄 Full HTML Code:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Random Joke Generator</title>
    <style>
        body {
            font-family: Arial, sans-serif;
            text-align: center;
            padding: 50px;
        }
        button {
            padding: 10px 20px;
            font-size: 16px;
            cursor: pointer;
            margin-top: 20px;
        }
        #jokeText {
            margin-top: 20px;
            font-size: 18px;
            color: #333;
        }
    </style>
</head>
<body>
    <h1>Random Joke Generator</h1>
    <button onclick="showRandomJoke()">Tell me a joke</button>
    <p id="jokeText"></p>

    <script>
        function showRandomJoke() {
            const jokes = [
                "Why don't scientists trust atoms? Because they make up everything!",
                "What do you call fake spaghetti? An impasta!",
                "Why did the scarecrow win an award? Because he was outstanding in his field!",
                "What do you get when you cross a snowman and a vampire? Frostbite!"
            ];

            const randomIndex = Math.floor(Math.random() * jokes.length);
            document.getElementById('jokeText').textContent = jokes[randomIndex];
        }
    </script>
</body>
</html>
```

---

### 🔍 How It Works:
- The `<script>` tag is placed in the `<head>` section, so the `showRandomJoke()` function is available **before** the page is fully rendered.
- The **button** has an `onclick` handler that calls the function.
- The `<p>` element with `id="jokeText"` holds the joke, and its content is updated dynamically via `textContent`.

### 🧠 Notes:
- This version does **not** use `addEventListener` for cleanliness and simplicity, but the `onclick` attribute is still safe and effective for this use case.
