---

### ✅ **HTML + JavaScript Code**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Random Joke Generator</title>
    <style>
        body {
            font-family: Arial, sans-serif;
            text-align: center;
            padding: 50px;
        }
        button {
            padding: 10px 20px;
            font-size: 16px;
            cursor: pointer;
        }
        #jokeDisplay {
            margin-top: 30px;
            font-size: 18px;
            color: #333;
        }
    </style>
</head>
<body>

    <h1>Random Joke Generator</h1>
    <button onclick="showRandomJoke()">Tell me a joke</button>
    <p id="jokeDisplay"></p>

    <script>
        const jokes = [
            "Why don't scientists trust atoms? Because they make up everything.",
            "What do you call fake spaghetti? An impasta.",
            "Why did the scarecrow win an award? Because he was outstanding in his field.",
            "What do you get when you cross a snowman and a vampire? Frostbite."
        ];

        function showRandomJoke() {
            const randomIndex = Math.floor(Math.random() * jokes.length);
            const jokeElement = document.getElementById("jokeDisplay");
            jokeElement.textContent = jokes[randomIndex];
        }
    </script>

</body>
</html>
```

### 🔧 **Features**

- ** draggable**: **No drag-and-drop functionality**, just a simple click operation.
- ** Reusability**: The list of jokes is stored in a constant array for easy future modification.
- ** Responsive**: Simple styling ensures the layout is centered and uses a readable font.
- ** **Accessibility**: The `onclick` attribute is used directly on the button for clear function for users.

---

### 🧠 **How It Works**

1. **HTML Elements**:
   - A `<h1>` heading, a `<button>`, and a `<p>` paragraph to reference the joke display.
   - The button’s `onclick` attribute triggers the `showRandomJoke()` function when clicked.

2. **JavaScript**:
   - An array `jokes` stores the four jokes.
   - The `showRandomJoke()` function:
     - Randomly selects a joke number via `Math.floor(Math.random() * jokes.length)`.
     - Retrieves the `<p>` element using `document.getElementById("jokeDisplay")`.
     - Updates the inner text of the `<p>` with the selected joke.
