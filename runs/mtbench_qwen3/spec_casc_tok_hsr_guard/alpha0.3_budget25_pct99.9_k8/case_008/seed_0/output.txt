To find the majority element in a given array using the **Boyer-Moore Voting Algorithm**, we need to identify the element that appears more than `n/2` times (where `n` is the length of the array). The algorithm works efficiently in **linear time** and **constant space**, making it optimal for large arrays.

---

### 🔍 **Understanding the Algorithm**

The Boyer-Moore Voting Algorithm maintains a count and a current candidate for the majority element. The logic is as follows:

1. **Initialize** a candidate element and a count to 0.
2. **Iterate** over each element in the array:
   - If the count is 0, set the current element as the candidate.
   - If the current element is the same as the candidate, increment the count.
   - If it’s different, decrement the count.
3. By the end of the iteration, the candidate will be the majority element **if one exists**.

This works because a majority element will outvote all other elements, so even if other elements "cancel" votes, the majority will remain as the final candidate.

---

### ✅ **Assumptions**

The problem assumes that **a majority element exists** in the array. Therefore, we don't need to validate the result, only determine the candidate. However, if there's no majority element, this algorithm may still return a candidate that is not the majority. In practice, for such cases, we would need to verify through a second pass.

---

### 📌 Python Implementation

```python
def majority_element(nums):
    candidate = None
    count = 0

    for num in nums:
        if count == 0:
            candidate = num
        if num == candidate:
            count += 1
        else:
            count -= 1

    return candidate
```

---

### 🧪 **Example Usage**

```python
# Example 1
nums = [2, 2, 1, 1, 2]
print(majority_element(nums))  # Output: 2

# Example 2
nums = [1, 1, 2, 2, 2]
print(majority_element(nums))  # Output: 2

# Example 3
nums = [1, 2, 3, 4, 5, 6, 1]
print(majority_element(nums))  # Output: 1
```

---

### ✅ **Time & Space Complexity**

- **Time**: **O(n)** — Only one linear pass through the array.
- **Space**: **O(1)** — Only a few variables are used, independent of the input size.

This makes the Boyer-Moore algorithm a highly efficient choice for this problem.
