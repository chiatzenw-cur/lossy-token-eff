To find the **majority element** in an array — defined as the element that appears **more than half the time** — using the **Boyer-Moore Voting Algorithm**, we can implement an efficient solution that operates in **O(n)** time and **O(1)** space.

---

### ✅ Algorithm Overview

The **Boyer-Moore Voting Algorithm** works by keeping track of a **candidate** and a **count**:
- Initialize the candidate to `None` and the count to `0`.
- For each element in the array:
  - If the count is `0`, assign the current element as the new candidate.
  - If the current element is the same as the candidate, increment the count.
  - Otherwise, decrement the count.

This algorithm guarantees that **if** a majority element exists (i.e., it appears more than `n//2` times), the candidate at the end of the iteration will be that majority element. 

> Note: **If no majority element exists**, the algorithm may return a candidate that is **not** the majority. But given the context of the problem, it is generally assumed that a majority element **does exist**.

So, we can directly return the candidate without performing a second pass to verify it.

---

### ✅ Code Implementation

```python
def majority_element(nums):
    candidate = None
    count = 0

    for num in nums:
        if count == 0:
            candidate = num
        count += 1 if num == candidate else -1

    return candidate
```

---

### 🔍 Example

#### Input:
```python
nums = [2, 2, 1, 1, 2]
```

#### Execution:
- Initially: `candidate = None`, `count = 0`
- `2`: count is 0 → set `candidate = 2`, `count = 1`
- `2`: same as candidate → `count = 2`
- `1`: not same → `count = 1`
- `1`: not same → `count = 0`
- `2`: count is 0 → set `candidate = 2`, `count = 1`

#### Output:
```python
2
```

This is correct since `2` appears 3 times (more than half of 5).

---

### 📌 Time and Space Complexity

- **Time Complexity**: **O(n)** — each element is processed once.
- **Space Complexity**: **O(1)** — only a fixed number of variables are used.

---

### 💡 Notes

- The Boyer-Moore Voting Algorithm **does not require a second verification** if we are **guaranteed** that a majority element exists.
- If the array does **not** have a majority element, the returned candidate may not be correct. However, in the context of this problem, we assume that such an element **exists**.
