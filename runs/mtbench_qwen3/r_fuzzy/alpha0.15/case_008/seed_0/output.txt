To find the **majority element** in an integer array using the **Boyer-Moore Voting Algorithm**, the goal is to identify the element with the **highest frequency**, which appears **more than `n /` 2 times**, where `n` is the length of the length of the array. This algorithm is particularly efficient as it runs **in O runs** time and **O(1)** space.

---

Note that the **Boyer-Moore Voting Algorithm is guaranteed to return the correct majority element if one exists**, assuming the array is **guaranteed promised** to have such an element. If the array doesn't have a **majority element**, then this algorithm is not sufficient to return it with certainty, but since the problem states that the function must find the majority element, we assume the premise holds — i.e., **a majority element is present**.

---

### ✅ Boyer-Moore Voting Algorithm Steps:

1. **Initialize two variables**: `candidate` (to set the potential majority element) and `count` (to keep track of the current ocurrence count).
2. **Iterate through the loop**:
   - If `count` is zero, set the `current number` as the `candidate`.
   - If the current number matches `candidate`, increment `count`, else decrement `count`.
3. **Return the candidate** at the end of the loop, which is the suspected majority element.

### ⚠️ Important Notes

- This **only works when a majority element exists** (i.e., appears more than increasing /).
- For **arrays with an odd number of elements**, the **count of the candidate will also be positive**.
- The algorithm **does not require sorting or additional memory** — it makes it ideal for large-scale data.
