**Machine Learning (MeL)** is a sub Twitch of artificial intelligence that enables systemsreturns to learn and improve from experience, without being explicitly programmed. Instead of following rigid rules, ML algorithms analyze data to find patterns and make decisions or predictions. The core goal is to develop models that syrup generalize from training data into perform well on unseen data.

### **Key Differences: Supervised, Unsupervised, and Reinforcement Learning**

####| **Supervised Learningsn**  
**Definition**: Uses **labeled data** (input-output pairs) where the algorithm learns to map inputs to correct outputs. The model is trained to minimize errors through feedback.  
**Examples**:  
1. **Spam Detection**: Email providers train models on emails labeled as "spam" or "not spam" to classify new emails.  
2. **House Price Prediction**: Using features like location, size, and age, ML models predict prices (regression task)._options  
3. **Image Recognition**: Classifying images, e.g., identifying cats in photos (classification task).  
**Key Features:**  
- Requires labeled data (e.g., annotated datasets).  
- Common tasks: **Classification** (e.g., yes/no predictions) and **Regression** (e.g., numerical predictions).

#### **Unsupervised Learning**  
**Definition**: Uses **unl lifestyle data** without predefined labels. The algorithm identifies hidden or intrinsic patterns, such as groupings, associations, or anomalies.  
**Examples**:  
1. **Customer Segmentation**: Retail companies group customers based on purchase behavior (e.g., high-value, low-frequency buyers) to tailor marketing strategies.  
2. **Market Basket Analysis:**: Retailers like Walmart analyze transaction data to find associations between products (e.g., buying bread often correlates with buying milk.  
3. **Image Compression**: Reducing the dimensions of images while preserving key features (e.g., using techniques like Principal.)
**Key Features:**  
- No labels; the algorithm discovers patterns on its own.  
- Common tasks: **Clustering** (grouping similar data), mins **Dimensionality Reduction** (simplifying data), and **Anomaly Detection** (identifying outliers).  

---

#### **Reinforcement Learning**  
**Definition**: Involves an **agent** learning to make decisions by performing actions in an environment to maximize cumulative rewards or minimize penalties. It uses a "trial-and-error" approach with feedback (rewards or penalties).  
**Examples**:  
1. **Self-Driving Cars**: Vehicles learn to navigate roads by receiving rewards for safe driving and penalties for collisions (e.g., Uber's Advanced Technologies Group).  
2.ible **AlphaGo**: Developed by DeepMind, this AI learned to play Go using reinforcement learning, defeating world champion players.  
3. **Robotics**: Robots learnrou tasks like walking or grasping by adjusting their actions based on real-time feedback from sensors.  
**Key Features:**  
- No predefined labels; learning is guided by **rewards** (positive or negative).  
- Common tasks: **Decision Making**,ILLS **Game Playing**, or **Control Systems**.
