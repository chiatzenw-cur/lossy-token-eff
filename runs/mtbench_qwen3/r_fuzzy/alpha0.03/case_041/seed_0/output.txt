Here's a simple website implemented in HTML that displays a random joke from a predefined list when a user clicks a button. This code includes a minimal structure, clean styling, and the required interactivity via embedded JavaScript.

---

### ✅ Full HTML Code: Random Joke Generator

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Random Joke Generator</title>
    <style>
        body {
            font-family: Arial, sans-serif;
            background-color: #f2f2f2;
            text-align: center;
            padding-top: 50px;
        }

        h1 {
            color: #333;
        }

        button {
            background-color: #008CBA;
            color: white;
            border: none;
            padding: 12px 24px;
            font-size: 18px;
            border-radius: 5px;
            cursor: pointer;
            margin-top: 20px;
        }

        button:hover {
            background-color: #005f7f;
        }

        #jokeDisplay {
            margin-top: 30px;
            font-size: 18px;
            color: #555;
            max-width: 600px;
            margin-left: auto;
            margin-right: auto;
        }
    </style>
</head>
<body>
    <h1>Random Joke Generator</h1>
    <button onclick="showRandomJoke()">Tell me a joke!</button>
    <div id="jokeDisplay">Click the button to see a joke!</div>

    <script>
        const jokes = [
            "Why don't scientists trust atoms? Because they make up everything.",
            "Why did the scarecrow win an award? Because he was outstanding in his field.",
            "What do you call a fake noodle? An impasta.",
            "Why did the bicycle fall over? Because it was two-tired."
        ];

        function showRandomJoke() {
            const index = Math.floor(Math.random() * jokes.length);
            document.getElementById('jokeDisplay').textContent = jokes[index];
        }
    </script>
</body>
</html>
```

---

### 📌 Features

- **Responsive Layout:** The design is centered and uses basic CSS for visual appeal.
- **Interactive Button:** Clicking the button triggers a JavaScript function.
- **Random Selection:** A JavaScript array holds four jokes, and a random one is selected and displayed each time the button is pressed.
- **Clear Output:** A `div` with the `id` `jokeDisplay` is used to show the joke. Initially, it displays a placeholder message.
- **No External Files:** Fully self-contained, with no dependencies.

---

### 🔄 How It Works

1. On page load, the `jokeDisplay` shows a prompt message: *"Click the button to see a joke!"*.
2. When the button is clicked:
   - A random number is generated using `Math.random()` and `Math.floor()` to ensure it is within the bounds of the array.
   - The joke at the selected index is fetched from the array and assigned to the `textContent` of the `jokeDisplay` element.
3. The user sees the selected joke immediately after clicking.
