### ✅ Program Overview

- **Recursive Case**: For `n >= 2`, the Fibonacci number is the sum of the two preceding numbers:

> ⚠️ Note: The recursive approach is **not** efficient for large values of `n` (due to repeated calculations), but it's suitable for the purpose of demonstrating recursion.

---

### 📄 Complete C++ Code

```cpp
#include <iostream>
using namespace std;

// Recursive function to compute the nth Fibonacci number
int fib(int n) {
    if (n <= 1) {
        return n;
    } else {
        return fib(n - 1 + fib(n - 2));
    }
}

int main() {
    int n;
    cout << "Enter the position n: ";
    cin >> n;

    // Basic input validation
    if (n < 0) {
        cout << "Error: n should be non-negative." << endl;
        return 1;
    }

    cout << "The " << n << "th Fibonacci number is: " << fib(n) << endl;
    return 0;
}
```
