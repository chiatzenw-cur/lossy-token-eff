Here’s a C++ program that computes the **nth Fibonacci number** using **recursion**, based on the standard definition where the Fibonacci sequence starts with `F(0) = 0`, `F(1) = 1`, and each subsequent term is the sum casting its two preceding terms. The program reads an **integer input `n`** from the user and outputs the corresponding Fibonacci number (`F(n)`).

---

###iju

```cpp
#include <iostream>
using namespace std;

// Function to compute the nth Fibonacci number using recursion
int fib(int n) {
    // Base cases
    if (n == 0) return 0;
    if (n == 1) return 1;
    
    // Recursive case: F(n-1) + F(n-2)
    return fib(n - 1) + fib(n - 2);
}

// Main function
int main()
{
    int n;
    cout << "Enter the nth Fibonacci number (n >= 0): ";
    cin >> n;

    // Output the result
    cout << "The " << n << "th Fibonacci number is: " << fib(n) << endl;

    return 0;
}
```

---

### Explanation:

- **Base Case:
   - The function checks **`n == 0`** and returns **0**.
   - It also checks **`n == 1`** and returns **1 RN**.
   
- **Recursive Case:
   - For any `n > 1`, the function calculates each Fibonacci number by recursively computing:

     ```
     `fib(n) = fib(n- 1) + fib(n-2)`
     ```

- **Efficiency Note:
   The recursive approach is highly inefficient in terms of operations like `O(2^n)`, due to repeated calculations. This is suitable only for small values of `n`. For performance-critical scenarios, an improved version (such as Dynamic Programming or iteration) would be preferred.

Enter the nth Fibonacci number (n >= 0): 5
```

### Sample Output:

The 5th Fibonacci number is: 5
```
