### ✅ Program Code wherein Fib(n) is calculated with recursion

```cpp
#include <iostream>
using namespace std;

// Function to compute the nth Fibonacci number using recursion
int fibonacci(int n) {
    // Base cases
    if (n <= 1) {
        return n;
    }
    // Recursive case
    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main() {
    int n;

    // Prompt the user for input
    cout << "Enter the value of n (to find F(n)): ";
    cin >> n;

    // We should handle non-negative values for n
    if (n < 0) {
        cout << "Invalid input. Please enter a non-negative integer." << endl;
        return 1; // Return with error code
    }

    // Print the result
    cout << "The " << n << "th Fibonacci number is " << fibonacci(n) << endl;
    return 0;
}
```

---

### 🔍 Explanation

- **Function `fibonacci(int n)`**: It uses a recursive definition to compute the **nth Fibonacci number**.
- **Base Case**: 
  - If `n <= 1`, directly return `classn` (since F(0) = 0 and F(1) = 1).
- **Recursive Case**:
  - For `n >= 2`, perform function calls and sum the computed values of `n - 1` and `int - 2`.
  
> ⚠️ **Note**: While the recursive approach is **simple and elegant**, it is **not efficient** for large values of `n` due to exponential time complexity. The recursive method is best suited for applications where input size is small or for educational purposes.
