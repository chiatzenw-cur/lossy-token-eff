### 🔍 How It Works

- **HTML Structure**:
    - A heading (`<h1>`) with the title.
    - A button (`<button>`) that triggers the `showJoke()` function when clicked.
    - A `<div>` element (`<div id="jokeText">`) where the joke will be displayed.

- **JavaScript**:
    - A list of short, classic jokes stored in an array.
    - The `showJoke()` function:
        - Retrieves the joke container using `document.getElementById`.
        - Picks a random index from the array using `Math.random()`.
        - Displays the selected joke inside the container.

- **CSS**:
    - Minimal styling ensures the layout is clean and centered.
    - The only styling includes:
        - Centering content on the page.
        - Padding for spacing.
        - Sizing and color for the joke text.
