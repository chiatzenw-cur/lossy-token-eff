        function showRandomJoke() {

                "Why don't scientists trust atoms? Because they make up everything!",

                "Why did the math book look sad? Because it had too many problems."
            ];
            const randomIndex = Math.floor(Math.random() * jokes.length);

### 💡 How It Works

- The `<script>` block runs after the `<div id="jokeDisplay">` element, relying on the DOM being fully loaded.
- The `showRandomJoke()` function executes when the button is clicked, using `Math.random()` to randomly select an index from the `jokes` array.
- The joke is then read from the array and displayed in the `<div>` using `innerHTML`.
