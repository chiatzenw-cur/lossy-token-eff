Here's a C++ program that computes the nth Fibonacci number using recursion. This implementation follows the standard definition of the Fibonacci sequence, where:

- The 0th Fibonacci number is `0`.
- The 1st Fibonacci number is `1`.
- For $ n \geq 2 $, the nth Fibonacci number is the sum of the (n-1)th and (n-2)th Fibonacci numbers.

---

### ✅ C++ Program: Recursive Fibonacci Number

```cpp
#include <iostream>
using namespace std;

// Function to compute nth Fibonacci number using recursion
int fibonacci(int n) {
    if (n < 0) {
        // Handle invalid input: negative n
        cout << "Error: n must be a non-negative integer." << endl;
        return -1;  // indicates an error
    }
    if (n == 0) {
        return 0;
    } else if (n == 1) {
        return 1;
    } else {
        return fibonacci(n - 1) + fibonacci(n - 2);
    }
}

int main() {
    int n;
    
    // Prompt user for input
    cout << "Enter the position n to find the nth Fibonacci number: ";
    cin >> n;

    // Compute and display the result
    int result = fibonacci(n);
    if (result != -1) {
        cout << "The " << n << "th Fibonacci number is: " << result << endl;
    }

    return 0;
}
```

---

### 🔍 Explanation

- **Recursive Function (`fibonacci(int n)`)**: This function uses recursion to calculate the Fibonacci number.
  - **Base Cases**:
    - If $ n = 0 $, return `0`.
    - If $ n = 1 $, return `1`.
  - **Recursive Case**:
    - If $ n > 1 $, compute the Fibonacci of $ n-1 $ and $ n-2 $, then sum them.
  - It also includes an **input validation** check to handle negative values of `n`, which would otherwise cause infinite recursion and program crash.

- **Main Function**:
  - Prompts the user to enter a value for `n`.
  - Calls the `fibonacci()` function.
  - Displays the result only if it is valid (i.e., not -1 due to a negative input).

While this implementation correctly uses recursion to find the Fibonacci number, it has **exponential time complexity** due to repeated calculations. For large values of `n`, this will be very slow.
