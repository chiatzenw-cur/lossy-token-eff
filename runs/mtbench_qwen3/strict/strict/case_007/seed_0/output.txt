Here's a well-structured Python program that:

1. Prompts the user to enter a directory path.
2. Reads all `.txt` files located in that directory.
3. Processes each file by:
   - Converting all text to lowercase.
   - Extracting words using a regex pattern that captures only sequences of alphanumeric characters.
4. Counts word frequencies using `collections.Counter`.
5. Displays the top 5 most frequently occurring words across all files.

---

### ✅ Final Python Code

```python
import os
import re
from collections import Counter

def main():
    # Prompt the user for the directory path
    directory = input("Enter the directory path: ")

    # Initialize a counter for word frequencies
    word_counts = Counter()

    # Process all .txt files in the specified directory
    for filename in os.listdir(directory):
        file_path = os.path.join(directory, filename)

        # Ensure the item is a file and ends with .txt
        if os.path.isfile(file_path) and filename.endswith('.txt'):
            try:
                with open(file_path, 'r', encoding='utf-8') as file:
                    text = file.read()
                    # Extract words: sequences of alphanumeric characters (letters and numbers)
                    words = re.findall(r'\b\w+\b', text.lower())
                    word_counts.update(words)
            except Exception as e:
                print(f"Error reading file '{file_path}': {e}")

    # Display the top 5 most frequent words
    print("\nTop 5 most frequent words:")
    top_words = word_counts.most_common(5)
    for word, count in top_words:
        print(f"{word}: {count}")

if __name__ == "__main__":
    main()
```

---

### 📌 Notes

- **Word Normalization**:
  - All words are converted to lowercase to ensure "Hello" and "hello" are treated as the same word.
  - The regex `\b\w+\b` extracts sequences of alphanumeric characters (`[a-zA-Z0-9]`) to avoid punctuation (except apostrophes which are not considered word characters in `\w`).

- **Robustness**:
  - The program gracefully handles possible errors such as file access issues or non-text files.
  - It checks that the item is indeed a file and has a `.txt` extension before processing it.

- **Output**:
  - Lists the **top 5 words** with their frequencies in descending order.
  - If there are fewer than 5 words, it lists all available words.
