Here's a C++ program that computes the **n-th Fibonacci number** using **recursion**, based on the standard definition:

- `Fib(0) = 0`  
- `Fib(1) = 1`  
- `Fib(n) = Fib(n-1) + Fib(n-2)` (for n ≥ 2)

This version of the Fibonacci sequence is widely used in mathematical and algorithmic contexts, and recursion is well-suited for the purpose, even though it is not the most efficient for large n.

---

### ✅ **C++ Program: Recursively Compute the nth Fibonacci Number**

```cpp
#include <iostream>
using namespace std;

// Function to compute the nth Fibonacci number using recursion
int fibonacci(int n) {
    if (n <= 1) {
        return n;
    } else {
        return fibonacci(n - 1) + fibonacci(n - 2);
    }
}

int main() {
    int n;
    cout << "Enter a number (n): ";
    cin >> n;

    // Check for invalid input
    if (n < 0) {
        cout << "Input should be a non-negative integer." << endl;
    } else {
        cout << "The " << n << "th Fibonacci number is " << fibonacci(n) << endl;
    }

    return 0;
}
```

---

### 🔍 **Explanation**

1. **Recurrence Relation**:
   - `Fib(n) = Fib(n-1) + Fib(n-2)`
   - Base case: `Fib(0) = 0` and `Fib(1) = 1`
   
2. **Why Recursion is Used**:
   - It directly mirrors the mathematical definition of the Fibonacci sequence.
   - The recursion works for any non-negative integer `n`.

3. **Time Complexity**:
   - **Time Complexity**: O(2ⁿ)  
   - **Space Complexity**: O(n) due to the call stack depth (though this can grow quickly and cause stack overflow for large values of `n`).

4. **Input Validation**:
   - If the user tries to input a negative number or a non-integer, the program will prompt them to provide a valid input.

### 📝 **Note**
While the recursive implementation is elegant and clear, it is not efficient for large `n` values due to repeated work. For large `n`, consider using **iterative approaches** or **memoization** to improve performance.
