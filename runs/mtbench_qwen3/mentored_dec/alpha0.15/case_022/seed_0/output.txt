Here's a C++ program that computes the **n-th Fibonacci number using recursion**. It assumes that the input is a non-negative integer and handles basic validation to ensure the program doesn't crash when negative numbers are provided.

---

### 💡 **Explanation**

The Fibonacci sequence is defined as:
- `F(0) = 0`
- `F(1) = 1`
- `F(n) = F(n-1) + F(n-2)` for `n > 1`

The recursive approach directly translates this definition into code. However, note that recursion is not the most efficient method for large values of `n` due to repeated calculations. Still, this fulfills the problem's requirement.

---

### ✅ **Code**

```cpp
#include <iostream>

using namespace std;

// Function to compute the nth Fibonacci number using recursion
int fibonacci(int n) {
    if (n <= 1) {
        return n;
    } else {
        return fibonacci(n - 1) + fibonacci(n - 2);
    }
}

int main() {
    int n;
    cout << "Enter the value of n (non-negative integer): ";
    cin >> n;

    // Input validation to ensure n is non-negative
    if (n < 0) {
        cout << "Invalid input. Please enter a non-negative integer." << endl;
        return 1;
    }

    // Compute and display the result
    cout << "The " << n << "th Fibonacci number is " << fibonacci(n) << endl;

    return 0;
}
```

### ⚠️ **Note on Efficiency**

While this recursive approach is simple and intuitive, it has exponential time complexity (O(2^n)) due to repeated calculations. For large `n`, this can be very slow. If performance is important, consider using **iterative** or **memoization-based** approaches instead.
