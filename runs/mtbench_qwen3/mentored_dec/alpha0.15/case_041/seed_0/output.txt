### 📁 Complete Code: `index.html`

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Random Joke Generator</title>
</head>
<body>
    <h1>Random Joke Generator</h1>
    <p id="joke">Click the button to get a joke!</p>
    <button id="jokeButton">Tell me a joke!</button>

    <script>
        const jokes = [
            "Why don't scientists trust atoms? Because they make up everything!",
            "What do you call fake spaghetti? An impasta!",
            "Why did the scarecrow win an award? Because he was outstanding in his field!",
            "How do you organize a space party? You planet!"
        ];

        const jokeButton = document.getElementById('jokeButton');
        const jokeElement = document.getElementById('joke');

        function showRandomJoke() {
            const randomIndex = Math.floor(Math.random() * jokes.length);
            jokeElement.textContent = jokes[randomIndex];
        }

        jokeButton.addEventListener('click', showRandomJoke);
    </script>
</body>
</html>
```

---

### 🧠 How It Works:

1. **HTML Structure**:
   - A heading (`<h1>`) introduces the idea.
   - A paragraph (`<p>`) with the `id="joke"` is used to display the joke.
   - A button (`<button>`) with the `id="jokeButton"` is rendered to trigger the joke display.

2. **JavaScript Logic**:
   - An array of four jokes is declared.
   - The script selects the button and joke paragraph using `document.getElementById`.
   - When the button is clicked, a `showRandomJoke` function is called.
   - Inside the function:
     - A random index is generated using `Math.random()`.
     - The joke at the random index is displayed in the paragraph.

---

### 💡 Notes:
- The joke paragraph initially displays a prompt message, which gets replaced when the button is clicked.
- The script is placed at the bottom of the `<body>` to ensure the DOM elements are fully loaded before the script runs.
- This is a **pure HTML + JavaScript** solution and requires no external assets or frameworks.
