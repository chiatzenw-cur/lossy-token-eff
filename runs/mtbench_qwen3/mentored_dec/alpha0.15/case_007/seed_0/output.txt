Here's a Python program that reads all the text files in the current directory, processes their content to count word frequencies, and then displays the top 5 most frequent words. The solution handles case-insensitivity, ignores punctuation, and is flexible for standard text files.

---

### ✅ **Overview of the Program**

The program performs the following steps:

1. **Locate All `.txt` Files** in the current directory.
2. **Read Each File's Contents** and extract the words.
3. **Count Word Occurrences** using `collections.Counter`.
4. **Determine the Top 5 Words** with the highest frequency.
5. **Print the Top Words and Their Frequencies**.

---

### 📜 **Python Code**

```python
import os
import re
from collections import Counter

def count_top_words(directory='.'):
    # Step 1: Find all .txt files in the specified directory
    text_files = [
        f for f in os.listdir(directory)
        if os.path.isfile(os.path.join(directory, f)) and f.endswith('.txt')
    ]

    if not text_files:
        print("No text files found in the directory.")
        return

    # Step 2: Initialize a counter to store word frequencies
    word_counts = Counter()

    # Step 3: Read each file's content and process words
    for filename in text_files:
        file_path = os.path.join(directory, filename)
        try:
            with open(file_path, 'r', encoding='utf-8') as file:
                content = file.read().lower()  # Normalize to lowercase
                words = re.findall(r'\w+', content)  # Extract words using regex
                word_counts.update(words)
        except Exception as e:
            print(f"Error reading file '{filename}': {e}")
            continue

    # Step 4: Get the top 5 most frequent words
    top_words = word_counts.most_common(5)

    # Step 5: Print the results
    print("Top 5 most frequent words:")
    for word, count in top_words:
        print(f"{word}: {count}")
```

### 🔍 **Key Features**

- **Case-insensitive** (converting all text to lowercase before counting).
- **Punctuation Ignored** (using `re.findall(r'\w+', content)`).
- **Robust File Handling** (captures errors during file access).
- **Flexible Directory** (can be changed to process any directory by modifying the `directory` argument in `count_top_words()`).
- **Portable** (works across different platforms as long as files are accessible).
