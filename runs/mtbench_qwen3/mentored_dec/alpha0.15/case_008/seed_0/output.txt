To solve the problem of finding the **majority element** in an integer array using the **Boyer-Moore Voting Algorithm**, we can follow a strategy that ensures **linear time complexity** $O(n)$ and **constant space complexity** $O(1)$. The criteria for a majority element is that it appears **more than $ \frac{n}{2} $ times** in the array.

---

### ✅ Key Concepts of the Boyer-Moore Voting Algorithm

- The algorithm operates by keeping track of a **candidate** and a **count**.
- It works by **cancelling out** elements as it traverses the array.
- When the count becomes 0, the next element becomes the new candidate.
- If the current element is the same as the current candidate, the count is incremented; otherwise, it is decremented.

This algorithm ensures that if there exists a majority element, it will be the final **candidate** after the loop. However, it **does not verify** if the candidate is indeed the majority, which is a potential issue if the array has no such element.

---

### ⚠️ Assumptions

- The input is guaranteed to have a **majority element**.
- Therefore, we **do not perform** a second pass to verify the result.
- If no such element exists, the algorithm may return a **false candidate**, but this is **not the focus** of the current problem.

---

### 🧠 Example

Given the array `[2, 2, 1, 1, 2]`:

- The majority element is `2`, which appears 3 times (more than half of 5).
- Using the algorithm:
  - Initialize `candidate = None`, `count = 0`.
  - Traverse each element and update the candidate and count accordingly.
  - Final candidate is `2`.

---

### 📘 Code Implementation

```python
def majority_element(nums):
    """
    Find the majority element in an array using the Boyer-Moore Voting Algorithm.
    Assumes the array contains a majority element (appears more than n/2 times).

    Parameters:
        nums (List[int]): The list of integers.

    Returns:
        int: The majority element.
    """
    candidate = None
    count = 0

    for num in nums:
        if count == 0:
            candidate = num
        if num == candidate:
            count += 1
        else:
            count -= 1

    return candidate
```

---

### 📌 Time & Space Complexity

- **Time**: $O(n)$ — Only a single pass through the array is required.
- **Space**: $O(1)$ — Only constant extra memory is used (candidate and count variables).

---

### 🔍 Edge Case: When the Majority Element is Not Present

If the input array does **not** have a majority element, this function may return a **false candidate**. However, since the question assumes the presence of a majority element, this is an acceptable design for the given problem.

If verification is needed, a simple second pass over the array to count the votes of the final candidate would be added.

---

### 🔚 Conclusion

The proposed function is a **correct and efficient** implementation of the Boyer-Moore Voting Algorithm to find a **majority element**, leveraging the assumption that such an element exists in the list. It is ideal for large datasets where memory is a concern and speed is a priority.
