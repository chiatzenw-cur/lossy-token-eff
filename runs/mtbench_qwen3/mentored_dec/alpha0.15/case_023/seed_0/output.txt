To find the **Highest Common Ancestor (HCA)** of two nodes in a binary tree, we can interpret this as finding the **Lowest Common Ancestor (LCA)**. In any binary tree, the LCA is the "deepest" node that is an ancestor of both input nodes. It is the **last common node along the paths from the root to each node**.

This interpretation is consistent with standard definitions in tree theory. Therefore, the problem of finding the HCA reduces to finding the LCA, and we can proceed under that understanding.

---

### ✅ Key Idea:
We use a **recursive approach** to traverse the tree from the root downward. At each node:
- If either node is the current root, it becomes a candidate for the LCA.
- If the two nodes lie in **different subtrees** (i.e., one in the left and one in the right), the current node is their **LCA**.
- If both nodes are in the **same subtree**, we recursively search that subtree.

---

### 🧠 Algorithm:
```python
def find_lca(root, p, q):
    if root is None:
        return None

    if root == p or root == q:
        return root

    left = find_lca(root.left, p, q)
    right = find_lca(root.right, p, q)

    if left and right:
        return root
    elif left:
        return left
    else:
        return right
```

---

### 🧾 Time and Space Complexity:
- **Time Complexity:** `O(h)`, where `h` is the height of the tree. We visit each node once in the worst case.
- **Space Complexity:** `O(h)` due to the recursion stack (in the worst case, for a skewed tree).

To compute the **Highest Common Ancestor (HCA)** of two nodes in a binary tree, you can use the lowest common ancestor algorithm. Here is the corresponding function:

```python
class Node:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def find_lca(root, p, q):
    if root is None:
        return None

    if root == p or root == q:
        return root

    left_lca = find_lca(root.left, p, q)
    right_lca = find_lca(root.right, p, q)

    if left_lca and right_lca:
        return root
    elif left_lca:
        return left_lca
    else:
        return right_lca
```

This function will correctly identify the **deepest node** that is a common ancestor of both input nodes, which is the standard **LCA** and also the **HCA** in a binary tree.
