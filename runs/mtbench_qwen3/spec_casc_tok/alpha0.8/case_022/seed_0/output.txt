Here's a C++ program that calculates the **nth Fibonacci number using recursion**, following the **standard definition** of the Fibonacci sequence where:

- `F(0) = 0`  
- `F(1) = 1`  
- For `n > 1`, `F(n) = F(n-1) + F(n-2)`

This implementation is recursive and will work correctly for all **non-negative integer values** of `n`. Additionally, it includes basic input validation to handle invalid inputs such as negative numbers.

---

### ✅ C++ Program Code

```cpp
#include <iostream>
using namespace std;

// Function to compute the nth Fibonacci number using recursion
int fibonacci(int n) {
    if (n <= 0) {
        return 0;
    } else if (n == 1) {
        return 1;
    } else {
        return fibonacci(n - 1) + fibonacci(n - 2);
    }
}

int main() {
    int n;
    cout << "Enter the value of n: ";
    cin >> n;

    // Input validation to handle negative numbers
    if (n < 0) {
        cout << "Please enter a non-negative integer." << endl;
        return 1;
    }

    cout << "The " << n << "th Fibonacci number is: " << fibonacci(n) << endl;

    return 0;
}
```

---

- The function `fibonacci(int n)` is the recursive implementation.
- It defines the base cases:
  - If `n <= 0`, return `0`.
  - If `n == 1`, return `1`.
- The recursive case computes `fib(n-1) + fib(n-2)` when `n > 1`.
