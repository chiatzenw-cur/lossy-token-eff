Here's a simple HTML website that displays a random joke from a list of four when the user clicks a button. This includes clean structure and the JavaScript logic necessary to handle the button click and display the joke.

### ✅ Features:

---

### 🌐 HTML Code:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Joke Generator</title>
    <style>
        body {
            font-family: Arial, sans-serif;
            text-align: center;
            margin-top: 50px;
            background-color: #f5f5f5;
        }
        button {
            padding: 10px 20px;
            font-size: 18px;
            cursor: pointer;
            background-color: #4CAF50;
            color: white;
            border: none;
            border-radius: 5px;
        }
        button:hover {
            background-color: #45a049;
        }
        #jokeDisplay {
            margin-top: 30px;
            font-size: 20px;
            color: #333;
        }
    </style>
</head>
<body>
    <h1>Joke Generator</h1>
    <button id="jokeButton">Tell me a joke!</button>
    <p id="jokeDisplay"></p>

    <script>
        const jokes = [
            "Why don't scientists trust atoms? Because they make up everything!",
            "Did you hear about the mathematician who’s afraid of negative numbers? He’ll stop at nothing to avoid them!",
            "Why did the scarecrow win an award? Because he was outstanding in his field!",
            "How do you organize a space party? You planet!"
        ];

        function showRandomJoke() {
            const randomIndex = Math.floor(Math.random() * jokes.length);
            const jokeDisplay = document.getElementById('jokeDisplay');
            jokeDisplay.textContent = jokes[randomIndex];
        }

        document.getElementById('jokeButton').addEventListener('click', showRandomJoke);
    </script>
</body>
</html>
```

---

### 🧠 How It Works:
1. **HTML Structure:**
   - A `<h1>` heading to display the title.
   - A `<button>` with an `id` for triggering the joke.
   - A `<p>` element with an `id` to show or update the joke text.

2. **JavaScript Logic:**
   - An array of four pre-defined jokes.
   - A function `showRandomJoke()` that picks a random joke from the array and updates the `textContent` of the joke display paragraph.
   - An event listener on the button to call the function on click.

3. **CSS Styling:**
   - Simple styling to make the page look clean and modern.

---

### 📝 Notes:
- The script is placed at the **end of the body** to ensure that all HTML elements (like the button and paragraph) are already loaded in the DOM before the script runs.
- The `textContent` property is used to safely set the joke content.

---

### 🧪 Example Output:
When the button is clicked, the displayed joke will be one of the four, chosen randomly each time.
