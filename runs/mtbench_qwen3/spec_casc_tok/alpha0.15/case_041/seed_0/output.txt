### ✅ **HTML Code**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Random Joke Generator</title>
    <style>
        body {
            font-family: Arial, sans-serif;
            text-align: center;
            padding: 50px;
            background-color: #f9f9f9;
        }
        button {
            padding: 10px 20px;
            font-size: 18px;
            cursor: pointer;
            border: none;
            background-color: #4CAF50;
            color: white;
            border-radius: 5px;
        }
        button:hover {
            background-color: #45a049;
        }
        #jokeDisplay {
            margin-top: 30px;
            font-size: 20px;
            color: #333;
        }
    </style>
</head>
<body>

    <h1>Random Joke Generator</h1>
    <button id="jokeButton">Tell me a joke!</button>
    <p id="jokeDisplay"></p>

    <script>
        // Array of jokes
        const jokes = [
            "Why don't scientists trust atoms? Because they make up everything!",
            "What do you call fake spaghetti? An impasta!",
            "Why did the scarecrow win an award? Because he was outstanding in his field!",
            "How do you organize a space party? You planet!"
        ];

        // Function to display a random joke
        function showRandomJoke() {
            const randomIndex = Math.floor(Math.random() * jokes.length);
            const jokeDisplay = document.getElementById('jokeDisplay');
            jokeDisplay.textContent = jokes[randomIndex];
        }

        // Attach event listener to the button
        document.getElementById('jokeButton').addEventListener('click', showRandomJoke);
    </script>

</body>
</html>
```

---

### 📌 Features Included

- **Responsive Design**: Clean and centered layout with simple styling.
- **Dynamic Joke Display**: Uses JavaScript to select a joke randomly from an array and show it on the page.
- **Interactive Button**: When clicked, it fetches a joke and updates the content instantly.
- **Accessible and Maintainable**: Separates structure (HTML), style (CSS), and behavior (JavaScript).

---

### 💡 How It Works

1. **HTML Elements**:
   - A `<button>` with the ID `jokeButton` triggers the action.
   - A `<p>` with the ID `jokeDisplay` is where the joke is shown.

2. **JavaScript Logic**:
   - An array `jokes` contains all the jokes.
   - The `showRandomJoke()` function picks a random joke and updates the text content of the `<p>` element.
   - The `addEventListener` method ties the click of the button to the function.
