To find the number of full binary trees with `n` vertices, we first observe the defining structure of a **full binary tree**: every node has **either zero or two** children. This means that **no node can have exactly one child**.

### Key Insight:

From combinatorial theory, it's well known that the number of **full binary trees** with `k` internal nodes (and therefore `k+1` leaves) corresponds to the **k-th Catalan number**. This is because the Catalan numbers count the number of ways to parenthesize an expression with `k+1` variables, which is structurally equivalent to forming full binary trees with internal nodes.

In turn, the total number of nodes in a full binary tree is always **odd**, due to the relationship between internal and leaf nodes:  
`Number of internal nodes = L - 1` (where `L` is the number of leaves),  
so total nodes = `L + (L - 1) = 2L - 1`, which is always odd.

This means that for **even values of `n`**, it is **impossible** to have a full binary tree with `n` vertices. Hence, `B_n = 0` for all even `n`.

For **odd `n`**, we can write `n = 2k + 1`, which means there are `k` internal nodes, so the number of such full binary trees is the `k-th Catalan number`.

---

### Implementation Strategy:

We can implement this logic efficiently by using **dynamic programming** to compute the Catalan numbers up to the required index. This avoids factorial or binomial coefficient calculations (which can be computationally heavy for large `k`) and is generally easier to maintain and understand.

---

### Python Function:

```python
def B(n):
    if n % 2 == 0:
        return 0
    k = (n - 1) // 2
    catalan = [0] * (k + 1)
    catalan[0] = 1  # Base case: C_0 = 1
    
    for i in range(1, k + 1):
        catalan[i] = sum(catalan[j] * catalan[i - 1 - j] for j in range(i))
    
    return catalan[k]
```
