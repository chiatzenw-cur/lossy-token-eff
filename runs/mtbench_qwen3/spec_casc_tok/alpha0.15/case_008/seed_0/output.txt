To solve the problem of finding the **majority element** in an array of integers using the **Boyer-Moore Voting Algorithm**, we implement an elegant and efficient solution that runs in **O(n)** time and **O(1)** space.

---

### ✅ Understanding the Problem

The **majority element** in an array is the one that appears **more than half** the length of the array. Formally, for an array of size `n`, the majority element must occur at least `n // 2 + 1` times.

The **Boyer-Moore Voting Algorithm** is a technique designed to **detect the majority element** in linear time without needing extra space. It works by maintaining a **candidate** and a **count**. It “votes” for the current element or “votes against” it, tracking the frequency of the candidate.

---

### 🔍 Algorithm Steps

The Boyer-Moore Voting Algorithm follows these steps:

1. Initialize a `candidate` to `None` and a `count` to `0`.
2. Iterate through each number in the array:
   - If the `count` is `0`, set the current number as the `candidate`.
   - If the current number is equal to the `candidate`, increment the `count`.
   - Otherwise, decrement the `count`.
3. At the end of the iteration, the `candidate` is the **majority element** **if it exists**.

This algorithm **guarantees to find the majority element** if one exists. However, **if no majority element exists**, the final `candidate` may not be the correct one. Thus, in some contexts, it’s good practice to *verify* the result by counting its actual occurrences once it is identified. But, given the problem's phrasing, it is **assumed that a majority element exists** in the input array.

---

### 🧠 Example Walkthrough

Consider the array: `[2, 2, 1, 1, 2]`

- Initialize: `candidate = None`, `count = 0`
- 2 (count = 0): `candidate = 2`, `count = 1`
- 2 (same as candidate): `count = 2`
- 1 (not same): `count = 1`
- 1 (not same): `count = 0`
- 2 (count = 0): `candidate = 2`, `count = 1`

At the end, the candidate is **2**, which is the correct majority element.

---

### 🧾 Python Implementation

```python
def majority_element(arr):
    candidate = None
    count = 0

    for num in arr:
        if count == 0:
            candidate = num
        if num == candidate:
            count += 1
        else:
            count -= 1

    return candidate
```

---

### 📌 Notes

- This implementation **does not check** whether the candidate is actually the majority element. This is intentional, as per the problem's context, where it is assumed that a majority element exists.
- If the problem requires verification, a second pass over the array to count the occurrences of the final `candidate` is necessary to ensure it is indeed the majority element.

---

### ✅ Time and Space Complexity

- **Time Complexity:** `O(n)` — We traverse the array once.
- **Space Complexity:** `O(1)` — We use only a constant amount of extra space.

---

### 🧪 Test Case

```python
arr = [1, 1, 2, 2, 3, 3, 3]
print(majority_element(arr))  # Output: 3
```

This will return `3`, which is the correct majority element in the array as it appears **more than half** the time.
