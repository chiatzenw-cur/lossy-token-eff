Here is a C++ program that calculates the nth Fibonacci number using recursion. This implementation follows the standard definition of the Fibonacci sequence where:

- `Fib(0) = 0`
- `Fib(1) = 1`
- `Fib(n) = Fib(n-1) + Fib(n-2)` for `n > 1`

---

### ✅ C++ Program to Find the nth Fibonacci Number Using Recursion

```cpp
#include <iostream>
using namespace std;

// Function to compute the nth Fibonacci number using recursion
int fibonacci(int n) {
    if (n <= 1) {
        return n;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main() {
    int n;

    // Prompt the user to enter a number
    cout << "Enter an index (n >= 0) to find the nth Fibonacci number: ";
    cin >> n;

    // Handle invalid input (negative number)
    if (n < 0) {
        cout << "Error: Fibonacci number is not defined for negative indices." << endl;
        return 1;
    }

    // Compute and display the result
    cout << "The " << n << "th Fibonacci number is: " << fibonacci(n) << endl;

    return 0;
}
```

---

### 🔍 Explanation

- **Recursive Function `fibonacci`**:
  - Base cases: `n == 0` or `n == 1` return `n` directly.
  - Recursive case: For `n > 1`, the function calls itself with `n-1` and `n-2`, and returns their sum.
  
- **Main Function**:
  - Accepts user input for index `n`.
  - Validates the input to ensure it is a non-negative integer.
  - Displays the result using the recursive function.

---

### ⚠️ Important Notes

- **Time Complexity**: This solution has exponential time complexity (`O(2^n)`), which is not efficient for large values of `n`. However, the problem specifically asks for a **recursive** implementation, so efficiency is not the focus here.
- **Space Complexity**: `O(n)` due to the recursion call stack.
