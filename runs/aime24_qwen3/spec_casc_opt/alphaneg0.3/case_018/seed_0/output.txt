To find the number of triples of nonnegative integers $(a, b, c)$ satisfying:

$$
a + b + c = 300 \quad \text{and} \quad a^2b + a^2c + b^2a + b^2c + c^2a + c^2b = 6,000,000,
$$

we proceed by examining and simplifying the second condition.

---

### Step 1: Simplify the Symmetric Expression

The expression:

$$
a^2b + a^2c + b^2a + b^2c + c^2a + c^2b
$$

can be factored as:

$$
a^2(b + c) + b^2(a + c) + c^2(a + b)
$$

Since $ a + b + c = 300 $, we can write:

$$
b + c = 300 - a, \quad a + c = 300 - b, \quad a + b = 300 - c
$$

Substituting into the expression:

$$
a^2(300 - a) + b^2(300 - b) + c^2(300 - c)
$$

Expanding each term and simplifying:

$$
= 300(a^2 + b^2 + c^2) - (a^3 + b^3 + c^3)
$$

So our first equation becomes:

$$
300(a^2 + b^2 + c^2) - (a^3 + b^3 + c^3) = 6,000,000 \tag{1}
$$

---

### Step 2: Use Identities to Express in Terms of Sums

We define:
- $ S = a + b + c = 300 $
- $ P = ab + bc + ca $
- $ Q = abc $

Then:

- $ a^2 + b^2 + c^2 = S^2 - 2P = 300^2 - 2P = 90000 - 2P $
- $ a^3 + b^3 + c^3 = S^3 - 3SP + 3Q = 300^3 - 3(300)P + 3Q = 27,000,000 - 900P + 3Q $

Substituting into (1):

$$
300(90000 - 2P) - (27,000,000 - 900P + 3Q) = 6,000,000
$$

Simplify:

$$
27,000,000 - 600P - 27,000,000 + 900P - 3Q = 6,000,000
$$

$$
300P - 3Q = 6,000,000 \Rightarrow Q = 100P - 2,000,000 \tag{2}
$$

---

### Step 3: Analyze the Cubic Roots

Given that $ a, b, c $ are roots of the polynomial:

$$
x^3 - Sx^2 + Px - Q = 0 = x^3 - 300x^2 + Px - (100P - 2,000,000)
$$

We factor:

$$
x^3 - 300x^2 + Px - 100P + 2,000,000 = x^3 - 300x^2 + P(x - 100) + 2,000,000
$$

We suspect that one root is $ x = 100 $, so we check:

$$
(100)^3 - 300(100)^2 + P(100 - 100) + 2,000,000 = 0
$$

Which is true, so $ x = 100 $ is a root. We divide the cubic by $ x - 100 $ to get:

$$
(a, b, c) = (100, 100 + m, 100 - m)
$$

These are the three numbers that satisfy the equation for all $ m \in [0, 100] $, and each gives a valid triple of nonnegative integers.

### Step 4: Count the Number of Ordered Triples

- For $ m = 1 $ to $ 100 $: $ 100 $ values of $ m $, each contributing 6 permutations
