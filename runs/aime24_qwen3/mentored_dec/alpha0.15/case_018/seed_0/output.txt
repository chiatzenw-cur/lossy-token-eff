To determine the number of nonnegative integer triples $(a, b, c)$ satisfying both conditions:
- $a + b + c = 300$
- $a^2b + a^2c + b^2a + b^2c + c^2a + c^2b = 6{,}000{,}000$

we can approach the problem in stages, first simplifying the expression and then analyzing possible cases.

---

### **Step 1: Simplify the Expression**

Let’s denote the given symmetric expression:

$$
a^2b + a^2c + b^2a + b^2c + c^2a + c^2b
$$

We can group terms:

$$
= a^2(b + c) + b^2(a + c) + c^2(a + b)
$$

Using the identity $a + b + c = S = 300$, we can express $b + c = 300 - a$, etc., giving:

$$
= a^2(300 - a) + b^2(300 - b) + c^2(300 - c)
$$

Expanding:

$$
= 300a^2 - a^3 + 300b^2 - b^3 + 300c^2 - c^3
= 300(a^2 + b^2 + c^2) - (a^3 + b^3 + c^3)
$$

Thus, the original condition becomes:

$$
300(a^2 + b^2 + c^2) - (a^3 + b^3 + c^3) = 6{,}000{,}000
$$

---

### **Step 2: Use Algebraic Identities**

Let’s use the standard symmetric identity for sum of cubes:

$$
a^3 + b^3 + c^3 = (a + b + c)^3 - 3(a + b + c)(ab + bc + ca) + 3abc
$$

Substituting $a + b + c = 300$, we obtain:

$$
a^3 + b^3 + c^3 = 300^3 - 3(300)(ab + bc + ca) + 3abc = 27{,}000{,}000 - 900(ab + bc + ca) + 3abc
$$

We also know:

$$
a^2 + b^2 + c^2 = (a + b + c)^2 - 2(ab + bc + ca) = 90{,}000 - 2(ab + bc + ca)
$$

Now plugging into the original equation:

$$
300(a^2 + b^2 + c^2) - (a^3 + b^3 + c^3) = 300(90{,}000 - 2(ab + bc + ca)) - (27{,}000{,}000 - 900(ab + bc + ca) + 3abc)
$$

Simplifying step by step:

- $300(90{,}000 - 2P) = 27{,}000{,}000 - 600P$
- The other part becomes $27{,}000{,}000 - 900P + 3abc$

Subtracting the expressions:

$$
(27{,}000{,}000 - 600P) - (27{,}000{,}000 - 900P + 3abc) = 300P - 3abc = 6{,}000{,}000
$$

Divide both sides by 3:

$$
100P - abc = 2{,}000{,}000 \quad \Rightarrow \quad abc = 100P - 2{,}000{,}000
