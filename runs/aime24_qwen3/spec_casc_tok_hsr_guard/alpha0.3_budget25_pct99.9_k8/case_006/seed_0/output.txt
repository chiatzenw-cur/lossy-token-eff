### Step 1: Recognizing the Symmetry

The symmetry in the edge lengths—specifically that opposite edges are equal—suggests that the tetrahedron has certain **planar symmetry**. This is a hallmark of a **disphenoid** tetrahedron, a type of tetrahedron in which all four **faces are congruent triangles**, and opposite edges are equal in length. 

Because of this symmetry, we can apply a geometric construction where the tetrahedron can be inscribed in a **rectangular box**. In this setup, the tetrahedron's edges are derived from diagonal distances of the box.

Let’s assign variables to the dimensions of the box:

- Let the box have side lengths $a$, $b$, and $c$
- Then, the edges of the tetrahedron are:
  - $AB = \sqrt{a^2 + b^2} = \sqrt{41}$
  - $AC = \sqrt{a^2 + c^2} = \sqrt{80}$
  - $AD = \sqrt{b^2 + c^2} = \sqrt{89}$

### Step 2: Solving for Dimensions of the Box

From the equations:

$$
\begin{cases}
a^2 + b^2 = 41 \\
a^2 + c^2 = 80 \\
b^2 + c^2 = 89
\end{cases}
$$

We solve this system:

- Subtract the first from the second: $c^2 - b^2 = 39$
- Add to the third: $c^2 - b^2 + b^2 + c^2 = 39 + 89 \Rightarrow 2c^2 = 128 \Rightarrow c^2 = 64 \Rightarrow c = 8$
- Then $b^2 = 89 - 64 = 25 \Rightarrow b = 5$
- Finally, $a^2 = 41 - 25 = 16 \Rightarrow a = 4$

So the dimensions are $a = 4$, $b = 5$, $c = 8$
