### Step 1: Simplify the Expression

We can group and re-express the given sum as follows:

$$
a^2b + a^2c + b^2a + b^2c + c^2a + c^2b = a^2(b + c) + b^2(a + c) + c^2(a + b)
$$

$$
a^2(300 - a) + b^2(300 - b) + c^2(300 - c)
$$

Now, expand this expression:

$$
300(a^2 + b^2 + c^2) - (a^3 + b^3 + c^3)
$$

This gives us:

$$
300(a^2 + b^2 + c^2) - (a^3 + b^3 + c^3) = 6,000,000
$$

We use the standard identity for the sum of cubes:

$$
a^3 + b^3 + c^3 = (a + b + c)^3 - 3(a + b + c)(ab + bc + ca) + 3abc
$$

Let’s define:

- $ S = a + b + c = 300 $
- $ P = ab + bc + ca $
- $ Q = abc $

Then:

$$
a^3 + b^3 + c^3 = 300^3 - 3 \cdot 300 \cdot P + 3Q = 27,000,000 - 900P + 3Q
$$

Substituting this into the original equation:

$$
300(a^2 + b^2 + c^2) - (a^3 + b^3 + c^3) = 6,000,000

$$
a^2 + b^2 + c^2 = S^2 - 2P = 300^2 - 2P = 90,000 - 2P
$$

300(a^2 + b^2 + c^2) = 300(90,000 - 2P) = 27,000,000 - 600P

- $ -3Q $ remains

- $ C $: set of triples where $ c = 100 $
