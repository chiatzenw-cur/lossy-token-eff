Just copy the code into a `<filename>` (e.g. `index.html`) and open it in any browser.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Random Joke Generator</title>
<style>
  body { font-family: Arial, sans-serif; text-align: center; margin-top: 5rem; }
  .joke { margin: 2rem 0; font-size: 1rem; font-weight: 500; }
  button { padding: 0.6rem 1.2rem; font-size: 1rem; cursor: pointer; }
</style>
</head>
<body>

<h1>Click the button for a random joke</h1>

<button id="jokeBtn">Tell me a joke!</button>

<p id="joke" class="joke">Your joke will appear here.</p>
  
<script>
  // Array that contains the jokes
  const jokes = [
      "Why don’t skeletons fight each other? They don’t have the guts.",
      "I told my wife she was drawing her eyebrows too high. She looked surprised.",
      "What do you call a fake noodle on a trip? An impasta!",
      "I’d tell you a construction joke, but I’m still working on it."
  ];

  // Function that picks a random joke from the array
  const getRandomJoke = () => {
    const idx = Math.floor(Math.random() * jokes.length);
    return jokes.find((_, i) => i === idx);
  };

  // Hook up the button
  document.getElementById('jokeBtn').addEventListener('click', () => {
    const jokeEl = document.getElementById('joke');
    jokeEl.textContent = getRandomJoke();
  });
</script>

</body>
</html>
```

### How it works

1. **Jokes Array** – Four jokes are stored in the `jokes` array.  
2. **Shuffling Logic** – The `getRandomJoke` function picks out a random index using `Math.random()` and returns that joke.  
3. **Handling the Click** – When the button is clicked, the script fetches the paragraph element `#joke` and replaces its text with the newly selected joke.
