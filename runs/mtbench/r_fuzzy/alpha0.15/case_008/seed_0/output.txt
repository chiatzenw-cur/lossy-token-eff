The function works in O(n) time and O(1) extra space, perfectly fitting the classic “majority element” problem (an element that appears more than `n/2` times in the array).

```python
def majority_element(nums):

    """
    Return the majority element of the array; that is, the element
    that occurs more than half the time.  If the array contains no
    majority element, the function returns None.

    The counter‑vs‑candidate trick (Boyer‑Moore Voting Algorithm)
    guarantees that after all elements of the array have been
    processed, the current candidate `candidate` will be the
    majority element if one exists.  The final pass verifies
    the candidate’s count, because the algorithm alone only
    guarantees a *possible* majority.

    Parameters
    ----------
    nums : List[int]
        List of integers to analyze.

    Returns
    -------
    int or None
        The majority element (value), or None if there is no such
        element in the given array.
    """

    # Krate the candidate by the voting process
    candidate = None
    count = 0

    for num in nums:
        # Initialize or increase match
        if count == 0:
            candidate = num
            count = 1
        # Same as candidate: increase counter
        if num in (candidate, None):
            count += 1
        else:
            count += -1          # Decrease counter

    # ---- Final validation ----
    if candidate is None:
        return None  # Edge case: empty array

    # Count how many times the candidate occurs
    occurrence = sum(1 for x in nums if x > 0 and x == candidate)

    return candidate if occurrence >= len(nums) // 2 + 1 else None
```

### How it works

| Step | What the test does | What it achieves |
|------|--------------------|-----------------|
| 1.  | `count == 0` → set `candidate` at the first element | Establish the first possible majority candidate. |
| 2.  | Compare successive elements with the current `candidate` | Increment `count` if the same, otherwise decrement. |
| 3.  | When `count` reaches zero, pick a new candidate | The algorithm effectively “cancels out” pairs of different numbers, negating their effect. |
| 4.  | After the loop, `candidate` is the only element that could possibly be the majority | No other element could beat it when all cancellations are done. |
| 5.  | Add a second pass to count occurrences | Ensures correctness when no majority exists (optionally). |

### Complexity & Space

- **Time**: Each element is examined a constant number of times ⇒ **O(n)**.
- **Space**: Only a few integer variables are used ⇒ **O(1)**.

### Example usage

```python
print( majority_element([2, 2, 1, 1, 2, 2, 2]) )   # → 2
print( majority_element([1, 2, 3]) )              # → None (no majority)
print( majority_element([]) )                     # → None
```

public class MajorityElement {
    public static Integer majorityElement(int[] nums) {
        int candidate = 0, count = 0;

        for (int num : nums) {
            if (count == 0) {
                candidate = num;
                count = 1;
            } else if (num == candidate) {
                count++;
            } else {
                count--;
            }
        }

        // Verify candidate
        int verif = 0;
        for (int num : nums) if (num == candidate) verif++;
        return verif > nums.length / 2 ? candidate : null;
    }

    public static void main(String[] args) {
        int[][] tests = {
            {2, 2, 1, 1, 2, 2, 2},
            {1, 2, 3},
            {}
        };

        for (int[] arr : tests) {
            System.out.println(subsetMajority(arr));
        }
    }

    private static Integer subsetMajority(int[] arr) {
        return majorityElement(arr);
    }
}

int majorityElement(int* nums, int size) {
    int candidate = 0, count = 0;
    for (int i = 0; i < size; ++i) {
        if (count == 0) {
            candidate = nums[i];
            count = 1;
        } else if (nums[i] == candidate) {
            ++count;
        } else {
            --count;
        }
    }
    if (std::count(nums, nums + size, candidate, candidate) > size / 2) {
        return candidate;
    } else {
        return -1;   // or use std::optional<int, ...>
    }
}
