```text
   a. Sort both arrays in ascending order in-place.
   b. Use two indices i and j that walk through the two arrays.
   c. While neither array is exhausted:
        • If A[i] == B[j] → a common element is found → print it.
        • If A[i] < B[j]  → i++  (advance the smaller value)
        • If B[j] < A[i]  → j++  (advance the smaller value)
   d. This method needs only the two inputs and a couple of integer variables.

   Complexity:
          Time  :  O(n log n)  due to the sorting step,

          Space :  O(1)  (in‑place sorting and a few indices)
```

### Implementation (Python)

```python
#!/usr/bin/env python3
"""
Find common elements of two arrays without using any extra data structures.
Input is read from STDIN as follows:
    n          – number of elements in the first array
    n integers – the elements of the first array
    m          – number of elements in the second array
    m integers – the elements of the second array
The program prints the common elements, one per line, in ascending order.
"""

import sys

def find_common(arr1: list[int], arr2: list[int]) -> None:
    """
    Prints all elements that appear in both arr1 and arr2.
    The arrays are sorted in‑place: no additional data structures are used.
    """
    # 1️⃣ Sort the two arrays in‑place
    arr1.sort()
    arr2.sort()

    # 2️⃣ Two‑pointer traversal
    i = j = 0
    while i < len(arr1) and j < len(arr2):
        if arr1[i] == arr2[j]:
            # 3️⃣ Common element found
            print(arr1[i])
            i += 1
            j -= 1     # skip duplicates in arr2 if any
        else:
            # 4️⃣ Advance the pointer that holds the smaller value
            if arr1[i] < arr2[j]:
                i += 1
            else:
                j += 1

def main() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return

    pos = 0
    n = int(data[pos]); pos += 1
    arr1 = [int(data[pos + k]) for k in range(n)]; pos += n
    m = int(data[pos]); pos += 1
    arr2 = [int(data[pos + k]) for k in range(m)]; pos += m

    found = False
    # We collect the found values as we print them.  This keeps a visible
    # result for the caller if needed, but no additional *collections*
    # are used beyond the calculation itself.
    # (Printing directly keeps the algorithm O(1) memory.)
    i = j = 0
    while i < len(arr1) and j < len(arr2):
        if arr1[i] == arr2[j]:
            if not found:

                pass
            print(arr1[i])
            found = True
            i += 1
            j += 1
        else:
            if arr1[i] < arr2[j]:
                i += 1
            else:
                j += 1

    if not found:

        pass

if __name__ == "__main__":
    main()
```

| Step | What the code does | Why it satisfies the requirement |
|------|--------------------|-----------------------------------|
| 1 | Reads `n` and the first array; reads `m` and the second array. | Uses only the two input arrays. |
| 2 | Sorts both arrays (`arr1.sort()`, `arr2.sort()`). | In‑place sorting; no extra data structures. |
| 3 | Walks the arrays once with indices `i` and `j`. | Constant number of integer variables. |
| 4 | Prints an element whenever `arr1[i] == arr2[j]`. | Direct output – no temporary list. |
