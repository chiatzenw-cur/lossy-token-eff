## 1.  What a “full binary tree” is

* Every internal vertex (i.e., a vertex with children) has exactly **2** children.  
* Vertices that are not internal are **leaves** (no parents).  

In such a tree

```
#leaves = #internal vertices + 1  (a basic property)
```

Let  

```
N = total number of vertices
I = number of internal vertices
L = number of leaves
```

From the property above  
  `L = I + 1 ⇒ N = I + L = I + (I + 1) = 2I+1`

So a full binary tree can only have an **odd** number of vertices, and  
`I = (N-1)/2`.

### Connection to Catalan numbers

The number of full binary trees with exactly `I + 1` leaves (or equivalently
`N = 2I+1` vertices) is the **Catalan number** `C_I`:

```
C_I = (1/(I+1))*binom{2I}{I}
```

Hence

```
B_N = 0                 if N is even
B_N = C_{(N-1)/2}       if N is odd

```

## 2.  Two ways to count `B_n`

| Approach | Complexity | Advantages | Good for … |
|----------|------------|------------|------------|
| **Catalan formula (closed‑form)** | O(1) arithmetic + binomial | Extremely fast, no loops | Small to large `n`, when you trust the math library |
| **Dynamic programming recurrence** | O(n²) time, O(n) space | No large factorials, can be extended to related problems | When you need to compute many values up to the same `n` or you don’t want to use the binomial formula |

Below are both implementations.

> **Tip** – For very large `n` (e.g. thousands of vertices) the Catalan number grows
>  extremely fast, so use Python’s arbitrary‑precision integers (or a big‑int library).

## 3.  Python code

```python
#!/usr/bin/env python3
"""
Count a full binary tree with n vertices.

Two flavours are provided:

* find_B_formula(n) – uses the closed‐form Catalan expression (fast, O(1)).
* find_B_dp(n)      – solves the recurrence B[n] = sum B[i] * B[n-1-i] (O(n^2)).
"""

from __future__ import annotations

from functools import lru_cache
from math import comb
from typing import Dict

# --------------------------------------------------------------------------- #
#  1.  Catalan‑formula version (O(1))
# --------------------------------------------------------------------------- #

def find_B_formula(n: int) -> int:
    """
    Return the number of full binary trees with n vertices.
    Uses the closed‑form Catalan number.
    
    This version:
        * returns 0 for even n
        * returns C_k for odd n, with k = (n-1)/2
    """
    if n % 2 == 0:
        return 0
    
    k = (n - 1) // 2  # number of internal vertices
    # Catalan number: C_k = binom(2k, k) // k+1
    return comb(2 * k, k) // (k + 1)
    
# --------------------------------------------------------------------------- #
#  2.  Dynamic‑programming version (O(n^2))
# --------------------------------------------------------------------------- #

@lru_cache(maxsize=None)
def _B_rec(n: int) -> int:
    """
    Recursive helper (memoized).
    Computes B[n] via the recurrence:
        B[1] = 1  (single vertex)
        B[n] = sum_{i odd} B[i] * B[n-1-i]  for n>1
    """
    if n == 1:
        return 1
    # If n is even, it can't be a full binary tree
    if n % 2 == 0:
        return 0
    
    total = 0
    # left subtree has an odd number of vertices (l)
    # right subtree then gets the rest: r = n-1-l
    for l in range(1, n, 2):
        r = n - 1 - l
        total += _B_rec(l) * _B_rec(r)
    return total


def find_B_dp(n: int) -> int:
    """
    Wrapper that uses the recursive memoised helper.
    The call cost is dominated by the O(n^2) DP recurrence.
    """
    return _B_rec(n)

# --------------------------------------------------------------------------- #
#  3.  Tiny test harness (illustrative)
# --------------------------------------------------------------------------- #

def _demo():
    for n in range(1, 15):
        print(f"n={n:2d} -> B(n) = {find_B_formula(n)}  (formula)")
        print(f"                {find_B_dp(n)}            (DP loop)")

if __name__ == "__main__":
    _demo()
```

### What this code does

| Function | What it returns | How it works |
|----------|-----------------|--------------|
| `find_B_formula(n)` | `B_n` (Catalan number if odd, else 0) | Uses `math.comb` to compute `C_k` in O(1) |
| `find_B_dp(n)` | `B_n` | Employs a DP recurrence; memoised and thus fast for repeated queries |

Both functions give *exact* integer results for any `n` that fits into the
Python `int` type (which is unlimited), so you can feed in tens of thousands
or even millions of elements with no loss of precision.
