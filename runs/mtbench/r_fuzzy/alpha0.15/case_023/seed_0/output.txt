> **What that means**  
> In a connected binary tree, the **root** is an ancestor of *every* node.  
> Therefore any two nodes that really belong to the same tree have a common ancestor that is *highest* up in the tree – the root itself.  

> **Why no algorithmic magic is needed**  
> The “Lowest Common Ancestor” (LCA) is the *deepest* node that is an ancestor of both.  
> The “highest” common ancestor is the *shallowest* one, i.e. the root.  
> So if the two nodes exist in the same tree, you simply return the root; if they are not both present you return `None`.  

Below is a tiny helper that checks the existence of both nodes in a tree and then returns the root (or `None`) – no recursive traversal to find the “deepest” one is required.

```python
# Binary‑tree node layout

class Node:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

# ----------------------------------------------------------
# helper to see if a node exists somewhere in the tree
# ----------------------------------------------------------
def contains(root, target):
    """Return True iff target subtree (by identity) is in the tree rooted at root."""
    if root is None:
        return False
    if root is target:
        return True
    return contains(root.left, target) or contains(root.right, target)

# ----------------------------------------------------------
# Highest common ancestor of two nodes – in the same tree
# ----------------------------------------------------------
def highest_common_ancestor(root, node1, node2):
    """
    Return the highest (root‑level) common ancestor of `node1` and `node2`
    in a single binary tree. If either node does not exist in the tree
    that contains `root`, return None.
    """
    if root is None or node1 is None or node2 is None:
        return None

    # Both nodes must be present in the same tree that has `root`
    if contains(root, node1) and contains(root, node2):
        return root      # the root is the highest common ancestor
    return None          # one (or both) does not belong to this tree


# -------------------------------------------------
# Example usage
# -------------------------------------------------
if __name__ == "__main__":

    #  build a small tree rooted at 'a'
    a = Node('a')
    b = Node('b')
    c = Node('c')
    d = Node('d')
    e = Node('e')
    a.left  = b
    b.left  = d
    b.right = e
    a.right = c

    # Pick two distinct nodes that exist in the tree
    print(highest_common_ancestor(a, b, d).val)          # => 'a'
    print(highest_common_ancestor(a, d, e)).val          # => 'aa'

    # A node that is not in the tree:
    x = Node('x')
    print(highest_common_ancestor(a, b, x))              # => None
```

### Complexity breakdown

| Step | Time | Space |
|------|------|-------|
| `contains` for each node | `O(N)` (each traversal visits every node once) | `O(H)` recursion depth |
| `highest_common_ancestor` | — | — |
| **Total** | `O(N)` (both nodes, worst‑case) | `O(H)` worst‑case |

> **Remark** – If you are merely *looking for a sub‑tree that contains both nodes and want the “closest” former parent that still contains them both (i.e. the usual LCA), then you would use a different algorithm that traverses once in `O(N)` (the classic LCA algorithm).

This tiny routine thus demonstrates exactly how trivial the “highest common ancestor” is in a simple, connected binary tree.
