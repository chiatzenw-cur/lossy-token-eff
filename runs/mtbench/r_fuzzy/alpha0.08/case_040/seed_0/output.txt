Because dividing by 10 leaves a remainder of 4, we have

\[
n \equiv 4 \pmod{10}\qquad(n=10k+4\text{ for some integer }k).
\]

Now double the number:

\[
2n = 2(10k+4)=20k+8.
\]

We want the remainder when \(2n\) is divided by 4, i.e. \(2n \pmod{4}\).

- \(20k\) is a multiple of \(4\), so \(20k \equiv 0 \pmod{4}\).
- \(8\) is also a multiple of \(4\), so \(8 \equiv 0 \pmod{4}\).

Therefore the whole expression is

\[
2n \equiv 0 + 0 \equiv 0 \pmod{4}.
\]

So the remainder when twice the number is divided by 4 is **0**.
