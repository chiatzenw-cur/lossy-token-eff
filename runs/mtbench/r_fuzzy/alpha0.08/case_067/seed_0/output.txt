A *full* (or *proper*) binary tree is one in which every internal vertex has **exactly two** children.  
A very useful property of such trees is that the number of vertices is always odd:

| internal nodes | leaf nodes | total vertices |
|-----------------|------------|----------------|
| 0               | 1          | 1              |
| 1               | 2          | 3              |
| 2               | 3          | 5              |
| …               | …          | …              |

If the tree has `k` internal nodes it has `k+1` total leaves, so the total number of vertices is  

```
1 (root) + 2*k = 2*k + 1
```

Hence

```
B_n = 0  if n even
B_{2k+1} = C_k          (k = 0,1,2,…)
```

where `C_k` is the `k`‑th **Catalan number**.  
Catalan numbers count many combinatorial objects – binary recursions, Dyck paths, etc.  
They can be computed in either of the following ways:

```text
C_0 = 1
C_{k+1} = Σ_{i=0}^{k} C_i * C_{k-i}                     (Catalan recurrence)

or, in closed form
C_k = (1/(k+1)) * binom(2k k)        (using binomial coefficients)
```

Python’s arbitrary‑precision integers and the standard library’s `math.comb` allow us to evaluate that closed form instantly, even for very large `k`.  
(Below we also show a DP version that works in O(k²) time, which can be handy if you’re not ready to trust binomial‑coefficient math.)

--------------------------------------------------------------------

## Python implementation

```python
import math

def B(n):
    """
    Return the number of full binary trees that contain exactly `n` vertices.

    The function implements the relation:
        - B_n = 0          for even n
        - B_{2k+1}  = C_k  where C_k is the k‑th Catalan number

    Parameters
    ----------
    n : int
        Number of vertices in the tree (must be a non‑negative integer).

    Returns
    -------
    int
        Number of full binary trees with n vertices.  For n == 0 the
        empty tree is not counted (return 1 only for nodes ≥ 1, but
        you can adjust this if you prefer the empty tree).
    Notes
    -----
    The result can be astronomically large; Python automatically handles
    arbitrarily large integers.
    """
    if n <= 0:
        # By convention we do NOT count the empty tree:
        # (If you want to count it, return 1 when n == 0).  Choose what you need.
        return 0

    if n % 2 == 0:          # Even number of vertices → impossible
        return 0

    k = (n - 1) // 2        # Number of internal nodes
    base = math.comb(2 * k, k)   # binomial coefficient (2k choose k)
    return base // (k + 1)       # divide by (k+1) to get the Catalan number
```

### DP version (less efficient but fine for small `k`s)

```python
def B_dp(n):
    """
    Same semantics as B but uses a bottom‑up DP to compute Catalan numbers.
    Complexity: O(k^2) where k = (n-1)//2   (k≤~5000 for 10⁷ sized n)
    """
    if n <= 0:
        return 0
    if n % 2 == 0:            # impossible
        return 0

    k = (n - 1) // 2
    catalan = [0] * (k + 1)
    catalan[0] = 1
    for i in range(1, k + 1):
        total = 0
        for j in range(i):
            total += catalan[j] * catalan[i - 1 - j]
        catalan[i] = total
    return catalan[k]
```

## Why this works – short mathematical proof

1. **Vertices must have 0 or 2 children** → every internal vertex contributes 2 children, so total leaf count `L = I + 1` where `I` is number of internal nodes.  
   Total vertices `V = I + L = 2I + 1`, an odd number.

2. **Number of full binary trees with `k` internal nodes** is the `k`‑th Catalan number `C_k`.  
   This is a classical result, proved for instance by constructing the tree recursively:  
   Pick a size `i` for the left segment (`0 ≤ i ≤ k-1`).  
   Then left subtree has `i` internal nodes (Catalan `C_i` possibilities) and right subtree has `k-1-i` internal nodes (`C_{k-1-i}` possibilities).  
   Multiplying and summing over all `i` gives the recurrence \(C_k =
   \sum_{i=0}^{k-1} C_i C_k-i-1\) that indeed counts the trees.

3. Substitute the relation \(n = 2k+1\) into the above gives  
   \(B_{2k+1} = C_k\) and \(B_n = 0\) for even `n`.  

Thus `B` indeed returns the number of full binary trees with exactly `n` vertices.

## How to use it in practice

```python
# Number of full binary trees with 13 vertices
print(B(13))
# → 132
```

Because the result can grow extremely fast (for `n = 101` we get
`B(101)=C_50≈2.5×10^28`), always keep an eye on the size of `n`
and guard against runaway memory/time consumption for very large values.
