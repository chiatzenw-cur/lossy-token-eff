Ok.<|end|><|start|>assistant<|channel|>final<|message|>**Boyer‑Moore Majority Vote Algorithm**  
The idea: keep a running “candidate” and a counter.  
While scanning the array we increase the counter when the current
element equals the candidate, and decrease it otherwise.  
When the counter drops to zero we choose the current element as the new
candidate.  
At the end the candidate is guaranteed to be the majority element
(if one exists and we’re told that it does), because every time we
decrease the counter we pair that element with a different one that
cancels it out.

## Function (Python)

```python
def majority_of_array(nums):
    """
    Return the majority element of an integer array using
    the Boyer–Moore Voting Algorithm.  Assumes that a majority
    element (appearing > n//2 times) exists.  For robustness
    an optional validation step is included.

    Parameters
    ----------
    nums : list[int]
        The list of integers to examine.

    Returns
    -------
    int
        The largest element that occurs more than n/2 times.
        If the input is empty, returns None.

    Raises
    ------
    ValueError
        If the input is empty or if no majority found.
    """
def majority_of_array(nums):
    if not nums:
        return None           # or raise ValueError("Empty list")

    # Phase 1 – find a candidate
    candidate = None
    count = 0
    for x in nums:
        if count == 0:
            candidate = x
            count = 1
        elif x == candidate:
            count += 1
        else:
            count -= 1

    # Optional Phase 2 – verify it really is a majority
    # (O(n) additional work, still O(1) extra space)
    if nums.count(candidate) > len(nums) // 2:
        return candidate

    raise ValueError("No majority element found")
```

## How it works

| Phase | What happens | Why it works |
|-------|--------------|--------------|
| 1. **Finding a candidate** | We maintain `candidate` (current guess) and `count` (balance). <br>When we hit a new element:  <br>• If `count == 0` → start a new candidate. <br>• If element equals candidate → increment count. <br>• Else ← decrement count. | Every time we pair a majority element with a different element the count goes down. Because the majority element appears more than half the time, it can never be fully cancelled out. Thus when the loop ends, the candidate left must be the majority. |
| 2. **(Optional) Verification** | Count how many times the candidate actually appears. | Some problem statements guarantee a minority exists, some do not, so it’s good to be safe.  The extra pass is still O(n).

### Complexity

| Time | Space |
|------|-------|
| O(n)  | O(1)  |
