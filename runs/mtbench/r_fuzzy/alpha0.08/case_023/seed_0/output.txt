> “Highest” in a binary tree simply means *closest to the root* (the very
> topmost ancestor).  
>  
> The only node that is higher than everyone else is the root itself,
> so the answer is always the root of the tree, **provided that both
> target nodes appear somewhere in the tree**.  
>  
> If any of the two nodes is **not** in the tree, the common
> ancestor does **not** exist.

Hence the whole problem reduces to

```text
return root if (root, a, b are all in the same tree)
// otherwise return None
```

Below is a practical implementation that
* checks whether both nodes are present in the tree,
* returns that root, or
* raises an error if one of the nodes is absent.

```python
# ------------------------------------------------------------
#  Binary‑tree node, simple definition
# ------------------------------------------------------------
class Node:
    """Tree node storing a unique value."""
    __slots__ = ("val", "left", "right")

    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None

    def __repr__(self):
        return f"Node({self.val!r})"   # <-- useful printing
```

```python
# ------------------------------------------------------------
#  Utilities – build helpers
# ------------------------------------------------------------
def insert(root: Node, val):
    """Insert ``val`` in a BST – used for creating test trees."""
    if root is None:
        return Node(val)
    if val < root.val:
        root.left = insert(root.left, val)
    else:
        root.right = insert(root.right, val)
    return root

def contains(root: Node, target: Node) -> bool:
    """Return True iff ``target`` is reachable from ``root``."""
    if root is None:                # nothing left to search
        return False
    if root is target:              # found exact reference
        return True
    # search both sub‑trees – nothing guarantees a parent‑child
    # ordering that allows us to prune
    return contains(root.left, target) or contains(root.right, target)
```

```python
# ------------------------------------------------------------
#  The “Highest Common Ancestor” function (lowest‑common‑ancestor
#  is more typical – but with the understanding that *highest* = root)
# ------------------------------------------------------------
def highest_common_ancestor(root: Node, a: Node, b: Node) -> Node | None:
    """
    Return the highest common ancestor that is an ancestor of **both**
    ``a`` and ``b`` *if they both exist in the tree*;
    otherwise return ``None``.
    """
    if root is None:
        return None

    # quick guard – if either node is missing we cannot have a shared ancestor
    if not contains(root, a) or not contains(root, b):
        return None

    # Since the root is common to **all** nodes in the tree, it can only
    # be “higher” because nothing lies above it.
    return root
```

```python
# ------------------------------------------------------------
#  Example usage / simple tests
# ------------------------------------------------------------
if __name__ == "__main__":

    #  Build a sample BST  (any binary tree would do)
    #            8
    #          /   \
    #         3     10
    #        /  \      \
    #       1    6      14
    #           / \    /
    #          4   7  13
    #
    root = None
    for val in [8,3,10,1,6,14,4,7,13]:
        root = insert(root, val)

    # Find node references for 4 and 13
    nodes = {}
    def traverse_and_store(node):
        if node is None:
            return
        nodes[node.val] = node
        traverse_and_store(node.left)
        traverse_and_store(node.right)

    traverse_and_store(root)

    a, b = nodes[4], nodes[13]
    ancestor = highest_common_ancestor(root, a, b)

    print(f"Highest common ancestor of {a.val} and {b.val}:", ancestor.val if ancestor else None)
    # Expected output: 8 (root of the whole tree)

    # Try with an absent node:
    fake = Node(99)   # not in the tree
    print(highest_common_ancestor(root, a, fake))  # None
```

### Why the answer is always the root

In any **connected** binary tree (i.e., assuming no isolated sub‑trees):

1. The **root** is an ancestor of **every** node.
2. Every other node has the root as one of its ancestors.
3. Thus the set of nodes common to two distinct nodes is the *entire*
   ancestor chain of their lowest common ancestor (LCA).

The “highest” node in this chain is the **root**.
If the two queried nodes belong to **different** trees (connected
components), no common ancestor exists.

### Complexity analysis

*Checking presence* – `contains()` visits each node at most once:   
`O(n)` time, `O(h)` recursion stack (worst‑case `h = n`).

The final `return root` is `O(1)`.

Space usage per call is `O(h)` due to recursion.

But the **essential** computation—returning the root—runs in constant time
once the check passes.

---

**Bottom line**:  
`highest_common_ancestor` = root (provided both nodes exist in the tree).  
If you were actually after the *lowest* common ancestor, switch to the
standard recursive algorithm shown in the first section.
