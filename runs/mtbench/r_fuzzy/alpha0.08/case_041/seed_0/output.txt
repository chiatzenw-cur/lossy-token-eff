```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Random Joke Generator</title>
    <style>
        body{
            font-family: "Arial",sans-serif;
            display:flex;flex-direction:column;align-items:center;justify-content:center;
            height:100vh;margin:0;background:#f7f7f7;

        }
    </style>
</head>
<body>

    <h1>Press the button for a joke!</h1>
    <button id="btn">Tell me a joke</button>

    <p>
        <strong id="joke"></strong>
    </p>

    <script>
        // 1. A tiny list of jokes
        const jokes = [
            "Why don’t scientists trust atoms? Because they make up everything!",
            "I told my wife she was drawing her eyebrows too high. She looked surprised.",
            "Why did the scarecrow win an award? Because he was outstanding in his field!",
            "I’m reading a book. It’s actually a... book. Yeah, it’s a book."
        ];

        // 2. Grab the elements we need
        const btn = document.getElementById('btn');
        const jokeEl = document.getElementById('joke');

        // 3. Helper to get one random joke
        function getRandomJoke() {
            const index = Math.floor(Math.random() * jokes.length);
            return jokes[index];
        }

        // 4. Wire up the button
        btn.addEventListener('click', () => {
            jokeEl.textContent = getRandomJoke();
        });
    </script>
</body>
</html>
```

### How it works

1. **HTML** – Place a `<h1>`, a `<button>` (id `btn`) and a `<p>` with a `strong` tag for the joke text.
2. **CSS** – Simple, centered layout just to make it look tidy. Nothing fancy, but you can tweak it.
3. **JavaScript**  
   * An array `jokes` holds four joke strings.  
   * `getRandomJoke()` picks a random index (from 0 to `jokes.length-1`) and picks that joke.  
   * The `click` listener on the button updates `jokeEl.textContent` with a new random song each time.

Open this file in any modern browser, hit the button, and you’ll see a new joke each time. You can freely extend the list, style the page, or even fetch jokes from an API instead of hard‑coding them. Happy coding!
