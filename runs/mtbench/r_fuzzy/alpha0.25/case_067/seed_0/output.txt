Every internal node has **exactly two children**.  If a tree has `n` vertices  

* `n` must be **odd** because a full binary tree with `m` internal nodes produces  
  \(n = 2m + 1\) vertices (each internal node gives two children, leaves = internal + 1).  
* The number of full binary trees with `m` internal nodes is a Catalan number

\[
C_m=\frac{1}{m+1}\binom{2m}{m}
          = \frac{2m!}{(2m+1)!}\,.
\]

Hence  

\[
C_{(n-1)/2} = 
\begin{cases}
0 & \text{if } n\text{ is even},\\[4pt]
\dfrac{(n-1)}{2}\text{th Catalan number} & 
\text{if } n\text{ is odd}.
\end{cases}
\]

Below we use Python (because it has built‑in arbitrary‑precision integers) so we can
compute very large `n` (e.g. 1,000,000) without overflow.  
The implementation offers two helpers:

* `binomial(2m, m)` – a fast multiplicative routine.  
* `catalan(m)` – returns the m‑th Catalan number.  

The public `full_binary_trees(n)` function simply puts the above together
and returns `0` if `n` is even, otherwise `C_{(n-1)/2}`.

```python
#!/usr/bin/env python3
"""
Seven‑line function to count the number of full binary trees with *n* vertices.

A full binary tree (also called “proper” or “strict”) has every internal node either
0 or 2 children.  Therefore we have

      n = 2*m + 1
   →   m = (n-1)/2              (number of internal nodes)

The count of such trees is the nth Catalan number:
      C_m = (1/(m+1)) * binom(2m, m)

If *n* is even, the answer is ``0`` because an even total vertex count is impossible.
"""

from math import prod
from typing import Any

def binomial_two_m_choose_m(m: int) -> int:
    """
    Compute   C(2m, m)   (= (2m choose m))  efficiently.
    Uses a multiplicative formula:
          C(2m, m) = product_{k=2}^{m} (m + k) / k
    All intermediate i are integers.
    """
    return prod((m + k) // k for k in range(m, 0, -1))

def catalan_number(m: int) -> int:
    """
    Return the m‑th Catalan number:
          C_m = (1/(m+1)) * binom(2m, m)
    """
    if m < 0:
        return 0
    # If m==0 -> C_0 = 1 (empty tree)
    return binomial_two_m_choose_m(m) // (m+1)

def full_binary_trees(n: int) -> int:
    """
    Count the number of full binary trees with exactly *n* vertices.
    
    Parameters
    ----------
    n : int
        Total number of vertices (nodes + leaves).

    Returns
    -------
    int
        The number of full binary trees with n vertices.
        Zero when n is even.
    """

        return 0
    if n % 2 == 0:
        return 0
    m = (n - 1) // 2
    return catalan_number(m)
```
