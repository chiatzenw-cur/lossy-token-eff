## What the script does (in a nutshell)

| Step | Action | Notes |
|------|--------|-------|
| 1 | **Recursively search** from `directory` for anything starting with `*.txt`. | Uses `pathlib.Path.rglob` which deals with symlinks. |
| 2 | **Stream read** each file line‑by‑line, converting to lower‑case ASCII‑compatible punctuation‑free tokens. | Any non‑letter/non‑number is considered a delimiter, all else treated as part of an alphanumeric token. |
| 3 | **Add tokens to an instance of `collections.Counter`**. | Uses `Counter.update()` so that the operation is memory‑efficient. |
| 4 | **Print the top‐k ordered by frequency**. | `most_common(k)` is provided directly by `Counter`. |

### Common pitfalls & how to avoid them

| Problem | Fix |
|---------|-----|
| **Large files** (`4GB`~) might throw a memory error. | The `with fp.open('r', encoding='utf-8', errors='ignore')` reads *streamingly* – the script never allocates the whole file in memory. |
| **Encoding errors** (`cp1252`, `latin1`, …). | `open(..., errors='ignore')` will silently drop non‑octet characters; you can supply a custom exception handler or replace with `errors='replace'`. |
| **Non‑ASCII characters** will be removed, with `re.sub(r"[^A-Za-z0-9_]+", " ", …)`. | If you want to keep Unicode other fields, replace `re` with a suitable Unicode-aware regex. |
| **You want a truly case‑insensitive mode** (makes `Word` adjust to `"word"` entirely). | Change the default of `ignore_case` to `True` and adjust all downstream logic (the already‑lower‑casing function drops that). |

## Extending the function

If you just want to **pull the top five words** into a `Counter` and return it for a script, just keep the `count_words_in_files()` function but call:

```python
>>> _counter = count_words_in_files(list_of_name_of_files)
>>> top5 = _counter.most_common(5)
>>> print(top5)
[('the', 539567), ('and', 388271), ('this', 256751), ('that', 245312)
```

The function can be called from another script, or from another command line using `python -m top_words` or a Jupyter notebook for analytics.
