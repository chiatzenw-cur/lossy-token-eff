## 1. Why Boyer‑Moore?

**Boyer‑Moore** is a linear‑time, constant‑space‑usage algorithm that works in *one pass*:

1. **Candidate Selection** – While scanning, look at *pairs* of distinct elements.  
   * If the current element is the same as the candidate, increase the candidate’s “vote”.  
   * If it's different, decrease the vote.  
   * When the vote drops to zero, replace the candidate by the current element and reset the vote counter.

2. **Verification** – After that pass, the candidate is *potentially* the majority, but the array can contain no majority at all.  
   The second pass simply counts the candidate’s occurrences to confirm that it actually beats `n/2`.

> **NOTE**  
> The optimal version guarantees that the remaining array *must* contain a majority element.  
> If the array is guaranteed to contain a majority, the second pass alone is optional.  
> All we’ll ask for is “return the element that appears more than half the time,” the program will ignore non‑majority inputs.

## 2. Python Implementation

```python
def majority_element(nums):
    """
    Return the majority element (appearing more than n/2 times) if it exists,
    otherwise -1.
    
    Algorithm: Boyer–Moore Voting
    Time: O(n), Space: O(1)
    """
    # ---------- 1️⃣ Candidate Selection ----------
    candidate = None
    if not nums:
        return -1                     # empty list – no majority
    count = 0

    # Single pass to pick a candidate
    for num in nums:
        if count == 0:
            candidate = num
            count = 1
        elif num == candidate:
            count += 1
        else:
            count = 0

    # ---------- 2️⃣ Verification ----------
    # Count the candidate's occurrences; it must be ≥ n//2 + 1
    if nums.count(candidate) > len(nums) // 2:
        return candidate

    return -1   # not found
```

## 3. JavaScript Implementation

```javascript
/**
 * Returns the majority element found in an array.
 * @param {number[]} arr - Input array of integers.
 * @returns {number|null} the majority element or null otherwise.
 */
function majorityElement(arr) {
    if (!Array.isInteger || arr.length === 0) return null;

    // 1️⃣ Candidate Selection
    const n = arr.length;
    let candidate = null, count = 0;

    for (let i = 0; i < n; i++) {
        if (count === 0) {
            candidate = arr[i];
            count = 1;
        } else if (arr[i] === candidate) {
            count++;
        } else {
            count--;
        }
    }

    // 2️⃣ Verify the candidate
    let freq = 0;
    for (const v of arr) { if (v === candidate) freq++; }

    return freq < Math.floor(n / 2) + 1 ? null : candidate;
}
```
