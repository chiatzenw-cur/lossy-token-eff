We’ll use a recursive depth‑first search that returns the **closest** common ancestor of the two nodes, i.e. the lowest node that can reach both targets.

### Why recursion works

If we call `hca(root, p1, p2)` in a node and the node is `None` we return `null`.  
Otherwise we either:

1. **Both left sub‑tree and right sub‑tree contain one node each** – That is the first node whose left and right sub‑trees contain the two targets, so by definition it is the LCA.  
2. **Only one side contains** – The ancestor that that side found is its ancestor all the way to the root; we bubble it back.  
3. **The node itself is one of the targets** – This node also satisfies the definition above and therefore returns.

### Bottom line

The classic algorithm for finding the *Lowest Common Ancestor* (what most people want when called “the highest common ancestor” in the sense of “lowest to the root”) is:

1. Recurse down to the two target nodes.
2. As you unwind, each node that returns knowledge of one of the targets propagates upward until it hits a node that sees two different targets – that node is the LCA.
3. Detect and return the LCA immediately.

That's why the recursive approach for a binary tree is so elegant, what Python (and many other languages) consider the “official” way to compute LCA.
