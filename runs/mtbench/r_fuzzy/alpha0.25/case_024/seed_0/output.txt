### Python example

```python
def common_elements(a, b):
    """Print common elements of a and b; no extra data structures."""
    for x in a:
        for y in b:
            if x == y:
                print(x, end=' ')
                break  # stop searching b
    print()

# ---- example ----
if __name__ == "__main__":

    common_elements(a, b)
```
