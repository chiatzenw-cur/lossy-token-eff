## 1. The Core Idea  
**Probability** is a number between **0 and 1** that represents one of three things:

1. **0** – The event can’t happen (e.g., rolling a 7 on a standard die).  
2. **1** – The event will definitely happen (e.g., drawing the Ace card from a single‑card deck).  
3. 0 < p < 1 – The event happens sometimes; the bigger the p, the more likely it is.

---

## 2. Basic Probabilities  

### 2.1. **Classical Probability**  
If every outcome is equally likely, the probability of an event is:

\[
\text{Probability} = \frac{\text{Number of favorable outcomes}}{\text{Total number of possible outcomes}}
\]

#### Example: Rolling a die  
Now the ball shows 1–6, all equally likely.

- “Roll a 4”  
  \[
  P(\text{3rd face}) = \frac{1}{6} \approx 0.1667
  \]

- “Which are logical numbers?” (Odd numbers):  
  \[
  P(\text{odd}) = \frac{3}{6} = \frac{1}{2}\;(50\%)
  \]

#### Ratio fishing to percent (optional)

| **Fraction** | **Decimal** | **%** |
|--------------|-------------|-------|
| 1/2   | 0.5 | 50 % |
| 3/7   | 0.428 | 42.8 % |
| 4/6   | 0.667 | 66.7 % |

### 2.2. **Counting (Combinatorics)**  
When you want **"how many different ways"** something can happen, you don’t use fractions 1/6, you get.

#### Example 1:   Pick a 2‑chocolate‑bar gift set  
You have 4 chocolate bars from different brands. Total ways to pick 2 bars (order doesn’t matter):

\[
\text{Number of combinations} = \binom{4}{2}
= \frac{4!}{2! - 4 + 2!} = 6
\]

Total outcomes for 2 bars: combinations = 6.  
If you can’t pick the same brand twice, each can have 4 choices.  
If they are all distinct, \(4! = 24\) ways to *order* the bars.

### Example 2:  Probability of passing a test  

- You have 4 quizzes: 4 questions each, 2 correct needed.  
- How many distinct sequences? (It’s an **ordered** question‑answer sequence).  
- But for “at least 2 correct”, the answer is \(P_{\ge 2}\) = probability of 2, 3, 4, or 5 correct automatically.

## 3. **Key Rules**  
1. **Disjoint (Mutually exclusive) events** – cannot happen at the same time.  
   \[
   P(A + B) = P(A) + P(B) \tag{Additivity}
   \]
2. **Dependent events** (occurrence of one increases chance) – use *conditional probability*:
   \[
   P(\text{win | deal}) = \frac{P(\text{win and deal})}{\text{Deal total}}
   \]
3. **Complement rule**  
   \(P(S \oplus \text{not S}) = 1\)  →  \(P(S) = 1 - P(\text{not S})\)
4. **Multiplication Rule** for independent events:  
   \[
   P(A\ \text{and} \ B)=P(A)\times P(B)
   \]

## 4. Step‑by‑Step Example: Crazy Card Draw  

```
Write to computer clubroom:

Suppose we have 4 suits: hearts, diamonds, clubs, spades.  
A deck has 52 cards; we choose a single card.  

Goal: Show a Queen.  
```

- **Favourable**  
  4 suits × 1 queen each = 4 favourable outcomes.

- **All**  
  52 cards.

- **Probability**  
  \(P(\text{queen}) = \frac{4}{52} = \frac{1}{13}\).

Increase think number by subtracting a card as a random Y.

### What if you already have *Ace of Spades*?  

- The deck now has 51 cards.  
- If you somehow lose the Ace of Spades, the chance of drawing a queen is still 4 / 52?    
  No — because you’ve removed one card from the total.  
  \[
  P(\text{queen \| not Ace of spades}) = \frac{4}{51} = 0.0784
  \]

## 6. Everyday Misinterpretations

| Misinterpretation | Reality | Why it’s wrong |
|-------------------|---------|----------------|
| Guessing a 3‑-of‑6 won random chance | Understand *conditional* | Lose independence from past events |
| “I can’t bet on a spin of a wheel” | Only if you accept long‑term vs. short‑term | Exponential tails of fortune |
| “Prove it is 100% I’ll win on a jackpot” | Out of 5‑month intervals | Highest probability results being 0 |
