The “highest common ancestor” is simply the *topmost* (empty‑| deepest‑? non‑root) node that lies on the paths from the root to both of the target nodes.  
To obtain it we:

1. Find the list of nodes on the path from the **root** to each of the two targets.
2. Walk the two paths together, starting at the root.
3. The first node that is not the same in both lists is the point where the two paths diverge.  
   The **previous node** (the last matching one) is the *highest* common ancestor.

Because every node in a binary tree is guaranteed to have exactly one path from the root, this is unique.

---

### Python implementation

```python
class Node:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left  = left
        self.right = right

def _path_from_root(root, target):
    """
    Return the list of nodes from root to target nodes.
    If no path exists, return an empty array.
    """
    if root is None:
        return []

    path = []
    def dfs(node):
        if node is None:
            return False
        path.append(node)
        if node is target:
            return True
        if dfs(node.left) or dfs(node.right):
            return True
        # backtrack
        path.pop()
        return False

    dfs(root)
    return path

def highest_common_ancestor(root, node1, node2):
    """
    Return the highest common ancestor of `node1` and `node2`
    (not the LCA).  Assumes the two nodes are distinct and
    present in the tree.  
    Complexity: O(n) time, O(h) additional space
    """
    path1 = _path_from_root(root, node1)
    path2 = _path_from_root(root, node2)

    if not path1 or not path2:
        return None          # one of the nodes not in the tree

    # Walk the paths together until they diverge
    i = 0
    while i < len(path1) and i < len(path2) and path1[i] is path2[i]:
        i += 1
    # Find the last similar node (hence the highest common ancestor)
    if i == 0:               # No source common ancestor found
        return None
    return path1[i-1]        # or path2[i-1]
```

#### Usage example

```python
# Build a simple tree.
#         a
#        / \
#       b   c
#      / \
#     d   e
root = Node('a')
root.left  = Node('b')
root.right = Node('c')
root.left.left  = Node('d')
root.left.right = Node('e')

# We know the highest common ancestor of d and e is b
b = root.left
d = root.left.left
e = root.left.right
print(highest_common_ancestor(root, d, e).val)   # prints 'b'
```

---

### Why “maximum depth” is not appropriate

The *lowest common ancestor* (LCA) is the deepest key node that is also an ancestor of both targets.  
The “highest” common ancestor is the opposite: it's the **lowest depth** common node (closest to the root).  
If we only care about the root as the answer, the above algorithm could be automated by simply avoiding the *search to the deepest node* and stopping as soon as the two paths begin to diverge – the longest common prefix of the two paths.

---

### Complexity

*Time* : `O(n)` – each node is visited at most twice (once in each path).  
*Extra space* : `O(h)` – the height of the tree for recursive stack usage and explicit path references.

---

### Variants

* If the tree nodes already have `parent` pointers, walking the two parent lists gradually and comparing parts will yield the same result.
* The axiom that *the root is always a common ancestor* means that the algorithm degenerates to <code>root</code> for most cases when one node is an ancestor of the other. This is correct; you only obtain a *higher* common ancestor if the two paths diverge after some node.
