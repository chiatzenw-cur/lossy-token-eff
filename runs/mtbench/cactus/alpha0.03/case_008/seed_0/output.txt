Find the *majority element* – the element that appears more than ⌊n/2⌋ times – in an integer array in linear time and constant extra space.

**Solution: Boyer–Moore voting algorithm**

The algorithm first finds a candidate that could be the majority, then verifies it.  
Only one pass is needed to locate the candidate, and the second pass (optional, if you want to be 100 % sure) only checks it.

All arithmetic is carried out in a linear scan, so the time complexity is O(n) and the extra space is O(1).

---

### 1. Quick insight

If we repeatedly pair different elements and “cancel” a pair, the unpaired element (if we can cancel all further pairs) is the majority element.

---

### 2. The algorithm steps

| Step | Operation | Why it works |
|------|-----------|--------------|
| **1** | Scan the array, keeping **candidate** and **count**. | `candidate` holds the element that might be the winner. |
| **2** | If any element equals | `candidate` → increment `count`. | It reinforces the candidate. |
| **3** | Else decrement `count`. | That element “cancels” a potential candidate. |
| **4** | If `count` reaches 0 → pick the new element as the next candidate. | Reset after a full cancellation. |
| **5** | After the loop, `candidate` is the majority. | If a majority exists, the cancellations will point to it. |
| **6** *(optional)* | Scan **again** to check that `candidate` indeed appears > n/2 times. | If the existence condition is guaranteed, this step can be omitted. |

---

### 3. Python implementation

```python
def majority_element(nums):
    """
    Return the majority element in the list.
    E.g. [2,2,1,1,1,2,2] -> 2
    Times:  O(n), Space: O(1)
    """
    candidate = None
    count = 0

    for num in nums:
        if count == 0:
            candidate = num
            count = 1
        elif num == candidate:
            count += 1
        else:  # num != candidate
            count -= 1

    # Optional verification:
    # if cand not majority, raise error or return None
    # Uncomment if the input may not contain a majority (add safety):

    # if nums.count(candidate) <= len(nums) // 2:
    #     return None
    return candidate
```

#### Example

```python
print(majority_element([2, 2, 1, 1, 1, 2, 2]))   # → 2
print(majority_element([1, 1, 2, 3, 1]))          # → 1
```

---

### 4. Complexity analysis

- **Time**: One full scan → O(n)
- **Space**: Only `candidate` and `count` → O(1)

---

### 5. Edge cases handled

- Array of length 1 → that element is the majority.
- Duplicate scenario → always returns the number that appears more than n/2 times.
- When a majority is guaranteed, the selection step is sufficient; if not, the optional verification can detect “no majority”.

> **Note**:  
> The code above assumes an input where a majority is present.  
> If you need to handle “no majority” safely, uncomment the optional verification part.
