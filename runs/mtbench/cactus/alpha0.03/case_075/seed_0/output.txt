Machine learning (ML) is among the core tools of artificial intelligence that lets computers **learn patterns from data instead of being explicitly programmed**.  
- **Input data** (the *features*) are fed into a model.  
- A **learning algorithm** adjusts internal parameters so that the model’s predictions or decisions match the observed training data.  
- Once the model is found, it can be used to **generalize** to new, unseen inputs.

Mathematically, ML is usually seen as an optimization problem, where we find parameters \(\theta\) that minimize a training loss:

\[
\hat{\theta} = \arg\min_{\theta} \sum_{i=1}^{N} \mathcal{L}(f_\theta(x_i), y_i)
\]

Here \(f_\theta\) is the model, \(x_i\) a data point, \(y_i\) its label (if available), and \(\mathcal{L}\) a loss function.

### 2. Three Families of Learning

| Type | Primary Goal | Label Availability | Typical Learning Signal | Representative Algorithms |
|------|--------------|-------------------|--------------------------|----------------------------|
| **Supervised** | Predict a output (often a class or numeric value) from an input ratio | **Yes** – labelled data (input + correct output) | Ground-truth output – “teacher” signal | Logistic Regression, SVM, Decision Trees, Random Forest (for tabular) <br>CNN, RNN, Transformer (for images, text, time‑series) |
| **Unsupervised** | Discover structure or hidden patterns inside the data, no explicit output needed | **No** – only input data | Distribution of data, similarity relations | K‑means, hierarchical clustering, DBSCAN (clustering), PCA, t‑SNE, Autoencoders, GANs (generative) |
| **Reinforcement** | Learn a policy (action‑selection rule) to maximize cumulative reward through trial‑and‑error in an environment | **No** – only (state, action, reward) tuples received during interaction | Reward feedback signal (scalar) w.r.t. chosen actions | Q‑learning, SARSA, Policy Gradient (REINFORCE), Actor‑Critic (A3C, DDPG), PPO, DQN, AlphaZero |

### 3. How They Distinguish

| Feature | Supervised | Unsupervised | Reinforcement |
|--------|------------|--------------|---------------|
| **Objective** | “Map inputs → output” | “Find hidden structure” | “Discover optimal actions” |
| **Typical Tasks** | Classification, regression, detection | Clustering, dimensionality reduction, density estimation | Game playing, driving, robotics, recommendation via bandits |
| **Data Format** | Paired examples \((x, y)\) | Solely parameter (x) | (state, action, reward). No explicit mapping of states to actions or labels to states. |
| **Feedback** | Randomized training signal (you output them) | Immutable signal (you can only compute correlations) | Delayed/ cumulative reward (exploration–exploitation balance). |
| **Learning Type** | Generalization | Pattern discovery | Decision‑making under uncertainty |

### 5. A Quick Start For Each

**Supervised**  
1. Load labelled dataset.  
2. Split into train/validation/test.  
3. Train a classifier (e.g., logistic regression).  
4. Evaluate on test set.  
5. Fine‑tune & deploy.  

**Unsupervised**  
1. Load unlabelled data.  
2. Reduce dimensionality (PCA or autoencoder).  
3. Cluster (k‑means) on sufficiently many dimensions.  
4. Inspect fine‑tunes.  

**Reinforcement**  
1. **Define an environment** (states, actions, reward).  
2. Choose a reinforcement learner (e.g., DQN).  
3. Run episodic training loops.  
4. Evaluate cumulative reward.  
5. Deploy as an agent or autonomous controller.  

---

### 6. Take‑away

- **Supervised learning** is the “map‑making” teaching discipline where the model is taught by explicit examples.  
- **Unsupervised learning** is the “exploration” discipline that lets the model discover hidden structure without explicit instruction.  
- **Reinforcement learning** is the “decision‑making” discipline where the model learns by playing beneficial actions in an environment and receiving a signal to hint at how well you did.

Choosing the right paradigm depends on whether you have labeled data, need to understand underlying patterns, or are building an agent that must act in interactions. Each often dovetails with a deep‑learning infrastructure, but many classic algorithms work in purely classical machine‑learning settings.
