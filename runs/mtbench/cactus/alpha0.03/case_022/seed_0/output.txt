#include <iostream>

/* ------------------------------------------------------------
 *  Recursive Fibonacci routine.
 *  - For n <= 0 the function returns 0 (by convention).
 *  - For n == 1 returns 1.

int fib(int n)
{
    if (n <= 0) {
        return 0;      // 0-th Fibonacci number is 0
    }
    if (n == 1) {
        return 1;      // 1st Fibonacci number is 1
    }
    return fib(n - 1) + fib(n - 2);
}

/**
 *  Main: reads an integer n, computes fib(n),
 *  and prints the result.
 */
int main()
{
    std::cout << "Enter the index (n) of the Fibonacci number to compute: ";

    if (!(std::cin >> n)) {
        std::cerr << "Error: invalid input.\n";
        return 1;
    }

    if (n < 0) {
        std::cerr << "Please enter a non‑negative integer.\n";
        return 1;
    }

    int result = fib(n);
    std::cout << "Fib(" << n << ") = " << result << '\n';

    return 0;
}

### How it works

1. **Recursion**  
   `fib(n)` splits the problem into two smaller sub‑problems:  
   `fib(n‑1)` and `fib(n‑2)`, adding their result until it reaches the
   base cases `n <= 0` (return 0) and `n == 1` (return 1).

2. **Handling input**  
   The `main()` function reads an integer from standard input and
   guards against badly formatted input or a negative number.

3. **Complexity**  
   The naïve recursion explores all binary tree paths of depth `n` and
   therefore runs in `O(2^n)` time and `O(n)` stack space—acceptable for
   small `n` but not for large values.
