Given two sorted arrays `A` and `B` of arbitrary (but different) sizes, we must
output the overall median of the merged sorted array using

* **O(1) auxiliary space** (apart from a handful of variables)  
* **Θ(n)** time – where *n* is the total number of elements (`len(A)+len(B)`)

Because the two input arrays are already sorted, we can walk through them in a
single pass (much like the “merge” step of merge‑sort).  
While walking, we keep the index of the “current value” in the two‑array
merge.  Once we hit the middle case(s), we stop – we never need to build a
merged array or keep all of its elements.

## Algorithm

```
Let m = len(A), n = len(B)
total     = m + n
midIndex  = total // 2          // 0‑based index of the first middle element
isEven    = (total % 2 == 0)

i, j      = 0, 0                // start pointers for A and B
cnt       = 0                   // number of elements processed so far
prevM     = 0                   // value of the element just before midIndex
midValue  = 0                   // value of the element at midIndex

while i < m OR j < n:
    // pick the next smallest element counting from the two arrays
    if i < m AND (j >= n OR A[i] <= B[j]):
        cur = A[i]
        i += 1
    else:
        cur = B[j]
        j += 1

    if cnt == midIndex - 1          // step before the desired middle
        prevM = cur
    if cnt == midIndex              // the desired middle element
        midValue = cur
        break

    cnt += 1

if isEven:
    return (prevM + midValue) / 2.0
else:
    return float(midValue)
```

**Why it works**

* linear loops with a constant number of variables – **O(1) space**  
* each array element is examined at most once – **O(total)** time  
* we stop as soon as we know the middle element(s) – no unnecessary work

## Python Implementation

```python
from typing import List

def find_median_sorted_arrays(A: List[int], B: List[int]) -> float:
    """
    Return the median of two sorted integer arrays.
    The function uses O(1) extra space and O(len(A)+len(B)) time.
    """
    m, n = len(A), len(B)
    total = m + n
    mid_index = total // 2             # first middle (0‑based)
    is_even = (total % 2 == 0)

    # 'prev_m' holds the value when the count is mid_index-1 (Empties when absent)
    prev_m, mid_value = 0, 0
    i = j = 0
    cnt = 0

    while i < m or j < n:
        if i < m and (j >= n or A[i] <= B[j]):
            cur = A[i]
            i += 1
        else:
            cur = B[j]
            j += 1

        if cnt == mid_index - 1:
            prev_m = cur
        if cnt == mid_index:
            mid_value = cur
            break

        cnt += 1

    if is_even:
        return (prev_m + mid_value) / 2.0
    else:
        return float(mid_value)

# Example
if __name__ == "__main__":
    A = [1, 3, 8]
    B = [7, 9, 10, 11]
    print(find_median_sorted_arrays(A, B))  # Output: 8.0
```
