The only “full” binary trees are for an odd number of vertices.  
If  

```
n = 2m + 1        (m ≥ 0)
```

then the number of full binary trees with `n` vertices is the Catalan number

```
B(n) = C_m = (1/(m+1)) * binom(2m , m)
```

So a single‑line implementation is

```python
def B(n: int) -> int:
    if n % 2 == 0:      # even number of nodes → impossible
        return 0
    m = (n - 1) // 2
    return math.comb(2*m, m) // (m + 1)
```

### Full code (Python 3)

```python
import math
from functools import lru_cache

# --------------------------------------------------------------------------
# 1. Closed–form;   O(1) time, O(1) memory
# --------------------------------------------------------------------------
def B_closed(n: int) -> int:
    """Return B_n (full binary trees of size n) using the Catalan formula."""
    if n % 2 == 0:                # even number of vertices – impossible
        return 0
    m = (n - 1) // 2
    # binom(2m, m) // (m+1)  (Catalan number C_m)
    return math.comb(2*m, m) // (m + 1)

# --------------------------------------------------------------------------
# 2. Dynamic programming implementation (here for clarity or pedagogic use)
# --------------------------------------------------------------------------
def B_dp(n: int) -> int:
    """Compute B_n by the standard recurrence.  O(n²) time, O(n) space."""
    if n < 0:          # no tree with negative nodes
        return 0
    if n == 0:         # empty tree, defined as a full tree with 0 vertices (even)
        return 1
    B = [0] * (n + 1)
    B[0] = 1           # empty tree
    B[1] = 1           # single node

    for tot in range(2, n + 1):
        total = 0
        # root consumes 1 node; left subtree length k, right length tot-1-k
        for k in range(1, tot, 2):          # k must be odd (full subtrees)
            total += B[k] * B[tot - 1 - k]
        B[tot] = total
    return B[n]

# --------------------------------------------------------------------------
# 3. Unlimited recursion (for demo)
# --------------------------------------------------------------------------
@lru_cache(maxsize=None)
def B_recursive(n: int) -> int:
    """Recursive implementation – no memoisation would be impossible."""
    if n % 2 == 0:
        return 0
    if n == 1:
        return 1
    result = 0
    for k in range(1, n, 2):                     # left subtree has odd number
        result += B_recursive(k) * B_recursive(n - 1 - k)
    return result


# --------------------------------------------------------------------------
# 4. Quick demo / test harness
# --------------------------------------------------------------------------
def simple_test():
    small = list(range(1, 11))          # 1 … 10 vertices
    print("n\tB(n) (fact.)\tB(n) (deduct.)")
    for n in small:
        print(f"{n}\t{B_dp(n)}\t\t{B_closed(n)}")

if __name__ == "__main__":
    simple_test()
```

#### Very small note on the theory

- A *full* binary tree has an odd number of vertices; it contains exactly `m+1` internal nodes and `m` leaves.  
- If `m = (n-1)/2`, the tree can be reduced by contracting each pair `(2 nodes + 1 parent)` to a single node until you have a right–skewed tree that is counted by Catalan numbers `C_m`.  
- The closed form is therefore the same as the count of all binary trees with `m+1` internal nodes (standard Catalan numbers).
