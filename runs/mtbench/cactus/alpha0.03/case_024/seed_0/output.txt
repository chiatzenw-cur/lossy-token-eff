## 2.  Correctness proof

We prove that the algorithm prints **every** element belonging to the
intersection of the two input arrays and that each printed element is
in both arrays.

*Lemma 1* – *If the algorithm prints an element `x`, then `x` is in both
arrays.*

*Proof.*  
The algorithm prints `x` only when  
`a[i] == b[j]`.  In that step `a[i]` is equal to the sum `x` and is taken
from the first array, and in particular `x` is an element of the first
array.  Similarly `b[j]` is an element of the second array; hence
`x` is in both arrays.  ∎



*Lemma 2* – *If an element `x` is present in *both* arrays (at an
unsorted position), the algorithm will print it.*

*Proof.*  
Let `p` be the smallest index such that `a[p] == x`.  
All elements before `p` are smaller than `x` in the first array.
Because `a` and `b` are sorted, all elements of `a` before `p`
are `< x`.  
During the scan, the pointer `i` with `i< p` will stop at some **position
`q`** at which `a[q] >= x`.  
Because `aq == x` and `iq < p`, the algorithm will continue advancing
while `a[i] < b[j]`.  
Symmetrically, the pointer `j` will process the second array
until it reaches an index `t` where `b[t] == x`.  
When both pointers point to an index sufficing
`a[i] == b[j] == x`, the algorithm prints the element and moves both
pointers forward. Therefore the element `x` is printed. ∎

*Theorem* – *The algorithm prints exactly the common elements of the two
arrays.*

*From Lemma&nbsp;1* every printed element is common.  
*From Lemma&nbsp;2* every common element is printed.  Therefore the
output set is exactly the intersection. ∎
