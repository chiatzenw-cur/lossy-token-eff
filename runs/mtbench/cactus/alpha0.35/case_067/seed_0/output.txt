For a *full* binary tree every node has either  

*0 children* (a leaf) **or** **2 children** (an internal node).  
If the tree has `k` internal nodes it has `k+1` leaves.  
With `k` internal nodes or `k+1` leaves the total number of vertices is

```
total vertices = k + (k+1) = 2k + 1
```

So the total number of vertices in a full binary tree is **always odd**.

--------------------------------------------------------------------

### 1.  Relation to the Catalan numbers

For a fixed inter‑connectivity `k` (a fixed number of internal nodes) the
number of *unlabelled* full binary trees is the *Catalan number* `C_k`.

```
C_k = 1/(k+1) * ( 2k choose k )
```

The Catalan numbers start with

```
C0 = 1  (1 leaf)
C1 = 1  (1 internal node + 2 leaves)
C2 = 2  (2 internal nodes + 3 leaves)
C3 = 5  (3 internal nodes + 4 leaves)
```

Thus, for any odd `n` we can simply compute

```
k = (n-1)/2          (the number of internal nodes)
B_n = C_k          (the number of full binary trees with n vertices)
```

If `n` is even or is `0`, `B_n = 0`.

### 2.  Algorithms
We provide two straightforward ways to compute it.

#### 2.1  Set‑up via nested DP (optional, but `n` is modest)

```python
def catalan_by_dp(k):
    """Return the Catalan number C_k using 1‑dimensional DP."""
    C = [1] * (k + 1)
    for m in range(1, k + 1):
        total = 0
        for i in range(m):
            total += C[i] * C[m - 1 - i]
        C[m] = total
    return C[k]
```

#### 2.2  Exact binomial + division

`C_k = (1/(k+1)) * binom(2k, k)` is the fastest and uses only integer arithmetic.

```python
from math import comb

def catalan_by_binom(k: int) -> int:
    """Return the nth Catalan number C_k using the binomial formula."""
    return comb(2 * k, k) // (k + 1)
```

### 3.  Final function `B_n`

The easiest implementation is to read the input `n`, test whether `n`
is odd, compute `k = (n-1)//2`, and return `C_k` (or `B_n = 0` otherwise).

For `n` should be very small (≤ 10⁶) even if we compute the binomial
correctly; for all usual sizes use the integer helper – it handles
large integers just fine.

```python
def full_binary_tree_count(n: int) -> int:
    """
    Return the number of distinct full binary trees with n vertices.
    A full binary tree is one in which every node has either 0 or 2 children.
    Returns
    -------
    int
        Number of full binary trees with n vertices (non‑negative integer).
    """
    if n <= 0 or n % 2 == 0:
        return 0     # no full binary tree has even number of vertices

    # k = number of internal nodes
    k = (n - 1) // 2

    # The number of full binary trees with exactly k internal nodes is
    # the Catalan number C_k.  Use the binomial formula.
    return comb(2 * k, k) // (k + 1)
```

  CPython implementation).
