We have two integer arrays `A` and `B`.  
The task is to print all the elements that appear in **both** arrays.

The approach must avoid extra data structures – i.e. we cannot use a `set`, `dict`, or any other
container besides the two input guarantees.

The most straightforward way is an “O(n²)” scan:

* For every element `a` in `A` test every element `b` in `B`.  
* If `a == b`, then `a` is common to both sequences, so we print it.  
* We stop the second loop when we find a match – it prevents duplicates that appear
  **inside** `A` from being printed more than once, because we only iterate through
  `A` once, printing each value at most once.

If you wish to be careful about repeated values in the *output* even when the arrays
contain duplicates, you will still need an extra memory-like structure
(e.g. a hash set) – but the requirement says “without using any
extra data structures”, so the solution above is justified.

> **Why this works**  
>  *The nested loops test every pair of elements in `A` × `B`.*  
>  After the inner `for` loop (`j`‑loop) goes through `B` there is **at least one** candidate
>  that matched the current `A[i]`.  
>  Because we `break` once a match is in hand, any larger matches will not be repeated
>  within the same call to the `i`‑loop.

### The code

```python
# -------------------------------------------------
# Find common elements in two arrays without any
# external data structures
# -------------------------------------------------

def common_elements(start, end, a, b):
    """
    Prints the numbers that appear in both arrays `a` and `b`.
    The function performs the scanning with two loops,
    but does not use any auxiliary buffers.
    """
    for i in range(start, end):          # process a[start … end-1]
        for j in range(len(b)):
            if a[i] == b[j]:
                print(a[i], end=' ')
                break                    # remove duplicates that appear from the
                                          # scan of the first array

def main():
    # 1. Input numbers of elements in each array (so the user knows)
    n = int(input("Enter the number of elements in the first array: "))
    m = int(input("Enter the number of elements in the second array: "))

    # 2. Read both arrays
    print(f"Enter the {n} numbers for the first array:")
    a = list(map(int, input().split()))
    while len(a) < n:  # if the user may continue on multiple lines
        a.extend(map(int, input().split()))

    print(f"Enter the {m} numbers for the second array:")
    b = list(map(int, input().split()))
    while len(b) < m:
        b.extend(map(int, input().split()))

    # 3. Find common elements
    print("Common elements:")
    common_elements(0, n, a, b)

if __name__ == "__main__":
    main()
```

### How the program works

1. **Input** – The user supplies the two arrays.  
   The function automatically consumes input lines if the program
   receives more than a single line; this keeps the code short and easy to test.

2. **Processing** – The `common_elements` function then performs two nested loops,
   performing the comparison between each element of `A` and every element of `B`.  
   The `break` statement ensures that when we find a match, we print it once
   and stop before the others; the number is checked for each element immediately.

3. **Output** – The common numbers are printed in the order they were found in
   the first array.  
   If the leading array is empty, nothing appears, which is the logic expected.

#### Complexity Analysis

For arrays of length **n** and **m** the inner loops examine `n × m`
complete pairs.  
Even if the arrays are sorted, this simple algorithm still needs
`O(n*m)` comparisons, no auxiliary data structures are used.
