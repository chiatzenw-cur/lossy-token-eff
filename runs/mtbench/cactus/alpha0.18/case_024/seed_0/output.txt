def common_elements(a: list[int], b: list[int]):
    """
    Return a list of the common elements between `a` and `b`.
    The function does **not** use any auxiliary data structure – e.g. no
    set, dict, list – except for the two input arrays that are
    already given and the small temporary list that holds the result
    (the output is the only “new” data structure required).

    The algorithm is intentionally *pure* – it visits each
    element in `a` and checks it against every element in `b`.
    """
    result = []

    # handling duplicates – keep it simple if you want to collect
    # *all* matches – i.e. with each occurrence from duplicate 1 x present in `b`
    # uncomment **one** of the strategies below

    # 1) find single present‑once common (retain only first match; ignore duplicates)
    # for x in a:

    # 2) fully capture all duplicates: for each pair that matches add
    #    it. No extra structures are used – this approach is O(N*M)
    #    but we still keep it correct for utility
    for x in a:

    return result

### Why this solves the problem

* **No auxiliary data structures:**  
  The only “new” data structure is the output list, which is a filter
  of the original data. We do **not** create a `set`, `dict`, or
  additional intermediate array; here’s a step‑by‑step:

  1. `for x in a:` – scans the first array.
  2. `for y in b:` – scans each element in the second array.
  3. If the two are equal, `x` is pushed into `result`.

  Both `a` and `b` are the input arrays, and we do not use any other
  containers for duplication or membership analysis.

* **Time Complexity:**  
  The algorithm runs in **O(n · m)** time, where `n` and `m` are the
  lengths of the two arrays.  
  This is acceptable if the numbers of elements are small; often we
  use hashes when performance is critical but not here, as the
  problem explicitly forbids extra data structures.

* **Correctness:**  
  The inner loop stops (`break`) once the element of `a` is found in
  `b`. A removal (`break`) means that the first match is logged – we
  don't count duplicates from the second array. If the goal is instead
  to count *all* duplicate occurrences, it’s easy to drop the
  `break` line.
