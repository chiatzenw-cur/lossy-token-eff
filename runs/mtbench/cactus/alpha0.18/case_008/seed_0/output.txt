The Boyer–Moore algorithm finds the most frequent element (the *majority* element) in a list in linear time and constant space.  
It works under the idea that a majority element occurs more than *n/2* times, so it can “beat” any other elements when processed pair‑wise.

---

### 1️⃣ Algorithm definition

```text
Input  – integers vector A[0 … n-1]
Output – majority element (might not exist)
```

We maintain two variables:

| Variable | Meaning |
|----------|---------|
| `candidate` | Current candidate for majority |
| `count`     | Count of the candidate’s “survivorship” |

**Step 1 – Find a candidate**  
```
candidate = None
count = 0

for each x in A:
    if count == 0:
        candidate = x          // decision to try new candidate
        count = 1
    else if x == candidate:
        count += 1
    else:
        count -= 1
```
After the loop, `candidate` is some element that *could* be the majority, but we don’t yet had a guarantee
that it appears > n/2 times.  

**Step 2 – Verify**  
If the problem guarantees a majority exists, a second pass is usually omitted.  
When you want to be safe we count the occurrences of the target:

```
freq = count of x in A where x == candidate
if freq > n/2:
    return candidate
else:
    return No majority (or None)
```

Total time O(n) and memory O(1).

### 2️⃣ Python implementation

```python
def majority_element(nums):
    """
    Returns the majority element of ``nums`` if it exists **or**
    returns None if the array has no majority element.
    
    Uses the Boyer–Moore Voting Algorithm.
    
    Args:
        nums (List[int]): int array with at least one element in typical usage.
    
    Returns:
        int | None:  The majority element or None if none exists.
    """
    # 1st pass – find candidate
    candidate = None
    count = 0
    
    for x in nums:
        if count == 0:
            candidate = x
            count = 1
        elif x == candidate:
            count += 1
        else:
            count -= 1
    
    # 2nd pass – verify candidate
    if candidate is not None:
        freq = sum(1 for x in nums if x == candidate)
        return candidate if freq > len(nums) // 2 else None

    return None
```

### 4️⃣ Edge‑case & correctness considerations

| Case | Strategy |
|------|----------|
| **Empty array** | Return `None` (or raise an exception). |
| **All elements equal** | `candidate` will be that element and count will succeed. |
| **No majority (all but one element)** | guarantee matches `freq > n/2` check fails → returns None. |
| **Large input?** | Linear time, single pass. Memory usage stays O(1). |
| **Multiple contexts** | If the array size isn’t guaranteed to have a majority element, performing the second verification pass is essential; otherwise the algorithm would inadvertently return a candidate that could be just a coincidence during high‑frequency usage. |

---

### 5️⃣ Complexity analysis (worst‑case)

* **Time**:  **O(n)** – one scan for *candidate*, optional second scan for verification.  
* **Space**: **O(1)** – only two integer variables (`candidate` and `count`).

### 6️⃣ Variants (if you’re in Java/Python/Javascript)

#### Java – `int majorityElement(int[] nums)`  
```java
public int majorityElement(int[] nums) {
    int candidate = 0, count = 0;
    for (int x : nums) {
        if (count == 0) { candidate = x; count = 1; }
        else if (x == candidate) { count++; } else { count--; }
    }
    // Optional second pass
    int freq = 0; for (int x : nums) if x == candidate freq++;
    return freq > nums.length / 2 ? candidate : -1;
}
```

#### JavaScript – `function majority(array)`  
```js
function majority(array) {
  let candidate, count = 0;
  for (const x of array) {
    if (count === 0) { candidate = x; count = 1; }
    else if (x === candidate) { count++; }
    else { count--; }
  }
  const freq = array.reduce((s, x) => s + (x === candidate ? 1 : 0), 0);
  return freq > Math.floor(array.length/2) ? candidate : null;
}
```

### 7️⃣ Final “take‑away”

The Boyer–Moore voting algorithm is a “kill‑the‑competition” algorithm:  
- Each non‑candidiate step pairs up two moderators that can forever reduce “candidates” by one.  
- Only one real antagonist remains – the relatively senior candidate if one holds >n/2 votes.  

Because the operations are simple `if`/`else`, the algorithm is stable and works extensively even on packed arrays, for millions of records, or in streaming data. The algorithm is also the core of the *Boyer–Moore majority vote* technique used in cellular networking (e.g., on Y devices) and computer logic.
