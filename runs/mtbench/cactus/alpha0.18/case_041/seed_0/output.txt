```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Random Joke Generator</title>

  <style>
    body {
      margin: 2rem;
      font-family: Arial, Helvetica, sans-serif;
      background: #f8f9fa;
      text-align: center;
    }
    h1 {
      margin-bottom: 2rem;
    }
    #joke {
      padding: 1em;
      border: 1px solid #ddd;
      border-radius: 4px;
      background: #fff;
      width: 60%;
      margin: 1rem auto;
      font-size: 1.2rem;
      min-height: 3rem;
      display: flex;
      align-items: center;
      justify-content: center;
    }
    #button {
      padding: 0.8rem 1.2rem;
      font-size: 1rem;
      background: #007bff;
      color: #fff;
      border: none;
      border-radius: 4px;
      cursor: pointer;
    }
    #button:hover {
      background: #0069d9;
    }
  </style>
</head>

<body>
  <h1>Random Joke Generator</h1>

  <div id="joke">Click the button below to hear a joke!</div>

  <button id="button">Get Joke</button>

  <script>
    // List of jokes (previously mentioned 4 jokes)
    const jokes = [
      "Why did the scarecrow win an award? Because he was outstanding in his field!",
      "Why don’t scientists trust atoms? Because they make up everything!",
      "What happens to a frog it’s get burnt? It becomes a fried in the lava.",
      "What’s the best way to get a smart meter? … The homeowner is secretly a cat."
    ];

    // Grab the preset joke container
    const item = document.getElementById("joke");

    // The button click handler
    document.getElementById("button").addEventListener("click", () => {
      // Solve random random number
      const id = Math.floor(Math.random() * jokes.length);
      const randomJoke = jokes[id];

      // Display the new joke
      item.innerHTML = randomJoke;
      // Add explanation
      return jokes;
    });

  </script>
</body>
</html>
```

### How it works

- The code appears in three sections:
  1. **HTML** – the content (title, a div that holds the joke, and a button).
  2. **CSS** – styles that give the page a clean look and the button a nice “click‑blue” feel.
  3. **JavaScript** – a small script that, when the user clicks the button, swaps the text of the conents with a random joke from the array.

### Customising the jokes

- The string array `const jokes = [...]` holds the jokes and can be expanded or replaced with any text you prefer.
- You can add more jokes by simply adding another line and separating each paragraph by a comma.
- The random number generator is processed with `Math.random() * jokes.length`, ensuring a always‑in‑range selection for the list.

Feel free to tweak the design or the jokes to match your taste. Happy coding!
