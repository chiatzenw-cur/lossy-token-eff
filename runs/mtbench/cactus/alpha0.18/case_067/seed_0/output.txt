A *full* (or **proper**) binary tree is a rooted tree in which every node has either

* **two internal children** (so it has 2 children) or  
* **zero** children (a leaf).

A classical enumeration result says that if a full binary tree has \(k\) internal
nodes (a *free* node) then it has

\[
n = 2k+1
\]

vertices.  
Conversely, only the odd `n` can belong to a full binary tree.

Let  

\[
B_n = \text{number of full binary trees with } n \text{ vertices}.
\]

*    
* If `n` is even, simply \(B_n = 0\).  
*  
* If `n = 2k+1` is odd, the number of such trees is a **Catalan number**:

\[
B_{\![2k+1]} = C_{k} = \binom{2k}{k}/(k+1)
\]

The Catalan sequence can be obtained by the recurrence

\[
C_{0}=1,\qquad  
C_{i} = \sum_{j=0}^{i-1} C_{j}\,C_{i-1-j}\quad(i\ge 1).
\]

In other words, the number of full binary‑tree‑shapes with exactly `k` internal
objects is `C_k`.  
The recursion above is exactly what we will use for the dynamic‑programming
solution.

--------------------------------------------------------------------

#### Algorithm

```
B_n(n):
    if n % 2 == 0:          # even n is invalid
        return 0
    k = (n - 1) // 2          # number of internal nodes

    # Compute Catalan numbers up to k, DP for each integer
    C = [0] * (k + 1)
    C[0] = 1
    for i in 1..k:
        sum = 0
        for j in 0..i-1:
            sum += C[j] * C[i-1-j]
        C[i] = sum

    return C[k]
```

`Gmp` (Python `bigint` etc.) will automatically handle arbitrarily large
integers, so the function is robust for whole numbers up to a few thousand
digits.

#### Correctness Proof  

We prove that `B_n` outputs the number of full binary trees with `n`
vertices.

*Lemma 1*  
If \(n\) is even, no full binary tree with \(n\) vertices exists.

*Proof.*  
Each internal node contributes 2 children. Therefore, after building the
whole tree, all non‑leaf nodes will introduce an *even* number of non‑leaf
children. The remaining nodes are leaves, giving an odd total count. Therefore,
`n` must be odd. ∎

*Lemma 2*  
Assume \(n = 2k+1\). The number of full binary trees with \(k\) internal nodes
is the Catalan number \(C_k\).

*Proof.*  
Consider a tree with \(k\) internal nodes. Remove the root; its two children
are the roots of a left and a right subtree that are themselves full binary
trees; let the left subtree have \(i\) internal nodes and the right one
\(k-1-i\) vertices.  
Thus

```
T_k  =  (number of ways to split i into left) × (number of ways to split
                             total k-1-i into right)
```

Therefore the number of ordered full binary trees with \(k\) internal nodes
recursively satisfies the Catalan recurrence

\[
C_k = \sum_{i=0}^{k-1} C_i \cdot C_{k-1-i}.
\]

With \(C_0=1\) (empty tree), the tree of size \(k\) is fully counted once
by the recurrence. ∎

*Theorem*  
For each integer `n`, `B_n(n)` returns the exact number of full binary
trees with `n` vertices.

*Proof.*  

1. If `n` is even, by Lemma&nbsp;1 the answer is \(0\).  
2. If `n` is odd, set `k = (n-1)/2`.  
   By Lemma&nbsp;2 the desired number is exactly `C_k`.  
   The algorithm computes `C_k` by iterating over the Catalan recurrence,
   which each term is found using already computed values.  
   Consequently, the algorithm returns `C_k`.

Thus every case works correctly, and `B_n` is correct. ∎

#### Complexity Analysis

Let \(k=\frac{n-1}{2}\) and \(N = k\).

*The outer loop runs `N` times* – \(O(k)\).  
*The inner loop runs up to `i` times* – summing up to \(O(k^2/2)\).

Hence

```
Time   : O(k^2)   = O(n^2)   (since n = 2k+1)
Memory : O(k)     = O(n)     for the DP array
```

For practical problem sizes (e.g., \(n < 2000\)), this is easily fast.  
If you need larger values, one can implement the direct binomial coefficient
manner and compute using modulo arithmetic but that’s beyond the scope.

#### Reference Implementation (Python 3)

```python
def B_n(n: int) -> int:
    """
    Return the number of full binary trees that make use of n vertices.
    n must be a non‑negative integer.
    
    Works when: n == 0 → 0,  n odd   → number of full trees,
     n even   → 0 (no full tree).
    
    Complexity: O(n²) time, O(n) memory.
    """
    if n <= 0:
        return 0
    if n % 2 == 0:
        return 0

    k = (n - 1) // 2
    # Catalan numbers (up to k)
    C = [0] * (k + 1)
    C[0] = 1

    for i in range(1, k + 1):
        sum_val = 0
        for j in range(i):
            sum_val += C[j] * C[i - 1 - j]
        C[i] = sum_val

    return C[k]
```

**Example usage**

```python

```

Notice that the outputs `1, 1, 2, 5, 14, 42` match the Catalan numbers
