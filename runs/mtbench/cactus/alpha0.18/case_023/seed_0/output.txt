## 1.  How the algorithm works

1. **Recursive DFS** – a post‑order traversal that carries the result upwards to the root.
2.  
   * `pickup` – one of the two nodes we are looking for (`p` or `q`).
3. **Return value of the recursion** – for a subtree rooted at node `root` it returns a tuple:
   * `found_node` – whatever `k` of the two nodes is found in the subtree (or `None` if none).
   * `lca` – the current candidate for the lowest common ancestor (if already known).
4. **Base case** – if `root` is `None` → `(None, None)`.

5. **Two steps to combine the recursive results**  
   1. **Combine the two queries**  
        `find_left` gives `(node_left, lca_left)` from the left subtree  
        `find_right` gives `(node_right, lca_right)` from the right subtree

   2. **Determine the final answer**  
        * If both `node_left` and `node_right` are not `None`, the current node is
          the LCA.  
        * If one side is `None`, the destination is deeper: return that node.  
        * If no node was found,  return `None`.
6. **Intersection** – when the sub‑results reach the same node; the path where it is found is placed in the root’s child.

## 2.  Code

```python
def lowest_common_ancestor(root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
    """
    Return the lowest common ancestor (deepest common ancestor) of nodes `p` and `q`.
    The tree is a generalbinary tree, not necessarily a BST.
    """
    removed = None

    def _find_lca(node: TreeNode) -> (TreeNode, TreeNode):
        """Return (node_found , lca)."""
        nonlocal removed

        if node is None:
            return (None, None)

        # If the node is one of the two targets, it matches immediately
        left_node, left_lca = _find_lca(node.left)
        if left_lca:
            return (None, left_lca)    # the LCA already found in the left subtree

        right_node, right_lca = _find_lca(node.right)
        if right_lca:
            return (None, right_lca)    # the LCA already found in the right subtree

        # The two nodes found in different subtrees
        if (node is p or node is q) and (left_node or right_node):
            return (None, node)          # this node is LCA
        if left_node and right_node:
            return (None, node)

        # If this node is already one of the target nodes, propagate it
        node_found = node if node is p or node is q else left_node or right_node

        return (node_found, None)

    return _find_lca(root)[1]
```
