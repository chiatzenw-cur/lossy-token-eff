> **Why Boyer‑Moore?**  
> The algorithm runs in linear time on a single pass and uses only a constant amount of extra space.  
> It keeps a candidate and a counter: when the counter changes, the counter is reset to zero and the candidate is replaced.

## The Code

```python
def majority_element(nums):
    """
    Returns the majority element in the list `nums` using the Boyer–Moore Voting Algorithm.
    
    * If a majority element exists, it returns that element.
    * If no majority element exists, the function returns None and a subsequent
      verification step is required.

    Parameters
    ----------
    nums : list[int]
        A list of integers in which we want to find the majority element.

    Returns
    -------
    int | None
        The majority element, or None if the input does not contain a majority.

    Complexity
    ----------
    Time   : O(n)   (single pass through the array)
    Space  : O(1)   (constant extra space)
    """

    # 1. Candidate selection phase – “tallies” cancel each other out.
    candidate = None
    count = 0

    for nums in nums:
        if count == 0:
            candidate = nums
            count = 1
        elif nums == candidate:
            count += 1
        else:
            count -= 1

    # 2. Optional verification step – returns None if no majority actually exists.
    # This step is optional if the problem guarantees a majority element.
    if candidate is not None:
        if nums.count(candidate) > len(nums) // 2:
            return candidate
    return None

    return candidate
```

## How it Works

| Step | Description |
|------|-------------|
| 1. **Candidate Selection** | Scan each element: If the counter is zero, choose the current element as candidate; otherwise, increment the counter if the element equals the current candidate, else decrement the counter. |
| 2. **Verification** | After reading the whole array, `candidate` is the “canonical” candidate. It could be a majority if the array doesn’t contain a majority. Check whether the candidate’s count equals the number of times it appears; if more than `len(nums) // 2`, return it; otherwise return `None`. |

### Why It Works

1. **Pairing** – Every time you encounter a different value, you flip an “opposite” vote against either the current candidate or the candidate. When the counter goes to zero, that former candidate can no longer win the majority.
2. **Uniqueness** – If there is a majority element, it must survive the remaining “counter” because it appears more than `N/2` times, so it will never be completely cancelled out by the counter. 
3. **Special case** – If the array contains a majority element, the algorithm now guarantees that the final candidate is exactly that element. The verification stage is optional but is a good safety net when the input may not be guaranteed to have a majority.
