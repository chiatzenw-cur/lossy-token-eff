```python
def find_median_sorted_arrays(A, B):
    """
    Return the median of the two sorted arrays A and B.
    The arrays are assumed to be non‑empty and sorted in non‑decreasing order.

    Returns:
        float / int – the median value (average of the two middle elements if the total
            length is even, otherwise the middle element).
    """
    n1, n2 = len(A), len(B)
    total = n1 + n2
    mid = total // 2          # index of the *first* middle element (0‑based)

    # Pointers into the two arrays
    i = j = 0
    prev = curr = None             # we keep the current and the previous one

    # Merge until we reach the required mid + 1 elements
    for _ in range(mid + 1):
        prev = curr

        # Pick the next element in the merged order
        if i < n1 and (j >= n2 or A[i] <= B[j]):
            curr = A[i]
            i += 1
        else:
            curr = B[j]
            j += 1

    # Compute the median
    if total % 2 == 0:            # even length → average of two middle elements
        return (prev + curr) / 2.0
    else:                         # odd length → median is the middle element
        return curr
```

### How it works

1. **Pointers** – `i` (0‑based index in `A`) and `j` (0‑based index in `B`) traverse the two
   arrays in sorted order.

2. **Merge on the fly** – While traversing partitions the arrays in a
   “standard” merge step, but we keep track of how many values have been
   produced (`mid + 1` values, where `mid` is the index of the first half‑ending
   element).  
   The `prev` variable holds the element that was produced just before
   `curr` (the current element).

3. **Median extraction** –  
   * If the total number of elements is odd, `curr` is the middle element.  
   * If the total is even, the two middle elements are `prev` and `curr` and the
     median is their average.

4. **Space & time** –  
   * Only a handful of integer variables are used – **O(1)**.  
   * Each element is examined at most once – **O(n)** time.

### Example

```python
>>> find_median_sorted_arrays([1, 3, 5], [2, 4, 6, 8])

```

**Explanation**  
- Combined array: `[1, 2, 3, 4, 5, 6, 8]`  
- Total length = 7.  
- Middle element (index 3 → 4).  
- The median is the 4th value (4) *or* the average of the 4th and 3rd values for an even number of elements; here we have an odd length, so the median is `4`.
