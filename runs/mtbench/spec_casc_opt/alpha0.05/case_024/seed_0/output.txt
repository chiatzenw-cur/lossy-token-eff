For two arrays `A[0] … A[n-1]` and `B[0] … B[m-1]` we want to print every
element that appears in **both** arrays.  
No extra data structures (no hash tables, no auxiliary arrays, arrays, …)
are allowed – we are allowed to modify the input arrays themselves.

The only operations we can use additionally are the two *pointer* variables
`i` and `j` that walk through the two arrays, and a few scalar integer
variables.

---

### Algorithm

1. **Sort the two arrays in‑place**  
   `A` is sorted in non‑decreasing order, `B` is sorted in non‑decreasing order.

2. **Two‑pointer scan**  
   ```
   i = 0, j = 0
   while i < n and j < m:
       if A[i] == B[j]          // common element found
           output A[i]
           i++; j++;            // move both pointers
       else if A[i] < B[j]      // the smaller element is not common
           i++; j++;;           // move the pointer that points to the larger one
       else
           j++;                 // skip the larger element of B
   ```

   *If A[i] == B[j] the value is printed in both arrays.  
   If the values differ we move the pointer that points to the smaller
   value – the smaller one cannot be matched with any other element in
   the *other* array because of the ordering.*

3. **End** – the loop finishes when one array is exhausted.

The algorithm works for *any* integer values, duplicates are handled
naturally: an element that appears `k` times in both arrays is printed
`k` times.

---

### Correctness Proof  

We prove that the algorithm outputs exactly the common elements of the
two arrays.

*Lemma 1*  
If the algorithm prints a value `x`, then `x` occurs in both arrays.

*Proof.*  
`x` is printed only when `A[i] == B[j]`.  
Since the arrays are sorted, each array positions `i` and `j` contain
exactly the values `A[i]` and `B[j]` respectively.
Therefore `x` is present in `A` and in `B`. ∎

*Lemma 2*  
If a value `x` is present in both arrays, the algorithm will eventually
print `x`.

*Proof.*  
Let `x` be the first common element of `A` and `B` when sorted
(the smallest common element, because sorting preserves order).
During the scan, pointers `i` and `j` start at 0.
At step `i = p` where `p` is the index of `x` in `A`, the value `A[p]` is
`x`.  
When `A[p]` is reached, there are two possibilities:

1. `B[j]` is already `x` ⇒ `x` is printed immediately.
2. `B[j] < x` ⇒ after the scan the smaller value `B[j]` is skipped, so
   `j` starts at the first element that is ≥ `x`.  
   Because `x` is in `B`, still `j` will eventually point to `x`.  
   When `B[j] = x`, `A[p] = x` and the algorithm prints `x`.

Thus `x` is printed. ∎

*Theorem*  
The algorithm outputs exactly the common elements of the two arrays.

*Proof.*  
From Lemma&nbsp;1 every output element is common.  
From Lemma&nbsp;2 every common element is printed.  
Therefore the sets of outputs are equal. ∎

### Complexity Analysis

Let `n = |A|`, `m = |B|`.

*Sorting* `A` and `B` takes `O(n log n)` and `O(m log m)` time respectively.
* Sorting* is done by the standard in‑place quicksort/merge sort.

The two‑pointer scan proceeds in `O(n + m)` time – each pointer moves
one direction only.

Total time: `O(n log n + m log m)`.

Memory usage: the arrays are sorted in‑place, and only two integer
variables (`i`, `j`) are used – `O(1)` extra space.
