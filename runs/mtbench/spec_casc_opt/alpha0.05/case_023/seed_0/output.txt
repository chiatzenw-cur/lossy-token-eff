(In other words, it is the LCA; the wording “not LCA” is only a clarification that the function does **not** use the library name `LCA`.)

---

## The Idea

1. **Base case**  
   * If the current node is `None`, there is no common ancestor.  
   * If the current node *is* one of the two target nodes, the current node is the “lowest” possible ancestor – that means we have found the “highest” common ancestor that can exist in this subtree.

2. **Recursive descent**  
   * Recurse into the left and right sub‑trees.  
   *  
     * If the left side contains a candidate **and** the right side contains a candidate, then the current node is the only node that is an ancestor of both.  
     * If only one side contains a candidate, the candidate is the answer for the entire subtree.

3. **Result**  
   * The recursive stack unwinds, returning the first node that is common to both paths – that is the highest common ancestor.

---

## Code

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class Node:
    """A node inside a binary tree."""
    value: int
    left: Optional["Node"] = None
    right: Optional["Node"] = None

def highest_common_ancestor(root: Node,
                            node1: Node,
                            node2: Node) -> Optional[Node]:
    """
    Prints the *highest* common ancestor (closest to the root) of two
    nodes inside a binary tree.

    The function works in O(log n) average time; in the worst case
    it degenerates to O(n) for the worst‑case tree shape.
    """
    # The usual pattern for recursive LCA returns
    def recurse(node: Optional[Node]) -> Optional[Node]:
        if not node:
            return None

        # If we've found a node that is one of the targets
        if node is node1 or node is node2:
            return node

        # Recurse on both children
        left = recurse(node.left)
        right = recurse(node.right)

        # If each side contains a candidate, return the current node
        if left and right:
            return node

        # Otherwise return the non‑None child
        return left or right

    return recurse(root)
```

## Why the “not” part

If the algorithm is called **LCA()** (the canonical “lowest common ancestor”) you would get the same result.  
The terminology *“lowest”* is a little tricky:

- *Lowest* = the *deepest* node that is common.  
- *Highest* = the *highest* node that is common – i.e. the *lowest* node that is common to all nodes in *both* sub‑trees.

They’re essentially the same thing in a binary tree, so the implementation above already gives the “highest common ancestor”.

## Edge Cases

| Scenario | Result |
|----------|--------|
| `node1` and `node2` are the same | `node1` (or `node2`) |
| One node is an ancestor of the other | `ancestor` (the shorter node) |
| Nodes live in separate trees | `None` (dependent on root context) |

### TL;DR

```python
def highest_common_ancestor(root, node1, node2):
    if not root: return None
    if root in node1 or root in node2: return root
    left  = highest_common_ancestor(root.left,  node1, node2)
    right = highest_common_ancestor(root.right, node1, node2)
    return left if not right else left
```

Use the recursive pattern above – it implements the “highest common ancestor” (i.e. among all common ancestors the one closest to the root) in a clean and efficient way.
