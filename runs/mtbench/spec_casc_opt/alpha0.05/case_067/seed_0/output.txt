## 1.  Why the formula works

* In a full binary tree every internal node has **exactly two** children.  
  * If `n` is the total number of vertices, let `i` be the number of internal nodes.  
  * A full binary tree has `i + 1` leaves, so  

  ```
  total vertices  = 2i + 1  →  n = 2i + 1
  ```

  * Therefore the tree can exist **only** when `n` is odd.  
  * For an odd `n`, the number of internal nodes is  
    `i = (n – 1) / 2`.

* The number of full binary trees with *exactly* `i` internal nodes is the familiar Catalan number `C_i`.  
  Recurrence:  

  ```
  C_0 = 1
  C_i = Σ_{k=0}^{i-1} C_k · C_{i-1-k}   for i ≥ 1
  ```

  Closed‑form:  

  ```
  C_i = binom(2i, i) / (i + 1)
  ```

* Therefore  

  ```
  B_n(n) = { 0      if n is even
           { C_i    if n is odd,  i = (n – 1)/2
  ```

## 2.  The implementation

We use either the closed‑form binomial formula or a dynamic‑programming recurrence – both are O(i²) time and O(i) memory, where `i = (n-1)/2`.  
The binomial version is only a bit faster in practice for very large odd `n` because it uses only a few integer multiplications.

```python
# ---------------------------------------------------------------
#  full_binary_trees.py
# ---------------------------------------------------------------

import math
from functools import lru_cache

# ------------------------------------------------------------------
# 1.  Closed–form (binomial) version
# ------------------------------------------------------------------
def B_n(n: int) -> int:
    """
    Return the number of full binary trees that have exactly n vertices.
    • If n is even the value is zero (no full binary tree possible).
    • If n is odd,  B_n = Catalan((n-1)//2).

    Parameters
    ----------
    n : int
        Total number of vertices in the tree.

    Returns
    -------
    int
        Number B_n for the given n.
    """
    if n % 2 == 0:
        return 0

    i = (n - 1) // 2          # number of internal nodes

    # Catalan(i) = binom(2i, i) // (i + 1)
    #   The binomial coefficient is computed with the Python math.comb (Python 3.8+).
    return math.comb(2 * i, i) // (i + 1)

# ------------------------------------------------------------------
# 2.  Dynamic‑programming version (alternative)
# ------------------------------------------------------------------
@lru_cache(maxsize=None)
def catalan_dp(k: int) -> int:
    """Catalan number via DP (bottom‑up)."""
    if k == 0:
        return 1
    total = 0
    for left in range(k):
        total += catalan_dp(left) * catalan_dp(k - 1 - left)
    return total

def B_n_dp(n: int) -> int:
    """
    Same as B_n but uses a dynamic‑programming version for Catalan numbers.
    """
    if n % 2 == 0:
        return 0
    i = (n - 1) // 2
    return catalan_dp(i)

# ------------------------------------------------------------------
# 3.  Quick sanity / demonstration
# ------------------------------------------------------------------
if __name__ == "__main__":
    # Pre‑compute the first few values to illustrate the sequence
    for n in range(1, 20, 2):
        print(f"B_{n} = {B_n(n)}")
```

### What the code does

1. **Closed‑form**  
   * `B_n` first checks whether `n` is even (`n % 2 == 0`).  
   * If `n` is odd, it computes `i = (n-1)//2`.  
   * `math.comb(2*i, i)` gives `2i choose i`.  
   * `Catalan(i)` is obtained by dividing the binomial coefficient by `(i + 1)`.  

   This yields the exact integer answer without any floating‑point arithmetic.

2. **Dynamic‑programming implementation**  
   * `catalan_dp` is the classic DP recurrence for Catalan numbers, cached with `lru_cache`.  
   * `B_n_dp` just calls `catalan_dp` with the number of internal nodes.

3. **Demonstration**


## 3.  Complexity Analysis

| Approach         | Time (worst) | Space (worst) |
|------------------|--------------|----------------|
| Closed‑form      | `O(log((n-1)/2))`  (binary multiplication) | `O(1)` (aside from integer size) |
| DP (recursive)   | `O(i²)` (i = (n‑1)/2, call `catalan_dp`) | `O(i)` (memoization integers) |

For most practical constraints (`n` up to a few thousand), the closed‑form is extremely fast and uses only an integer arithmetic.

## 4.  Porting to other languages

| Language | How to compute binomial coefficients |
|----------|-------------------------------------|
| **C/C++** | `std::uint64_t` or `unsigned long long/multiply` + `__int128` for big factorials, or use GMP’s `mpz_t`. |
| **Java** | `java.math.BigInteger` or use `java.math.BigInteger.binomial` (since JDK 17). |
| **JavaScript** | `BigInt` for arbitrary precision; implement `comb(`) via factorial or iterative multiplication. |

The only language‑specific thing is the way to compute binomial coefficients; the rest of the logic basically remains the same.
