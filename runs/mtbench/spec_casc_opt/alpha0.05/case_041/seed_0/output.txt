Just copy the code into a file named `index.html` (or any name you prefer) and open it with a browser.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Random Joke Generator</title>
<style>
  body {font-family: Arial, sans-serif; margin: 2rem; text-align: center;}
  #joke {margin-top: 1rem; font-size: 1.2rem;}
  button {padding: 0.6rem 1.2rem; font-size: 1rem; cursor: pointer;}
</style>
</head>
<body>

<h1>Random Joke Generator</h1>
<button id="jokeBtn">Tell me a joke</button>
<div id="joke"></div>

<script>
  // The four jokes.
  const jokes = [
    "Why did the scarecrow win an award? Because he was outstanding in his field!",
    "I told my wife she was drawing her eyebrows too high. She looked surprised.",
    "What do you call chess players who can’t enjoy a game? A–given!",
    "I’m reading a book on anti‑gravity. It’s impossible to put down."
  ];

  // Pick a random joke.
  const getRandomJoke = () => {
    const index = Math.floor(Math.random() * jokes.length);
    return jokes[index];
  };

  // Attach the click handler to the button.
  const btn = document.getElementById('jokeBtn');
  const jokeDiv = document.getElementById('joke');

  btn.addEventListener('click', () => {
    jokeDiv.textContent = getRandomJoke();
  });
</script>

</body>
</html>
```

### How it works
1. A button with a click event listener is defined.
2. When the button is clicked, the script picks a random joke from the `jokes` array.
3. The chosen joke is displayed inside the `<div id="joke">`.

You can add more jokes to the array or style the page further with your own CSS. Happy coding!
