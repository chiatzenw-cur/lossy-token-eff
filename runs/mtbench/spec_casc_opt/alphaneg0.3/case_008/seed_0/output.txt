The function returns the majority element (the element that appears more than ⌊n/2⌋ times) or raises a `ValueError` if the input array is empty.

```python
def majority_element(nums):
    """
    Return the majority element of the list `nums` using the Boyer–Moore Voting Algorithm.

    If the input is empty (or if no element satisfies the majority condition), a
    ValueError is raised.

    Parameters
    ----------
    nums : list[int] | tuple[int]
        The list (or tuple) of integers.

    Returns
    -------
    int
        The element that appears more than n // 2 times in `nums`.

    Examples
    --------
    >>> majority_element([2, 1, 2, 2, 3, 2, 2])
    2
    >>> majority_element([4, 4, 4, 4])
    4
    >>> majority_element([1],)
    1
    """
    if not nums:
        raise ValueError("Array must contain at least one element")

    # 1. Find a candidate candidate
    candidate = None
    count = 0
    for num in nums:
        if count == 0:
            candidate = num
            count = 1
        elif num == candidate:
            count += 1
        else:
            count -= 1

    # 2. Optional validation (optional if problem guarantees a majority)
    # count the candidate occurrences to confirm it truly is a majority
    if nums.count(candidate) <= len(nums) // 2:
        raise ValueError("No majority element present")

    return candidate
```

### How the Algorithm Works

| Step | Action                            | Why it works **(theory)** |
|------|------------------------------------|----------------------------|
| 1    | `candidate = None` & `count = 0`   | Initialise with no candidate and zero count. |
| 2    | Iterate over each element `num`    |   |
| 3    | `count == 0` → set `candidate = num` & `count = 1` | We pick a new candidate when the balance cancels out. |
| 4    | `num == candidate` → `count += 1` | When the current element matches the candidate, we reinforce it. |
| 5    | `num != candidate` → `count -= 1` | A mismatch reduces the candidate’s “vote” counter. |
| 6    | After the loop, `candidate` is the only one that could survive this cancellation scheme. | The majority element can never be cancelled out entirely because it outnumbers every other element combined. |
| 7    | (Optional) Count again to check if `candidate` truly occurs > n/2 times. | Some variations guarantee a majority; others do not. |

### Complexity

- **Time**: `O(n)` – one pass over the array (plus a second pass for the optional validation if you choose to include it).
- **Space**: `O(1)` – only a few integer variables are maintained.
