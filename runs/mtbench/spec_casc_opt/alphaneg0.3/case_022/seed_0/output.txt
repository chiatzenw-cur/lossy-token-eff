```cpp
#include <iostream>
#include <cstdint>      // for uint64_t
#include <stdexcept>    // for std::invalid_argument

/* ----------------------------------------------------------
   Recursive function that returns the nth Fibonacci number.
   Definition used:
          F(0) = 0
          F(1) = 1
          F(n) = F(n‑1) + F(n‑2)   for n ≥ 2
   ---------------------------------------------------------- */
uint64_t fib_recursive(int n)
{
    if (n < 0)                  // negative indices are not defined
        throw std::invalid_argument("n must be non‑negative");

    if (n < 2)                  // base cases: F(0)=0, F(1)=1
        return static_cast<uint64_t>(n);

    // recursive step
    return fib_recursive(n - 1) + fib_recursive(n - 2);
}  // fib_recursive

// ------------------------------------------------------------------
// Simple interface: read an integer from standard input,
// compute Fibonacci, and print the result.
// ------------------------------------------------------------------
int main()
{
    std::cout << "Enter a non‑negative integer n: ";
    int n;
    std::cin >> n;

    try {
        uint64_t result = fib_recursive(n);
        std::cout << "F(" << n << ") = " << result << "\n";
    }
    catch (const std::exception &ex) {
        std::cerr << "Error: " << ex.what() << '\n';
        return 1;
    }

    return 0;
}
```

### How it works

1. **Base cases**  
   *If `n < 2`* the function returns `n` itself – this gives `F(0)=0` and `F(1)=1`.

2. **Recursive case**  
   *For `n ≥ 2`* the function calls itself twice: once at `n-1` and once at `n-2`.  
   Those calls eventually reduce to the base cases, after which the results bubble up.

3. **Complexity**  
   The naive recursive method runs in *O(φⁿ)* time (exponential) and uses *O(n)* stack depth, so it’s fine for small `n` (say `n ≤ 40` on a 64‑bit machine).  
   For larger `n` you’d normally use memoisation or an iterative solution, but the code above keeps the recursion simple as requested.
