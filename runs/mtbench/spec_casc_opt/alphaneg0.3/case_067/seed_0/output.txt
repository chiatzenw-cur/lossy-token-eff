A *full* (or *proper*) binary tree is a rooted tree in which every vertex has either 0 or 2 children.  
It is a classical fact that:

* The number of vertices of a full binary tree is always odd.  
* If the tree has `I` internal nodes (nodes with 2 children) then it has `I+1` leaves, so  
  total vertices `N = I + (I+1) = 2I + 1`.  
* The number of full binary trees with `I` internal nodes is the `I`‑th Catalan number  
  `C_I = (1/(I+1)) * binom(2I, I)`.

Therefore

```
B_n = 0   if n is even
B_n = C_{(n-1)/2}   if n is odd
```

Below is a compact and efficient implementation in Python that returns the exact integer value (no modulo is supplied).  
It uses the closed‑form formula for Catalan numbers, which is O(1) apart from the arithmetic involved in `math.comb`.

```python
import math
from functools import lru_cache

def B(n: int) -> int:
    """
    Return the number of full binary trees with exactly n vertices.

    Parameters
    ----------
    n : int
        Total number of vertices in the tree.

    Returns
    -------
    int
        Number of full binary trees with n vertices.
        If n is even, the result is 0.
    """
    if n < 1:
        raise ValueError("n must be a positive integer")
    if n % 2 == 0:
        return 0          # impossible – full binary trees have odd size only

    k = (n - 1) // 2      # number of internal nodes
    # Catalan_k = binom(2k, k) // (k + 1)
    return math.comb(2 * k, k) // (k + 1)


# ------------------------------------------------------------------
# Some quick tests / examples
# ------------------------------------------------------------------
if __name__ == "__main__":
    for n in range(1, 15):
        print(f"B({n}) = {B(n)}")
```

### Why the formula works
If a full binary tree has `I` internal nodes, the number of internal nodes can be any non‑negative integer `I`.  
Each binary tree with `I` internal nodes determines a unique *shape* of a full binary tree: the total number of different shapes is given by the Catalan number `C_I`.  
Since the total vertex count `N = 2I + 1`, we solve for `I = (N-1)/2` and plug it into the Catalan formula.

### Complexity
- **Time**: O(1) (dominant work is `math.comb(2*k, k)`, which is usually implemented in a few multiplications and divisions).
- **Space**: O(1).

If you prefer a dynamic‑programming approach that does **not** use the closed formula (useful for educational purposes or for languages that lack a large‑integer combinatorics routine), you can compute the Catalan numbers using the recurrence
