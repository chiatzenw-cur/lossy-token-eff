When the button is pressed the JavaScript picks one of four jokes at random and displays it in a paragraph.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Random Joke Generator</title>
    <style>
        body {font-family: Arial, sans-serif; text-align:center; margin-top:3rem;}
        #joke  {margin-top:1rem; font-size:1.2rem; color:#333;}
        button {padding:0.5rem 1rem; font-size:1rem;}
    </style>
</head>
<body>

    <h1>Click a button for a random joke!</h1>
    <button id="jokeBtn">Tell me a joke</button>
    <p id="joke"></p>

    <script>
        // --------------- 1. List of jokes ---------------
        const jokes = [
            "I told my friend 10 jokes to pay for a pizza: 5 got cheesy, 5 got my friend in the corner.",
            "Why do we never tell secrets on a farm? Because the potatoes have eyes and the corn has ears.",
            "What do you call a computer that sings? A-Dell.",
            "I once tried to take a bath in the shower.  My hair turned into a bad hair day."
        ];

        // --------------- 2. Helper to get a random joke ---------------
        function getRandomJoke() {
            const idx = Math.floor(Math.random() * jokes.length);
            return jokes[idx];
        }

        // --------------- 3. Set up the button click handler ---------------
        document.getElementById('jokeBtn').addEventListener('click', () => {
            const joke = getRandomJoke();
            document.getElementById('joke').textContent = joke;
        });
    </script>
</body>
</html>
```

### How it works

1. **HTML** – A simple page with a button (`#jokeBtn`) and a paragraph (`#joke`) where the joke will appear.
2. **CSS** – A minimal style to make the page legible and centered.
3. **JavaScript** –  
   * An array `jokes` holds your four jokes.  
   * `getRandomJoke()` returns a random joke from that array.  
   * The button’s click event fires, calling the function and updating the paragraph’s text.

Feel free to open, copy, and run the file in any web browser. Enjoy the jokes!
