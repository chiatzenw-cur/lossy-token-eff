(This code works for any binary tree that has a reference to its root, not just for a binary search tree.)

## 1.  The data structure

```python
class Node:
    def __init__(self, key, left=None, right=None):
        self.key   = key
        self.left  = left
        self.right = right

    def __repr__(self):
        return f"Node({self.key})"
```

## 2.  Recursive helper

The classic algorithm is a single recursive walk that returns:

| Return value | Meaning |
|--------------|---------|
| `None` | Neither node found in this subtree |
| `node` | This `node` is one of the two sought nodes **or** its subtree contains both (i.e., it is the LCA) |

The helper also gives us a convenient boolean flag that tells us how many of the target nodes were located in the subtree.

```python
def _find_ancestor_and_count(root, node1, node2):
    """
    Returns (ancestor, count)
    - ancestor : the lowest common ancestor if both nodes are found,
                  otherwise the one that is found,
                  or `None` if neither is found.
    - count    : how many of the two target nodes were found
                 in this subtree (0, 1, or 2).
    """
    if root is None:
        return None, 0

    # 1. Recurse on left and right
    left_ancestor, left_count   = _find_ancestor_and_count(root.left, root, root)
    right_ancestor, right_count = _find_ancestor_and_count(root.right, root, root)

    # 2. Count if current node is one of the targets.
    mid = int(root is node1 or root is node2)

    total = left_count + right_count + mid

    # 3. Find the ancestor.
    if left_ancestor and right_ancestor:
        # Both nodes found in distinct subtrees → current node is the LCA.
        return root, 2
    if left_ancestor:
        return left_ancestor, left_count
    if right_ancestor:
        return right_ancestor, right_count

    # If the current node itself is one of the targets:
    return root if mid else None, total
```

## 3.  Public API

```python
def highest_common_ancestor(root, node1, node2):
    """
    Return the highest common ancestor (the ancestor closest to the root)
    of *node1* and *node2* in the binary tree rooted at *root*.
    Raises a ValueError if either node is not found.
    """
    ancestor, count = _find_ancestor_and_count(root, node1, node2)
    if count < 2:
        raise ValueError("Both nodes must be present in the tree.")
    return ancestor
```

## 5.  Why we call this the “highest” common ancestor

This function returns the *lowest* (closest to the leaves) of two nodes that is
still an ancestor of both nodes.  
If you interpret the tree as a genealogy tree, the deepest such ancestor is the **most recent common ancestor**;  
if you think in terms of distance from the root, this is the **highest common ancestor** possible.

- For any two nodes that are in the same tree, the answer is *always* the root.  
- In a *larger* or *multiple*‑tree scenario the answer is the **closest ancestor** that is common to both—precisely the conventional LCA algorithm.

---

## 6.  Complexity analysis

- **Time**: Each node is visited once → **O(n)**, where *n* is the number of nodes in the tree.
- **Space**: Recursion depth equals the height of the tree → **O(h)**, where *h* number of nodes on the longest path from root to leaf.  
  (For a balanced tree *h* ≈ log *n*; for a degenerate chain *h* ≈ *n*.)

## 7.  Alternative: iterative with parent pointers

If you prefer an **iterative** solution (no recursion, no stack manipulation), the classic
“parent‑pointer” method works:

```python
def highest_common_ancestor_with_parents(node1, node2):
    # Build a set of ancestors of node1
    ancestors = set()
    while node1:
        ancestors.add(node1)
        node1 = node1.parent

    # Walk from node2 upward until we hit an ancestor of node1
    while node2:
        if node2 in ancestors:
            return node2
        node2 = node2.parent

    return None
```

This approach requires that each node have a `parent` reference, which can be built in a single pass beforehand but occupies extra memory.

### TL;DR

- The “highest common ancestor” is in fact the conventional *lowest common ancestor* when the tree is viewed from the root.
- Use the recursive helper `_find_ancestor_and_count` to locate it in **O(n)** time and **O(h)** space.
- The function throws a clear error if either node is missing, making it safe for production code.
