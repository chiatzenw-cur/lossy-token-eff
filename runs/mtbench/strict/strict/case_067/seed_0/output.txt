> **Full binary tree** – every internal vertex has *exactly two* children.  
> **Key observation** – a full binary tree with *n* vertices must have an  
> odd number of vertices (because every internal node contributes an extra
> leaf).  
> If  
> n = 2 k + 1  
> the tree has **k** internal nodes and **k + 1** leaves.  
> The number of distinct shapes of a full binary tree with *k* internal nodes
> is the *k*‑th Catalan number \(C_k\).

Hence  

```
B_n  = 0  if n is even
B_n  = C_{(n-1)/2}  otherwise
```

The Catalan numbers can be computed in several ways:

* **Closed form**: \(C_k = \frac{1}{k+1}\binom{2k}{k}\)  
  (uses only integer arithmetic – perfect for Python’s unlimited‑size ints)
* **Dynamic programming**:  `C_{k+1} = Σ_{i=0}^{k} C_i * C_{k-i}`  
  (O(k²) time but needs no factorial computations)
* **Recursive memoisation** – same as DP but lazy

Below I provide two flavours:  
1. **Fast, clean** (using the closed form + `math.comb`),  
2. **Illustrative DP** (shows the recurrence that is often taught in
   algorithm classes).

```python
# --------------------------------------------------------------
# 1️⃣  Fast closed‑form + maths.comb (Python 3.8+)
# --------------------------------------------------------------
from math import comb
from typing import Union

def B_fast(n: int) -> int:
    """
    Return the number of full binary trees with exactly `n` vertices.
    Uses the closed form B_n = C_{(n-1)/2}.
    """
    if n % 2 == 0:           # an even number of nodes is impossible
        return 0

    k = (n - 1) // 2         # number of internal nodes
    # Catalan number C_k = binom(2k, k) // (k + 1)
    catalan_k = comb(2 * k, k) // (k + 1)
    return catalan_k

# Quick sanity checks
assert B_fast(1) == 1
assert B_fast(3) == 1
assert B_fast(5) == 2
assert B_fast(7) == 5          # 5 is 3rd Catalan number
assert B_fast(2) == 0
assert B_fast(0) == 0


# --------------------------------------------------------------
# 2️⃣  Dynamic‑programming version (illustrative, O(k²))
# --------------------------------------------------------------
def B_dp(n: int) -> int:
    """
    Compute B_n using the recurrence for Catalan numbers:
        C_0 = 1
        C_{k+1} = Σ_{i=0}^{k} C_i * C_{k-i}
    Since n = 2k + 1, we only compute odd indices.
    """
    if n % 2 == 0:
        return 0
    k = (n - 1) // 2

    # Catalan numbers up to k
    C = [0] * (k + 1)
    C[0] = 1
    for m in range(1, k + 1):
        total = 0
        for i in range(m):
            total += C[i] * C[m - 1 - i]
        C[m] = total

    return C[k]

# Same sanity tests
assert B_dp(1) == 1
assert B_dp(3) == 1
assert B_dp(5) == 2
assert B_dp(7) == 5
assert B_dp(2) == 0
assert B_dp(0) == 0


# --------------------------------------------------------------
# 3️⃣  Example usage (interactive)
# --------------------------------------------------------------
if __name__ == "__main__":
    for n in range(1, 13, 2):          # test all odd n <= 11
        print(f"B_{n} =", B_fast(n))
```

#### Extending or customizing

* **If you want arbitrary precision in older Python versions**  
  replace `comb(2*k, k)` with a manual binomial coefficient routine:

  ```python
  def binom(n, k):
      res = 1
      for i in range(1, k+1):
          res = res * (n - i + 1) // i
      return res
  ```

* **Large n** – use the DP version to avoid massive binomial numbers
  (though Python’s int still handles it, the DP version runs in O(k²)
  and uses only additions/multiplications of already small numbers).

* **Languages other than Python** – the same formulas carry over.
  For instance, in C/C++/Java you can implement the closed form using
  128‑bit integers or arbitrary‑precision libraries.
