```python
def majority_element(nums):
    """
    Returns the majority element in the list `nums`.
    A majority element is defined as an element that appears more
    than floor(n/2) times in the array.

    The algorithm runs in O(n) time and O(1) extra space.
    """
    if not nums:
        raise ValueError("Array must contain at least one element")

    # --- Phase 1: find a candidate ---
    candidate = None
    count = 0
    for num in nums:
        if count == 0:
            candidate = num
            count = 1
        elif num == candidate:
            count += 1
        else:
            count -= 1

    # --- Phase 2: verify the candidate (optional, if the problem
    # guarantees a majority element this can be omitted) ---
    if nums.count(candidate) > len(nums) // 2:
        return candidate
    else:
        raise ValueError("No majority element found")
```

### How it works

1. **Candidate selection**  
   - Scan the list.  
   - Keep a counter that increments for matches of the current candidate and decrements for mismatches.  
   - When the counter drops to zero, pick the next element as a new candidate.  
   - After one full pass, if a majority element exists, the remaining candidate must be it.

2. **Verification**  
   - Count the candidate’s occurrences and confirm that it appears more than *⌊n/2⌋* times.  
   - If the input guarantees a majority element, this step can be skipped.

### Complexity

| Operation | Time | Extra Space |
|-----------|------|-------------|
| Pass 1    | O(n) | O(1) |
| Pass 2    | O(n) | O(1) |
| Total     | O(n) | O(1) |
