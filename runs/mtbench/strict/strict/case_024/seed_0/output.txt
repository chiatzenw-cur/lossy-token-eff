For two given arrays `A[0…n-1]` and `B[0…m-1]` we have to output every element that
occurs in **both** arrays.  
The only restriction is that **no additional data structure** (hash table, set,  
vector, etc.) may be used.

The simplest way to honour this restriction is to compare every element of the first
array with every element of the second array – a double loop.  
The algorithm runs in `O(n·m)` time and uses only a few scalar variables
(constant extra space).

> **Tip:** If the arrays are large, you can first sort them in place and
> then walk through them with two pointers.  
> Sorting can be done with the library `std::sort` – it only needs `O(log k)` 
> auxiliary space and still satisfies the “no extra data structure” rule
> because the array itself is used.  
> The two–pointer walk then runs in linear time (`O(n+m)`).

Below we present the straightforward double‑loop version, because it is
hard‑to‑misunderstand, needs no sorting, and clearly respects the constraint.

--------------------------------------------------------------------

## Algorithm
```
for i = 0 … n-1                     // all elements of A
    for j = 0 … m-1                 // all elements of B
        if A[i] == B[j]             // common element found
            print A[i] (or store / collect it)
            break                   // stop inner loop – no duplicate output
```

*The `break` is optional: without it a duplicate pair will be printed
for every copy of the value in `B`.*

--------------------------------------------------------------------

## Correctness Proof  

We prove that the algorithm outputs **exactly** the common elements of `A` and `B`.

---

### Lemma 1  
If an element `x` appears in both arrays, then the algorithm outputs `x`.

*Proof.*  
Take any occurrence of `x` in `A`, say at index `i`.  
During the outer loop iteration `i`, the inner loop checks all indices `j` of `B`.  
Since `x` exists in `B`, there is some `j` with `B[j] = x`.  
The condition `A[i] == B[j]` becomes true, therefore the algorithm prints `x`. ∎



### Lemma 2  
The algorithm never outputs a value that is **not** common to both arrays.

*Proof.*  
The algorithm only prints a value when the equality `A[i] == B[j]` is true.  
Thus the printed value is present in `A` (at index `i`) **and** in `B` (at index `j`),  
i.e. it is a common element. ∎



### Theorem  
The output of the algorithm is **exactly** the set (or multiset, if the inner
loop is not broken) of common elements of `A` and `B`.

*Proof.*  
From Lemma&nbsp;1 each common element is printed at least once.  
From Lemma&nbsp;2 nothing else is printed.  
Hence the output set equals the set of common elements. ∎



--------------------------------------------------------------------

## Complexity Analysis  

Let `n = |A|` and `m = |B|`.

* **Time**:  
  Two nested loops ⇒ `n` iterations × `m` inner iterations ⇒  
  `O(n · m)` comparisons.

* **Auxiliary Space**:  
  Only a constant number of scalar variables are used ⇒ `O(1)`.

## Reference Implementation  (C++)

```cpp
#include <iostream>
#include <vector>

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int n, m;
    std::cout << "Size of first array: ";
    std::cin >> n;
    std::vector<int> A(n);
    std::cout << "Enter elements of first array:\n";
    for (int i = 0; i < n; ++i) std::cin >> A[i];

    std::cout << "Size of second array: ";
    std::cin >> m;
    std::vector<int> B(m);
    std::cout << "Enter elements of second array:\n";
    for (int i = 0; i < m; ++i) std::cin >> B[i];

    std::cout << "Common elements are: ";
    bool first = true;
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            if (A[i] == B[j]) {
                if (!first) std::cout << ' ';
                std::cout << A[i];
                first = false;
                break;                 // skip duplicates of this A[i] in B
            }
        }
    }
    std::cout << '\n';
    return 0;
}
```

### Variant: Two‑Pointer after Sorting

If you want the algorithm to run in `O(n log n + m log m)` time (sorting) and
`O(n + m)` after that, you can quick‑sort both arrays first and then walk them
with two indices.  This approach is useful when `n` and `m` are very large,
because it reduces the time complexity compared to the quadratic double loop.

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    int n, m;
    std::cin >> n;
    std::vector<int> A(n);
    for (int &x : A) std::cin >> x;

    std::cin >> m;
    std::vector<int> B(m);
    for (int &x : B) std::cin >> x;

    std::sort(A.begin(), A.end());
    std::sort(B.begin(), B.end());

    std::cout << "Common elements are: ";
    int i = 0, j = 0;
    bool first = true;
    while (i < n && j < m) {
        if (A[i] < B[j]) ++i;
        else if (A[i] > B[j]) ++j;
        else {
            if (!first) std::cout << ' ';
            std::cout << A[i];
            first = false;
            ++i; ++j;               // move past this common element
        }
    }
    std::cout << '\n';
}
```

Both implementations meet the problem requirement of *not using any extra
data structures* – the only data used are the input arrays themselves.
