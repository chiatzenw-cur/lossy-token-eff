## 1. Python

```python
def majority_element(nums):
    """
    Return the majority element in nums using Boyer-Moore Voting Algorithm.
    If no majority exists, return None.

    Parameters
    ----------
    nums : List[int]
        Input list of integers.

    Returns
    -------
    int | None
        The majority element if present, otherwise None.
    """
    # 1.  Find a candidate
    candidate = None
    count = 0
    for num in nums:
        if count == 0:
            candidate = num
            count = 1
        elif num == candidate:
            count += 1
        else:
            count -= 1

    # 2.  Verify that the candidate is indeed a majority
    if nums.count(candidate) > len(nums) // 2:
        return candidate
    return None
```

**Usage**

```python
print(majority_element([2, 2, 1, 1, 1, 2, 2]))   # → 2
print(majority_element([1, 2, 3, 4]))             # → None
```

## 2. Java

```java
public class MajorityElement {
    public static Integer findMajority(int[] nums) {
        if (nums == null || nums.length == 0) return null;

        // 1.  Candidate selection
        int candidate = 0, count = 0;
        for (int num : nums) {
            if (count == 0) {
                candidate = num;
                count = 1;
            } else if (num == candidate) {
                count++;
            } else {
                count--;
            }
        }

        // 2.  Verify candidate
        int freq = 0;
        for (int num : nums) {
            if (num == candidate) freq++;
        }
        return (freq > nums.length / 2) ? candidate : null;
    }

    public static void main(String[] args) {
        int[] arr = {2, 2, 1, 1, 1, 2, 2};
        System.out.println(findMajority(arr));  // 2

        int[] arr2 = {1, 2, 3, 4};
        System.out.println(findMajority(arr2)); // null
    }
}
```

*The method returns `Integer` so it can return `null` when no majority exists.*

## 3. C++

```cpp
#include <vector>
#include <optional>

std::optional<int> majority_element(const std::vector<int>& nums) {
    if (nums.empty()) return std::nullopt;

    // 1.  Candidate selection
    int candidate = 0, count = 0;
    for (int num : nums) {
        if (count == 0) {
            candidate = num;
            count = 1;
        } else if (num == candidate) {
            ++count;
        } else {
            --count;
        }
    }

    // 2.  Verify candidate
    int freq = 0;
    for (int num : nums) {
        if (num == candidate) ++freq;
    }
    if (freq > static_cast<int>(nums.size() / 2)) {
        return candidate;
    } else {
        return std::nullopt;
    }
}
```

### How the algorithm works

1. **Candidate selection** –  
   Keep a `candidate` and a `count`.  
   *If `count` is 0, the current element becomes the new candidate.*  
   *If the current element equals the candidate, increment `count`.  
   *Otherwise, decrement `count`.*

   After a single pass, **if** a majority element exists, the candidate **must** be that element.

2. **Verification** –  
   Count the occurrences of the candidate to ensure it actually appears more than `⌊n/2⌋` times.  
   (If the input guarantees a majority, this step can be omitted.)
