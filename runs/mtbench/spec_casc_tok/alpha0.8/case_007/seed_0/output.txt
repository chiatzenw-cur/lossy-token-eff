Let's produce final.<|end|><|start|>assistant<|channel|>final<|message|>Below is a **ready‑to‑run** Python script that

1. Walks through a directory tree (recursively) and finds every file that ends with `.txt`.
2. Reads each file, extracts the words (case‑insensitive, ignoring punctuation and numbers).
3. Counts how many times each word appears in **all** files combined.
4. Prints the five most frequent words together with their counts.

```python
#!/usr/bin/env python3
"""
wordcounter.py – Count words in all .txt files under a directory and print the top‑5.
"""

import argparse
import pathlib
import re
from collections import Counter

# --------------------------------------------------------------------------- #
# 1.  Helpers
# --------------------------------------------------------------------------- #

def read_text_files(directory: pathlib.Path):
    """
    Generator that yields the text of every *.txt file found under `directory`
    (recursively).  Files are opened with UTF‑8 encoding; if a file cannot be
    decoded, a warning is printed and the file is skipped.
    """
    for txt_file in directory.rglob("*.txt"):
        try:
            with txt_file.open("r", encoding="utf-8") as f:
                yield f.read()
        except UnicodeDecodeError:
            print(f"⚠️  Skipping {txt_file} – cannot decode as UTF‑8.")
        except Exception as exc:
            print(f"⚠️  Skipping {txt_file} – {exc}")

def tokenize(text: str) -> list[str]:
    """
    Return a list of words found in *text*.
    • Lower‑case for case‑insensitive counting.
    • Words are defined by the regex \b\w+\b which matches
      sequences of letters, digits or underscore.
    • Punctuation is discarded.
    """
    return re.findall(r"\b\w+\b", text.lower())

# --------------------------------------------------------------------------- #
# 2.  Main routine
# --------------------------------------------------------------------------- #

def main() -> None:
    parser = argparse.ArgumentParser(
        description="Count words in all .txt files under a directory and "
        "display the top‑5 most frequent words."
    )
    parser.add_argument(
        "directory",
        type=str,
        help="Path to the directory to scan (recursively).",
    )
    args = parser.parse_args()

    root = pathlib.Path(args.directory)
    if not root.is_dir():
        raise SystemExit(f"❌  {root!s} is not a directory or does not exist.")

    counter = Counter()

    for txt in read_text_files(root):
        counter.update(tokenize(txt))

    if not counter:
        print("⚠️  No words found in the given directory.")
        return

    top_five = counter.most_common(5)

    print("\nTop 5 words by frequency:")
    for word, count in top_five:
        print(f"  {word!r:>10} – {count:#6d}")

# --------------------------------------------------------------------------- #
# 3.  Entry point
# --------------------------------------------------------------------------- #

if __name__ == "__main__":
    main()
```

## What the script does exactly

| Step | What happens | Why it matters |
|------|--------------|----------------|
| 1 | `Path.rglob("*.txt")` walks **recursively** down the directory tree. | Guarantees all `*.txt` files are considered. |
| 2 | Reads each file in UTF‑8 (the most common encoding). | Avoids garbled text. |
| 3 | `re.findall(r"\b\w+\b", text.lower())` extracts words and normalises them to lower‑case. | Counts words in a case‑insensitive way and ignores punctuation. |
| 4 | `Counter.update` accumulates the counts. | Efficient, single‑pass counting. |
| 5 | `most_common(5)` returns the five most frequent words. | Gives you the exact result you asked for. |

## Tweaks you might want

| Desired tweak | Where to change |
|---------------|-----------------|
| **Ignore stop‑words** (e.g. `the`, `and`, `is`) | Add a `STOPWORDS` set and filter out `word in STOPWORDS` before `counter.update`. |

| **Handle huge files** | Instead of loading the whole file into memory, read line‑by‑line and update the counter. |
