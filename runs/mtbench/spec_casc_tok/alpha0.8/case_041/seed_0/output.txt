```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Random Joke Generator</title>
  <style>
    body {
      font-family: Arial, sans-serif;
      margin: 2rem;
      text-align: center;
    }
    #joke {
      margin: 1.5rem auto;
      font-size: 1.2rem;
      color: #333;
      max-width: 480px;
      line-height: 1.5;
    }
    button {
      padding: 0.75rem 1.5rem;
      font-size: 1rem;
      background: #0066cc;
      color: #fff;
      border: none;
      border-radius: 4px;
      cursor: pointer;
    }
    button:hover {
      background: #004999;
    }
  </style>
</head>
<body>

  <h1>Random Joke Generator</h1>

  <div id="joke">Click the button to see a joke.</div>

  <button id="jokeBtn">Show a Joke</button>

  <script>
    // List of 4 jokes
    const jokes = [
      "Why don’t scientists trust atoms? Because they make up everything!",
      "I told my wife she should embrace her mistakes… She hugged me.",
      "Why did the bicycle stay up? Because it was two‑tired.",
      "What’s a computer’s favorite snack? Microchips."
    ];

    // Function that picks a random joke and displays it
    function showRandomJoke() {
      const randomIndex = Math.floor(Math.random() * jokes.length);
      const joke = jokes[randomIndex];
      document.getElementById('joke').textContent = joke;
    }

    // Attach the function to the button click
    document.getElementById('jokeBtn').addEventListener('click', showRandomJoke);
  </script>
</body>
</html>
```

### How it works

1. **HTML** – The page contains a `<div>` for the joke and a `<button>` to trigger it.  
2. **CSS** – Minor styling for readability.  
3. **JavaScript** –  
   * `jokes` array holds four jokes.  
   * `showRandomJoke()` picks a random index and updates the `<div>` with the selected joke.  
   * The button’s `click` event is wired to this function.

Open the file in a browser and press the button to see a new joke each time!
