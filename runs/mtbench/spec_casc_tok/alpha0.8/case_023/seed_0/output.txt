In a *proper* binary tree the **highest common ancestor** of any two nodes is the **root** of the tree – it is the ancestor that is “closest to the top” of the tree.  
Consequently, if you are given the root of the tree you can simply return it:

```python
def highest_common_ancestor(root, node1, node2):
    """
    Return the highest common ancestor of node1 and node2.
    This is the root of the tree (assuming both nodes belong to the same tree).
    """
    if root is None:
        return None

    # Optional: verify that both nodes actually belong to the tree.
    # (O(n) time, O(1) space – you can skip if you trust the input.)
    if not node_in_tree(root, node1) or not node_in_tree(root, node2):
        return None

    return root
```

`node_in_tree` is a simple helper that walks the tree to find a node:

```python
def node_in_tree(root, target):
    if root is None:
        return False
    if root is target:
        return True
    return node_in_tree(root.left, target) or node_in_tree(root.right, target)
```

### Why the “not LCA” note?

> **LCA** = *Lowest Common Ancestor* – the deepest node that is an ancestor of both nodes.  
> **HCA** = *Highest Common Ancestor* – the ancestor that is *closest to the root* (i.e. the shallowest).

In a conventional binary tree, the root is the unique shallowest common ancestor of every pair of nodes, so the HCA is trivial.

---

### When would you need a more elaborate algorithm?

If you *do not* have the root available, or if you are dealing with a forest or an unrooted tree, you can find the root by climbing parent pointers (or by scanning the tree once for a node that has no parent). Below is a quick helper that finds the root given a node that has a parent pointer:

```python
def find_root_from_node(node):
    """
    Return the root of the tree given a node that has a 'parent' pointer.
    """
    while node.parent is not None:
        node = node.parent
    return node
```

If you only have a `root` pointer and *two* nodes, the answer is still the root. However, if you want the **lowest** common ancestor (the usual interview question), you can use a standard recursive solution:

```python
def lowest_common_ancestor(root, p, q):
    """
    Return the LCA of nodes p and q.
    """
    if root is None or root is p or root is q:
        return root

    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)

    if left and right:
        return root          # this node is the LCA
    return left if left else right
```

### Summary

| Problem | What you want | Typical answer |
|---------|---------------|----------------|
| Highest common ancestor (HCA) | Shallowest common ancestor | The root of the tree (or the node that has no parent). |
| Lowest common ancestor (LCA) | Deepest common ancestor | The node returned by the recursive `lowest_common_ancestor` routine. |

So if the interview explicitly says “not LCA”, the answer is simply the root of the tree. If you’re given a tree without a root pointer, climb the parent pointers until you hit `None`, and that node is the HCA.
