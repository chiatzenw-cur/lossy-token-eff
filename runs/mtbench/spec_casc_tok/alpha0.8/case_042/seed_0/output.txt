When two sorted arrays `A` and `B` are merged, the median of the combined
sequence is the *k‑th* element in the merge order, where  

```
k = (len(A)+len(B)) // 2          if the total length is odd
k = (len(A)+len(B)) // 2          and k+1          if the total length is even
```

The obvious way to obtain that element is to merge the two arrays *until
the median position is reached*.  
Because we only need to keep the current element from each array and a
few counters, the extra memory is **O(1)**.  
The algorithm visits each element at most once → **O(n)** time, where
`n = len(A)+len(B)`.

Below is a clean, self‑contained implementation in Python.  
(Any language will follow the same idea – two pointers, one pass, a few
variables.)

```python
def median_of_two_sorted_arrays(A, B):
    """
    Return the median of two sorted arrays A and B.

    Parameters
    ----------
    A : list[int] or list[float]
        First sorted array (may be empty).
    B : list[int] or list[float]
        Second sorted array (may be empty).

    Returns
    -------
    float
        The median value.  If the total length is odd the median is an
        integer (or float if the input contains floats); if even it is
        the arithmetic mean of the two middle elements.

    Raises
    ------
    ValueError
        If both arrays are empty.
    """
    m, n = len(A), len(B)
    total = m + n

    if total == 0:
        raise ValueError("Both arrays are empty")

    # Position(s) of the median element(s) in the merged order
    if total % 2:                     # odd length
        median_pos = total // 2 + 1     # 1‑based index
    else:                             # even length
        median_pos = total // 2         # 1‑based index of the first middle
        median_pos_next = median_pos + 1

    i = j = 0          # indices in A and B
    count = 0          # how many elements we have consumed
    prev = curr = None # store the last two elements

    # Merge until we reach the median position(s)
    while i < m or j < n:
        if i < m and (j >= n or A[i] <= B[j]):
            curr = A[i]
            i += 1
        else:
            curr = B[j]
            j += 1

        count += 1

        # Store the element that will be the median (or the first of the two)
        if count == median_pos:
            prev = curr            # first middle element (odd or even)
            if total % 2:          # odd case – we can return immediately
                return float(prev)

        if total % 2 == 0 and count == median_pos_next:
            # second middle element reached – compute the average
            return (prev + curr) / 2.0

    # Control should never reach here for non‑empty input
    raise RuntimeError("Logic error – median not found")
```

The algorithm is essentially a left‑to‑right merge of the two sorted
