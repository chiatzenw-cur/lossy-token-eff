The function `majority_element` returns the element that appears more than ⌊n/2⌋ times in the array.  
If the list is empty or no majority exists the function raises a `ValueError` (you can change this to any sentinel value you prefer).

```python
def majority_element(nums):
    """
    Return the majority element of the list `nums` using Boyer‑Moore voting.
    A majority element is one that appears more than ⌊len(nums)/2⌋ times.
    
    Parameters
    ----------
    nums : list[int]
        The input array.

    Returns
    -------
    int
        The majority element.

    Raises
    ------
    ValueError
        If the input list is empty or no majority element exists.
    """
    if not nums:
        raise ValueError("Input list is empty")

    # 1. Phase 1 – Find candidate
    candidate = None
    count = 0

    for num in nums:
        if count == 0:
            candidate = num
            count = 1
        elif num == candidate:
            count += 1
        else:
            count -= 1

    # 2. Phase 2 – Verify candidate (optional, required if majority
    #    might not exist)
    if nums.count(candidate) <= len(nums) // 2:
        raise ValueError("No majority element found")

    return candidate
```

### How it works

| Step | What happens | Why it works |
|------|--------------|--------------|
| **Initialization** | `candidate = None`, `count = 0` | We need a slot for the possible majority element and a counter of how many times it has "survived" the competition. |
| **Iteration** | For each `num` in `nums` | If `count` is zero we adopt the current element as a new candidate.  If the current element equals the candidate, we increment the counter; otherwise we decrement it. |
| **Candidate obtained** | After a single pass, the candidate is the one that would survive all “pair‑wise eliminations” of distinct elements. | In a sequence where a majority element exists, it can never be fully eliminated by the cancellation process, so it remains the candidate. |
| **Verification** | Count the occurrences of the candidate to confirm it occurs > n/2 times. | The algorithm guarantees a candidate, but if the array **does not** contain a majority, the candidate might be wrong. The second pass is only O(n) extra time and guarantees correctness. |

- **Time**: O(n) — one pass to find the candidate, optionally one more pass to verify.
