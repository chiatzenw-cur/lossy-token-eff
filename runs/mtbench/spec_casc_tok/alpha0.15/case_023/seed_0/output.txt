In a *single* binary tree the **highest** common ancestor of any two nodes is simply the *root* of the tree.  
The lowest common ancestor (LCA) is the *deepest* (closest to the leaves) node that is an ancestor of both, so the “highest” one is the opposite: the *closest to the root* one – i.e. the root itself.

Below is a tiny helper that enforces that the root is indeed a common ancestor of the two given nodes (it will return `None` if one of the nodes is not even in the tree).  In the usual interview setting the root is already known, so the function could just `return root`.

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def highest_common_ancestor(root: TreeNode, node1: TreeNode, node2: TreeNode) -> TreeNode:
    """
    Return the highest (root‑most) common ancestor of node1 and node2
    in a binary tree.  The result is the root of the tree if both
    nodes are present.
    """
    # Optional sanity check: make sure both nodes are in the tree
    if not (is_in_tree(root, node1) and is_in_tree(root, node2)):
        return None

    return root

def is_in_tree(root: TreeNode, target: TreeNode) -> bool:
    """Helper: true if target is in the subtree rooted at root."""
    if root is None:
        return False
    if root is target:
        return True
    return is_in_tree(root.left, target) or is_in_tree(root.right, target)
```

### Why this works

* Any node in a binary tree is an ancestor of itself, so if both `node1` and `node2` are in the tree, the root is a common ancestor.
* The root is the *highest* (i.e., shallowest) node in the tree, so it is the highest common ancestor by definition.
* There is no deeper common ancestor above the root, so the root is the unique answer.

If you’re working in an environment where you already know the root (as you usually do), you can drop the `is_in_tree` check and simply return `root`:

```python
def highest_common_ancestor(root, node1, node2):
    return root
```

And that’s it – the highest common ancestor of any two nodes in a binary tree is the root.
