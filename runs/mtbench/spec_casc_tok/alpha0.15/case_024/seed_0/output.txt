The trick is to *mark* an element of the second array once it has been matched so that it is not counted again – this is a pure in‑place modification.

---

## 1.  Algorithm (without extra storage)

```
for i = 0 … n-1
        for j = 0 … m-1
                if arr1[i] == arr2[j]
                        print arr1[i]
                        arr2[j] = SENTINEL          // <‑‑ mark it
                        break                       // no need to keep searching this arr1[i]
```

* **SENTINEL** – a value that is guaranteed **not** to appear in the input (e.g. `INT_MAX`, `INT_MIN`, or a very large number).  
  Because we overwrite the matched element, the second array is still of the same size, and we never allocate another array, list, or hash table.

* In the worst case, every element of `arr1` is compared against every element of `arr2`:  
  **Time complexity**: `O(n · m)`  
  **Space complexity**: `O(1)` (only the input arrays)

---

## 2.  Edge‑case handling

| Situation | What the code does |
|-----------|-------------------|
| Duplicate values in **arr1** | Each duplicate is compared against **arr2**; if a duplicate has already been matched, the sentinel in **arr2** prevents it from being matched again. |
| Duplicate values in **arr2** | The first match consumes one of the duplicates; the following duplicates stay untouched and can be matched only if another element of **arr1** equals them. |
| Empty array | If either array is empty, the nested loops simply never enter, so nothing is printed. |
| SENTINEL already present in input | The program would incorrectly skip that value.  In practice you can choose a sentinel that is outside the allowed input range or arbitrarily large (e.g. `INT_MAX`), or you can pre‑check and adjust if needed. |

## 3.  Full C++ implementation

```cpp
#include <iostream>
#include <vector>
#include <climits>   // for INT_MAX

int main() {
    // --- read input -------------------------------------------------------
    int n, m;
    std::cout << "Enter size of first array: ";
    std::cin >> n;
    std::vector<int> arr1(n);
    std::cout << "Enter " << n << " elements:\n";
    for (int i = 0; i < n; ++i) {
        std::cin >> arr1[i];
    }

    std::cout << "Enter size of second array: ";
    std::cin >> m;
    std::vector<int> arr2(m);
    std::cout << "Enter " << m << " elements:\n";
    for (int i = 0; i < m; ++i) {
        std::cin >> arr2[i];
    }

    // --- find common elements without extra DS ----------------------------
    const int SENTINEL = INT_MAX;          // choose a value outside the input range
    std::cout << "Common elements: ";
    bool first = true;                     // for pretty printing

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            if (arr1[i] == arr2[j]) {
                if (!first) std::cout << ' ';
                std::cout << arr1[i];
                first = false;
                arr2[j] = SENTINEL;         // mark this arr2 element
                break;                      // move to next arr1 element
            }
        }
    }
    std::cout << '\n';
    return 0;
}
```

## 4.  Alternative: **Sorting + two‑pointer**

If you do not mind rearranging the input arrays, a more efficient `O(n log n + m log m)` solution is:

1. Sort `arr1` and `arr2` in place (e.g. `std::sort`).
2. Use two indices `i` and `j` to walk through the sorted arrays simultaneously.
3. Whenever `arr1[i] == arr2[j]`, print the value and advance both; otherwise advance the smaller one.

This still uses only the input arrays and no extra storage.  
The present solution, however, obeys the literal “no extra data structures” requirement while keeping the implementation simple.
