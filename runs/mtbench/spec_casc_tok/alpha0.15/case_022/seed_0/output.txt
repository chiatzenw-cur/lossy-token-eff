```cpp
// fib_recursive.cpp
#include <iostream>
#include <cstddef>   // for std::size_t
#include <limits>   // for std::numeric_limits

// ---------------------------------------------------------------------------
// Recursive Fibonacci
// ---------------------------------------------------------------------------
// fib(n) returns the nth Fibonacci number (0‑based indexing: fib(0)=0, fib(1)=1)
constexpr std::size_t fib(std::size_t n)
{
    if (n == 0) return 0;          // first Fibonacci number
    if (n == 1) return 1;          // second Fibonacci number
    return fib(n - 1) + fib(n - 2); // recursive definition
}

// ---------------------------------------------------------------------------
// Main
// ---------------------------------------------------------------------------
int main()
{
    std::size_t n;

    std::cout << "Enter n (0‑based index): ";
    if (!(std::cin >> n))
    {
        std::cerr << "Invalid input!\n";
        return 1;
    }

    // Warning: recursion depth grows with n, and the method is exponential
    // in time. For n > 40 it will be noticeably slow.
    if (n > 92)
    {
        std::cerr << "Warning: with n > 92, the result will overflow a 64‑bit integer.\n";
    }

    std::cout << "Fib(" << n << ") = " << fib(n) << '\n';
    return 0;
}
```

### How it works

1. **Base cases**  
   * `fib(0)` returns `0`.  
   * `fib(1)` returns `1`.  
   These are the first two numbers of the Fibonacci sequence.

2. **Recursive step**  
   For all other `n`, the function calls itself twice:
   ```cpp
   fib(n - 1) + fib(n - 2)
   ```
   which, by definition, returns the nth Fibonacci number.

3. **Usage**  
   Compile with a C++ compiler (e.g. `g++ -std=c++17 fib_recursive.cpp -o fib`), run it, and provide the desired index `n`. The program prints the result.

> **Note:**  
> This is the classic recursive implementation. Its time complexity is *O(2ⁿ)*, so it becomes impractical for large `n`. For production code you would normally use an iterative or memoized version, but for educational purposes the plain recursion is great to see the direct translation of the mathematical definition.
