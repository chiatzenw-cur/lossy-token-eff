Copy the code into a file named `index.html` and open it in a browser.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Random Joke Generator</title>
<style>
  body {font-family: Arial, sans-serif; text-align: center; margin-top: 2rem;}
  #joke {margin-top: 1rem; font-size: 1.2rem; color:#333;}
  button {padding: 0.6rem 1.2rem; font-size: 1rem; cursor: pointer;}
</style>
</head>
<body>

<h1>Need a Laugh?</h1>
<button id="jokeBtn">Tell me a joke!</button>
<p id="joke"></p>

<script>
  // Array of jokes
  const jokes = [
    "Why don’t skeletons fight each other? They don’t have the guts.",
    "Parallel lines have so much in common… it’s a shame they’ll never meet.",
    "I told my wife she was drawing her eyebrows too high. She looked surprised.",
    "What do you call a fake noodle? An impasta."
  ];

  // Grab DOM elements
  const btn = document.getElementById('jokeBtn');
  const jokeEl = document.getElementById('joke');

  // Function to show a random joke
  function showRandomJoke() {
    const randomIndex = Math.floor(Math.random() * jokes.length);
    jokeEl.textContent = jokes[randomIndex];
  }

  // Attach event listener
  btn.addEventListener('click', showRandomJoke);
</script>

</body>
</html>
```

**How it works**

1. The page contains a button (`#jokeBtn`) and a paragraph (`#joke`) where the joke will appear.  
2. A JavaScript array (`jokes`) holds the four jokes.  
3. When the button is clicked, the `showRandomJoke` function picks a random index, picks the corresponding joke, and updates the paragraph’s text.
