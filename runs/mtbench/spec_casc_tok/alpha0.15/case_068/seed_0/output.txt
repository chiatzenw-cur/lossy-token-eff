<|end|><|start|>assistant<|channel|>final<|message|>**Idea**

Both lists are already sorted.  
We can walk through them in the same way we merge two sorted arrays, but we stop as soon as we have seen the first *k* elements.  
The element that we “take” in the *k*‑th step is exactly the *k*‑th smallest element of the union.

**Pseudo‑code**

```
function kth_smallest(A[0..m-1], B[0..n-1], k):
    i ← 0          // index in A
    j ← 0          // index in B
    while k > 0:
        if i == m:
            return B[j + k - 1]          // A is exhausted
        if j == n:
            return A[i + k - 1]          // B is exhausted
        if A[i] <= B[j]:
            i ← i + 1
        else:
            j ← j + 1
        k ← k - 1
    // k == 0 – the last element we took is the answer
    return (A[i-1] if A[i-1] <= B[j-1] else B[j-1])
```

**Complexity**

- Every iteration moves one pointer forward.  
- At most `k` increments are performed, so the running time is `O(k)`.  
- In the worst case (when `k` is larger than the size of the smaller list) we may need to visit all `m + n` elements, giving `O(m + n)` time.  
- The algorithm uses only a few integer variables → `O(1)` extra space.

**Python implementation**

```python
def kth_smallest_union(A, B, k):
    """
    Return the k-th smallest element (1‑based) in the union of
    two sorted lists A and B.

    Parameters
    ----------
    A : list[int]
        First sorted list (non‑decreasing order).
    B : list[int]
        Second sorted list (non‑decreasing order).
    k : int
        1‑based index of the desired element.
        Must satisfy 1 <= k <= len(A) + len(B).

    Returns
    -------
    int
        The k‑th smallest element.
    """
    m, n = len(A), len(B)
    i = j = 0        # current positions in A and B

    while k > 0:
        # If one list is exhausted, the answer is in the other list
        if i == m:
            return B[j + k - 1]
        if j == n:
            return A[i + k - 1]

        # Choose the smaller current element
        if A[i] <= B[j]:
            i += 1
        else:
            j += 1
        k -= 1

    # Should never reach here because the loop returns when k == 0
    # but putting a safe fallback is good practice.
    raise RuntimeError("k is out of bounds")
```

**Example**

```python
A = [1, 3, 5, 7]
B = [2, 4, 6, 8, 9]
print(kth_smallest_union(A, B, 5))   # → 5
print(kth_smallest_union(A, B, 8))   # → 8
```

The function works for any two sorted lists, including empty ones, and runs in linear time with respect to the size of the output (`k`) or the total size of the two lists.
