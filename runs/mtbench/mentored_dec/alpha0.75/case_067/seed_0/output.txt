## 1.  The formula

A *full* (proper) binary tree has the property that every internal vertex has **exactly two** children,  
so the number of vertices is always **odd**.  
Let  

```
n = 2k + 1   (k = number of internal nodes, 0 ≤ k ≤ (n-1)/2)
```

The number of full binary trees with `n` vertices is the Catalan number `C_k`:

```
B_n = C_k = (1/(k+1)) * binom(2k, k)     ,   if   n = 2k+1
B_n = 0                                   ,   if   n is even
```

The Catalan number can be obtained directly via a binomial‑coefficient (fast, but
needs exact arithmetic) or via a small dynamic‑programming recurrence.

```
B1 = 1          # only the single leaf
B_odd = Σ B_i * B_{n-1-i}   (i odd)   for n ≥ 3
```

Both approaches are simple, but the DP version is numerically stable and works even for
large `n` where the factorial‑based formula can overflow the intermediate
(`(2k)!`) when using standard floating‑point arithmetic.

---

## 2.  Implementation – DP (most straightforward)

```python
def B_n(n: int) -> int:
    """
    Return the number of full binary trees with exactly n vertices.

    Parameters
    ----------
    n : int
        Total number of vertices. Must be non‑negative.

    Returns
    -------
    int
        Number of full binary trees. 0 if n is even.
    """
    if n < 0:
        raise ValueError("n must be non‑negative.")
    if n == 0:
        return 0  # no vertices -> no full tree
    if n % 2 == 0:      # even number of vertices → impossible
        return 0
    # DP array: dp[i] will hold B_i for all i ≤ n
    dp = [0] * (n + 1)
    dp[1] = 1          # single leaf
    # Only odd indices are required; the rest stay 0
    for size in range(3, n + 1, 2):          # jump by 2 (odd sizes)
        total = 0
        # root splits tree into left and right subtrees
        # left_size = odd, right_size = size - 1 - left_size  (also odd)
        left_size = 1
        while left_size < size:
            right_size = size - 1 - left_size
            total += dp[left_size] * dp[right_size]
            left_size += 2
        dp[size] = total
    return dp[n]
```

### Why this works

* Every full binary tree has a **root** that has 2 children.  
  The *root* consumes 1 vertex; the remaining `n-1` vertices are split into two sub‑trees.
* The left subtree can have any odd vertex count `i` (including 1 for a leaf),
  and the right subtree must have `n-1-i` vertices – also odd.  
  Thus the recurrence `dp[n] = Σ_{i odd} dp[i] * dp[n-1-i]` is correct.
* We only iterate over odd indices (`size` 3, 5, …) because even sizes are impossible.

## 3.  Optional – direct Catalan evaluation

If you want the fastest possible solution for a moderate range `n` (say up to 1000)
you can use the binomial‑coefficient formula directly:

```python
import math

def B_n_catalan(n: int) -> int:
    if n < 0:
        raise ValueError("n must be non‑negative")
    if n % 2 == 0:
        return 0
    k = (n - 1) // 2
    return math.comb(2*k, k) // (k+1)
```

`math.comb` returns exact integer binomial coefficients, so the division at the end
is integer division.  
Both `B_n` and `B_n_catalan` give the same answer; use the one that fits the
language and library constraints you have.

## 4.  Complexity analysis

* **Time** – `O(n)` for the DP version (`n` is the number of vertices).  
  Each odd size does a linear scan over the smaller odd sizes, totaling `O(n)` operations.
* **Space** – `O(n)` for the DP table (`dp`).
* **Catalan** – the closed form runs in `O(k)` time for the binomial coefficient
  (Python’s `math.comb` uses fast algorithms) but the DP will also be extremely fast.
