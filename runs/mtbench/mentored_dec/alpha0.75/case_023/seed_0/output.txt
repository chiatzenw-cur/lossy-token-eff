In a (non‑empty) binary tree there is *exactly one* node that is an ancestor of every
other node – the root.  
Therefore the **highest common ancestor** of **any two nodes** is simply the
root.  
(You can think of “highest” as “closest to the root” – i.e. the “highest” (topmost)
node in the tree.)

So the function needs only to return the root node that the tree is built
with.  
Below is a compact implementation that also shows how to recover the root
if the nodes you are given don’t have a parent pointer.

```python
# ------------------------------------------------------------------
# Node definition (classic binary tree)
# ------------------------------------------------------------------
class Node:
    __slots__ = ('val', 'left', 'right', 'parent')

    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
        self.parent = None
        # set parents for the children
        if self.left:
            self.left.parent = self
        if self.right:
            self.right.parent = self

# ------------------------------------------------------------------
# Helper: find the root of a node that may have a parent pointer.
# ------------------------------------------------------------------
def find_root(node: Node) -> Node:
    """Return the root of the tree containing `node`."""
    while node.parent is not None:
        node = node.parent
    return node

# ------------------------------------------------------------------
# Highest common ancestor (root)
# ------------------------------------------------------------------
def highest_common_ancestor(node1: Node, node2: Node) -> Node:
    """
    Returns the highest common ancestor of two nodes.
    Since the root is the single node that is an ancestor of *every* node,
    the answer is simply the root.
    """
    # The root is the same regardless of which node you start from.
    return find_root(node1)

# ------------------------------------------------------------------
# Example usage
# ------------------------------------------------------------------
if __name__ == "__main__":

    # Build a simple tree
    #
    #          1
    #        /   \
    #       2     3
    #      / \   /
    #     4   5 6
    #
    n4, n5, n6 = Node(4), Node(5), Node(6)
    n2 = Node(2, n4, n5)
    n3 = Node(3, n6)
    root = Node(1, n2, n3)

    # Find the highest common ancestor of 4 and 5
    hca = highest_common_ancestor(n4, n5)
    print(f"Highest common ancestor of {n4.val} and {n5.val} is {hca.val}")
    # → Highest common ancestor of 4 and 5 is 1

    # Likewise, for any two nodes:
    hca = highest_common_ancestor(n2, n6)
    print(f"Highest common ancestor of {n2.val} and {n6.val} is {hca.val}")
    # → Highest common ancestor of 2 and 6 is 1
```

**Explanation**

1. **Finding the root.**  
   If a node has a `parent` reference, we walk up the parent chain until the
   parent is `None`.  The resulting node is the **root**.

2. **Returning the highest common ancestor.**  
   Because the root is the only ancestor common to *every* node, the answer
   is always the root.  
   No search, comparison, or stack traversal is required (the runtime is
   `O(1)`).

3. **Robustness.**  
   If you only have access to the nodes (and no explicit root), the helper
   `find_root` guarantees that the returned node is the true root, even if
   the two nodes come from different subtrees, or one of the nodes is the
   root itself.

That’s all! The “highest” common ancestor is, in a binary tree, the root. If you ask for any other ancestor, you’re looking at the *lowest* common ancestor (LCA).
