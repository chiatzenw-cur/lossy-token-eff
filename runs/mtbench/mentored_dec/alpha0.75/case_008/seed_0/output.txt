The algorithm runs in two passes:
1. **Candidate selection** – the “vote” phase.  
2. **Verification** – confirm the candidate is indeed the majority.

### 1. Python Implementation

```python
def majority_element(nums):
    """
    Return the majority element (the element that appears more than ⌊n/2⌋ times)
    in the integer array `nums`.  If no majority element exists, return None.

    The function is a direct implementation of the Boyer‑Moore Voting Algorithm.
    """
    if not nums:
        return None

    # 1. Candidate selection
    candidate = None
    count = 0
    for x in nums:
        if count == 0:
            candidate = x
            count = 1
        elif x == candidate:
            count += 1
        else:
            count -= 1

    # 2. Verify the candidate
    if nums.count(candidate) > len(nums) // 2:   # 2⌊k/2⌋ + 1 semantics
        return candidate
    return None       # no majority element

# ---------------------------------------------------
# Example usage
if __name__ == "__main__":
    arr = [2, 1, 2, 2, 3, 2, 2]
    print(majority_element(arr))  # Output: 2

    arr = [1, 2, 3, 4]    # no majority
    print(majority_element(arr))  # Output: None
```

**Why the verification step?**  
The Boyer‑Moore algorithm guarantees that *if a majority element exists*, the final candidate will be that element.  
If the array is guaranteed to contain a majority, you can skip the verification step, but checking it is O(n) anyway, so it’s a small safety net.

### 2. Java Implementation

```java
public class MajorityElement {
    public static Integer majorityElement(int[] nums) {
        if (nums == null || nums.length == 0) return null;

        // 1. Candidate selection
        int candidate = nums[0];
        int count = 1;
        for (int i = 1; i < nums.length; i++) {
            if (count == 0) {
                candidate = nums[i];
                count = 1;
            } else if (nums[i] == candidate) {
                count++;
            } else {
                count--;
            }
        }

        // 2. Verify (optional)
        int freq = 0;
        for (int x : nums) {
            if (x == candidate) freq++;
        }
        return (freq > nums.length / 2) ? candidate : null;
    }

    public static void main(String[] args) {
        int[] arr = {1, 1, 2, 1, 2, 1, 3};
        System.out.println(majorityElement(arr));   // prints 1
    }
}
```

### 3. C++ Implementation

#include <vector>
#include <iostream>

int majorityElement(const std::vector<int>& nums) {
    if (nums.empty()) return -1; // sentinel; adjust to Optional if you prefer

    // 1. Candidate selection
    int candidate = nums[0];
    int count = 1;
    for (size_t i = 1; i < nums.size(); ++i) {
        if (count == 0) {
            candidate = nums[i];
            count = 1;
        }
        else if (nums[i] == candidate) {
            ++count;
        }
        else {
            --count;
        }
    }

    // 2. Verify (optional)
    int freq = 0;
    for (int x : nums) if (x == candidate) ++freq;
    if (freq > nums.size() / 2) return candidate;
    return -1;      // sentinel for “not found”
}

int main() {
    std::vector<int> arr  = {2, 1, 2, 2, 3, 2, 2};
    std::cout << majorityElement(arr) << '\n'; // 2
}

### ✅ How the Algorithm Works

1. **Pass 1 – Guess the majority**  
   - Keep a counter (`count`).  
   - When the counter is `0`, pick the current element as the new candidate.  
   - If the current element matches the candidate, increment a counter; otherwise decrement it.  
   - The idea: a true majority element will survive all pairwise cancellations, ending with a counter > 0.

2. **Pass 2 – Verify**  
   - If the array is guaranteed to contain a majority, you can skip this.  
   - Otherwise, counting the candidate’s occurrences will confirm whether it indeed exceeds `n/2`.  
   - Complexity: O(n) time, O(1) additional space.

---

#### Common Pitfalls

| Issue | Fix |
|-------|-----|
| **Wrong frequency check** | Use `if (freq > n/2)` for strict majority (`> n/2`) or `>= (n + 1) / 2` for ≥. |
| **Empty array** | Return `None`/`null`/`-1` or throw an exception. |
| **No majority element** | Return an explicit sentinel value or a `Optional` type. |
