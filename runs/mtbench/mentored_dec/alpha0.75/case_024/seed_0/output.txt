The task is to output all values that appear in **both** of two given arrays.  
The catch: *we cannot use extra data structures* (no hash **set**, no another array, no sorting helper, etc.).  
We can still use the arrays themselves (they are allowed to be modified) and a few scalar variables – that’s all the “extra” we really need.

The classic way to find common elements without allocating extra storage is:

1. Sort both arrays *in place* – the standard `std::sort` (or `qsort` in C) does not need any additional memory besides the input array itself.
2. Walk the two sorted arrays in a single pass with two pointers – each pointer moves only forward, so the algorithm runs in linear time after the sort.

This satisfies the constraint because we never allocate an second buffer, only the two integer counters (`i` and `j`).

---

### Algorithm (C++)

```cpp
// read two arrays a and b
// sort a and b
// use two indices i and j
//   while i < n and j < m
//       if a[i] == b[j]  →  print a[i], i++, j++
//       else if a[i] < b[j]  →  i++
//       else                 →  j++
```

Because the arrays are sorted, the only way two numbers can be equal is if the same value appears in both arrays, so the pointer “matching” step is exact.

---

### Correctness Proof  

We prove that the algorithm prints **exactly** the common elements.

---

#### Lemma 1  
After sorting, for each array the order of elements is non‑decreasing.

**Proof.**  
`s.sort()` is an in‑place comparison based sort that guarantees an output in non‑decreasing order. ∎



#### Lemma 2  
During the scan, if the algorithm prints a value `x`, then `x` appears in both arrays.

**Proof.**  
`x` is printed only when `a[i] == b[j]`.  
Because of Lemma&nbsp;1, arrays are sorted, so each equality comparison holds only when the current elements of both arrays are equal.  
Thus the same value appears in both arrays. ∎



#### Lemma 3  
Every common value `x` is printed at least once.

**Proof.**

Let `x` be removed from the arrays.  
Let the first position (`p`) of `x` in the sorted array `a` be `i` (maybe some earlier elements might be equal to `x` as well).  
Let `q` be the first position of `x` in the sorted array `b` be `j`.

During the scan, at the beginning we have `i < p` and `j < q`.
If `a[i] < b[j]` we move `i` forward, otherwise we move `j` forward.
Because `i` and `j` only move forward, after enough steps the pointers will hit the values `x` at positions `p` and `q`.
At that point `a[i] == b[j]` and the algorithm prints `x`. ∎



#### Theorem  
The algorithm prints a value if and only if that value is common to the two input arrays.

**Proof.**  

*If* part: Lemma&nbsp;2.  
*Only if* part: Lemma&nbsp;3.  
Thus the algorithm is correct. ∎

### Complexity Analysis

Let `n = |a|`, `m = |b|`.

*Sorting*: `O(n log n)` and `O(m log m)`  
*Scanning*: `O(n + m)`  

The dominating term is the sorting time:  
`T(n, m) = O(n log n + m log m)`  

The memory consumption is `O(1)` auxiliary space because we only maintain two indices and read the input arrays in place.

### Reference Implementation (C++17)

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    /* ---------- input ---------- */
    int n, m;
    if (!(cin >> n >> m)) return 0;

    vector<int> a(n), b(m);
    for (int i = 0; i < n; ++i) cin >> a[i];
    for (int i = 0; i < m; ++i) cin >> b[i];

    /* ---------- algorithm ---------- */
    sort(a.begin(), a.end());  // in‑place, no extra data structures
    sort(b.begin(), b.end());  // in‑place

    size_t i = 0, j = 0;
    bool first = true;          // to format output nicely

    while (i < a.size() && j < b.size()) {
        if (a[i] == b[j]) {
            if (!first) cout << ' ';
            cout << a[i];
            first = false;
            ++i; ++j;
        } else if (a[i] < b[j]) {
            ++i;
        } else {
            ++j;
        }
    }

    /* ---------- output ---------- */
    if (first)  // no common element found
        cout << "No common elements";

    cout << '\n';
    return 0;
}
```
