A classic linear‑time, constant‑space algorithm for finding the *majority* element (an element that occurs more than `n//2` times) in an array.

### How it works
1. **Candidate Selection**  
   Iterate through the array, keeping a *candidate* and a *counter*.
   * If the counter is `0`, set the current element as the new candidate.
   * If the current element equals the candidate, increment the counter.
   * Otherwise, decrement the counter.

   After one pass, if a majority element exists, the candidate will be that element.

2. **Verification (optional)**  
   The algorithm guarantees that the candidate is the majority **only if** a majority element exists.  
   A second pass (or counting the occurrences of the candidate) can be used to confirm that it indeed appears more than `n//2` times.

### Complexity
- **Time:** `O(n)` – one or two linear scans
- **Space:** `O(1)` – only a few variables, regardless of input size

### Python implementation

```python
def majority_element(nums):
    """
    Return the majority element of the given list.
    If no majority element exists, returns None.

    :param nums: List[int] – the input array
    :return: int | None – the majority element or None if none exists
    """
    # 1. Find candidate
    candidate = None
    count = 0
    for x in nums:
        if count == 0:
            candidate = x
            count = 1
        elif x == candidate:
            count += 1
        else:
            count -= 1

    # 2. Verify candidate (optional, ensures correctness if problem guarantees a majority)
    if candidate is not None:
        if nums.count(candidate) > len(nums) // 2:
            return candidate
    return None
```

### Example usage

```python
print(majority_element([3, 3, 4, 2, 3, 3, 3]))        # → 3
print(majority_element([1, 2, 3, 4, 5]))            # → None
print(majority_element([2, 2, 1, 1, 2, 2, 2, 1, 2])) # → 2
```

- **When a majority element is guaranteed** (e.g., some coding interview questions state that the input always has a majority element), you can skip the verification step for a tiny speed improvement.
- **If you want to support “no majority”** explicitly, keep the verification as shown.
- The algorithm works for any type that supports equality comparison, not just integers.
