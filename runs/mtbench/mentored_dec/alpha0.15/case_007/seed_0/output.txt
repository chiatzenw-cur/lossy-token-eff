Let's answer accordingly.<|end|><|start|>assistant<|channel|>final<|message|>Below is a **stand‑alone Python 3 script** that:

1. Accepts a directory path from the command line (or uses the current directory if none is supplied).  
2. Recursively walks that directory to find every file that ends with `.txt`.  
3. Reads each file, normalises the text (lower‑case, punctuation stripped, “words” defined as contiguous alphanumerics + underscore), and counts every word.  
4. Prints the **top‑5 most frequent words** together with their counts.

Feel free to copy the code into a file called, e.g., `top_words.py` and run it with `python top_words.py [<directory>]`.

```python
#!/usr/bin/env python3
"""
top_words.py – Find the 5 most frequent words in all .txt files below a directory.

Usage:
    python top_words.py          # uses the current working directory
    python top_words.py /path/to/dir

"""

import argparse
import collections
import pathlib
import re
import sys

# ----------------------------------------------------------------------
# Helper functions
# ----------------------------------------------------------------------
def word_iter_from_text(text: str):
    """
    Yield words from a block of text.

    Words are defined as runs of letters, numbers or underscores.
    The function normalises everything to lower case.
    """
    for match in re.finditer(r'\b\w+\b', text.lower()):
        yield match.group()

def process_file(path: pathlib.Path, counter: collections.Counter):
    """
    Read a single file and update the provided Counter with its words.
    """
    try:
        # Read the whole file – text files are usually small enough for this.
        raw = path.read_text(encoding='utf-8')
    except UnicodeDecodeError:
        # If utf‑8 fails, fall back to latin1 (older Windows‑encoded txt files)
        raw = path.read_text(encoding='latin1')
    except Exception as exc:
        # Skip files that we cannot read for any reason.
        print(f"[WARN] Could not read {path}: {exc}", file=sys.stderr)
        return

    counter.update(word_iter_from_text(raw))

def walk_txt_files(base_dir: pathlib.Path):
    """
    Generator yielding every .txt file under base_dir (recursively).
    """
    for path in base_dir.rglob('*.txt'):
        if path.is_file():
            yield path

# ----------------------------------------------------------------------
# Main routine
# ----------------------------------------------------------------------
def main():
    parser = argparse.ArgumentParser(
        description="Show the top‑5 most frequent words in all .txt files "
                    "under a given directory."
    )
    parser.add_argument(
        'directory',
        nargs='?',
        default='.',
        help='Target directory (default: current working directory)'
    )
    args = parser.parse_args()

    base_dir = pathlib.Path(args.directory).expanduser().resolve()
    if not base_dir.is_dir():
        print(f"[ERROR] {base_dir!s} is not a directory.", file=sys.stderr)
        sys.exit(1)

    word_counter = collections.Counter()

    # Walk the directory tree
    for txt_file in walk_txt_files(base_dir):
        process_file(txt_file, word_counter)

    if not word_counter:
        print("No .txt files found or no words extracted.")
        return

    top5 = word_counter.most_common(5)

    print("Top‑5 words across all .txt files:")
    for rank, (word, count) in enumerate(top5, start=1):
        print(f"{rank:>2}. {word:>15} : {count:,}")

# ----------------------------------------------------------------------
# Entry point
# ----------------------------------------------------------------------
if __name__ == '__main__':
    main()
```

### How it works

| Step | What happens | Why it matters |
|------|--------------|----------------|
| **Argument parsing** | Uses `argparse` – a familiar way to give the script a directory or accept the default `.` | Gives flexibility; the script keeps private to every user’s needs |
| **Directory walk** | `Path.rglob('*.txt')` yields every `.txt` file, recursive. | Simple & fast; no need to manage `os.walk` manually |
| **Reading files** | `path.read_text()` with UTF‑8, falling back to Latin‑1 if the file isn't encoded in UTF‑8. | Handles unusual encodings without crashing |
| **Word extraction** | Regular expression `\b\w+\b` captures alphanumeric words (digits, letters, underscore). Lower‑casing produces case‑insensitive counting. | Precision and speed – regex is compiled automatically and runs in C |
| **Counting** | `collections.Counter` aggregates all words in a single pass. | Extremely fast and memory‑efficient up to millions of words |
| **Output** | `most_common(5)` returns the five most frequent words and their counts. | Human‑friendly formatting with commas for counts |

### Things you might want to tweak

* **Different word definition** – change the regex (e.g. include apostrophes, hyphens).  
* **Stop‑words filtering** – `word_counter` can be filtered before printing.  
* **More output** – `most_common()` accepts any `n`; just pass a variable instead of `5`.  
* **Verbose mode** – add a `--verbose` flag that prints which files are being processed.
