A *full* binary tree is one in which every vertex has **either 0 or 2 children**.  
For such a tree

```
#leaves = #internal nodes + 1
#vertices = #leaves + #internal nodes
           = 2 * (#internal nodes) + 1
```

Hence the number of vertices must be **odd**.  
Let  

```
n = 2·k + 1          (k = number of internal nodes)
```

The number of different full binary trees with `k` internal nodes is the
*k‑th Catalan number*:

```
Ck = (1/(k+1)) * binom(2k, k)
```

So

```
B_n = 0                      if n is even
B_n = Ck   with k = (n-1)/2   otherwise
```

Below is a compact implementation in Python that uses the closed form
of the Catalan numbers (no binomial‑library needed) and runs in *O(k)*
time and *O(1)* memory.

```python
from math import comb   # Python 3.8+: optional, used only if you prefer
from functools import lru_cache

def B_n(n: int) -> int:
    """Return the number of full binary trees with n vertices."""
    if n <= 0 or n % 2 == 0:              # 0 vertices or even number → impossible
        return 0

    k = (n - 1) // 2                      # number of internal nodes

    # ---- approach 1: direct Catalan formula --------------------------------
    # Ck = binom(2k, k) // (k + 1)
    # If you have a binomial‑coefficient routine you could write:

    # return comb(2*k, k) // (k + 1)

    # ---- approach 2: iterative product (avoids factorial/large binom) -------
    res = 1
    for i in range(1, k + 1):
        # res = res * (2*(2*i-1)) // (i+1)
        # unravel for clarity:
        res = res * (2 * (2 * i - 1)) // (i + 1)

    return res
```

**Examples**

```python
>>> B_n(1)   # one vertex: a single node
1
>>> B_n(3)   # 3 vertices: root + two leaves
1
>>> B_n(5)
2
>>> B_n(7)
5
>>> B_n(10)  # even → impossible
0
```

These numbers are the Catalan sequence shifted by one level:  
`1, 1, 2, 5, 14, …` for `n = 1, 3, 5, 7, 9, …`.

### Alternative – pure DP (useful if you want to build all trees)

If you need the values for a range of `n` or prefer a dynamic‑programming
solution, this is equivalent and very straightforward:

```python
def B_n_dp(max_n: int) -> list[int]:
    """Return list of B_n for all odd n up to max_n."""
    B = [0] * (max_n + 1)
    B[1] = 1
    for size in range(3, max_n + 1, 2):          # only odd sizes
        total = 0
        # left subtree size i (odd), right size = size - i - 1 (odd)
        for i in range(1, size - 1, 2):
            total += B[i] * B[size - i - 1]
        B[size] = total
    return B
```

Usage:

```python
B = B_n_dp(13)      # get all values up to n=13
print(B[1], B[5], B[13])   # 1, 2, 42
```

Both approaches give the same answer; the product‑formula version is
preferable for a single query because it uses only O(1) storage and
O(k) time, whereas the DP version pre‑computes everything up to `max_n`.
