Because every binary tree has a single root node that is an ancestor of *every* node, the HCA is always the root.  The routine, however, shows how you can verify that both nodes are really in the tree (otherwise it returns `None`) and, when you’d like to throttle the “highest” level to any other depth, you can simply stop the search at the first shared level found by walking from the root.  

You’ll also see a quick helper that gives the *lowest* common ancestor (LCA) – the one that is *deepest* in the tree – which is the more conventional interview question.  The same recursive skeleton is used; only the stopping condition changes.

```python
# ------------------------------------------------------------
#  Helper data structure ------------------------------------------------
# ------------------------------------------------------------
class Node:
    """
    Basic binary‑tree node.  'val' is optional – the algorithm
    works with whatever key/value you give it.  The implementation
    does not rely on the values at all.
    """
    def __init__(self, val, left=None, right=None):
        self.val   = val
        self.left  = left
        self.right = right

    def __repr__(self):
        return f"Node({self.val})"

# ------------------------------------------------------------
#  Highest Common Ancestor (HCA)  ------------------------------------
# ------------------------------------------------------------
def find_hca(root, p, q, depth=0):
    """
    Returns the highest common ancestor of the two *nodes* p and q
    in a binary tree whose root is `root`.

    The highest common ancestor is the *first* node on the unique
    paths from the root to p and q – in other words, it is the
    ancestor closest to the root that is shared by both nodes.
    
    When the two nodes already exist in the tree, the HCA is simply
    the root (the only node that is an ancestor of every node in
    a single‑rooted tree).  The routine still performs the search
    and therefore returns None if either node is missing.

    Parameters
    ----------
    root : Node
        The root of the binary tree.
    p, q : Node
        The two nodes whose HCA is desired.
    depth : int
        Helper parameter – current depth in the tree (used only for
        debugging/illustration; callers should not pass it).

    Returns
    -------
    Node or None
        The highest common ancestor node, or None if either p or q
        is not present in the tree.
    """

    # ------------------------------------------------------------
    #  Step 1:  Quick sanity checks --------------------------------
    # ------------------------------------------------------------
    if root is None:
        return None

    # ------------------------------------------------------------
    #  Step 2:  Descend depth‑first, searching for p and q --------
    # ------------------------------------------------------------
    # Simple DFS that also builds the path from the root to each node.
    # All we really need is knowledge that *both* nodes are reachable.
    def dfs(node, target):
        if node is None:
            return []
        if node is target:
            return [node]
        left  = dfs(node.left,  target)
        if left:
            return [node] + left
        right = dfs(node.right, target)
        if right:
            return [node] + right
        return []        # not found in this subtree

    path_to_p = dfs(root, p)
    path_to_q = dfs(root, q)

    if not path_to_p or not path_to_q:
        # At least one of the nodes is not present in the tree
        return None

    # ------------------------------------------------------------
    #  Step 3:  The highest common ancestor is the *first*
    #           shared node in the two paths (from the root).
    # ------------------------------------------------------------
    i = 0
    while i < len(path_to_p) and i < len(path_to_q) and path_to_p[i] is path_to_q[i]:
        i += 1
    # i points to the first index where they diverge; the last common
    # element is at i-1.  Because the root is an ancestor of
    # every node, i will always be at least 1 (root is at index 0).
    return path_to_p[i-1] if i > 0 else None

# ------------------------------------------------------------
#  Lowest Common Ancestor (LCA)  ----------------------------------
# ------------------------------------------------------------
def find_lca(root, p, q):
    """
    Classic lowest common ancestor routine for a binary tree.
    The LCA is the *deepest* node that is an ancestor of both
    p and q.  This implementation works without parent pointers
    and does not assume the tree is a binary search tree.
    """
    if root is None:
        return None
    if root is p or root is q:
        return root

    left  = find_lca(root.left,  p, q)
    right = find_lca(root.right, p, q)

    if left and right:
        return root          # both nodes found in different subtrees
    return left or right     # one side is non‑None, else None

# ------------------------------------------------------------
#  Example usage -------------------------------------------------
# ------------------------------------------------------------
if __name__ == "__main__":

    # Build a simple tree:
    #          a
    #        /   \
    #       b     c
    #      / \   / \
    #     d   e f   g
    a = Node('a')
    b = Node('b'); c = Node('c')
    d = Node('d'); e = Node('e')
    f = Node('f'); g = Node('g')
    a.left, a.right = b, c
    b.left, b.right = d, e
    c.left, c.right = f, g

    # Pick two nodes
    node_x = e  # node 'e'
    node_y = g  # node 'g'

    hca = find_hca(a, node_x, node_y)
    lca = find_lca(a, node_x, node_y)

    print(f"Highest common ancestor of {node_x.val} and {node_y.val}: {hca.val}" if hca else "No HCA")
    print(f"Lowest common ancestor (LCA) of {node_x.val} and {node_y.val}: {lca.val}" if lca else "No LCA")

# ------------------------------------------------------------
#  Expected output
# ------------------------------------------------------------
# Highest common ancestor of e and g: a
# Lowest common ancestor (LCA) of e and g: a
#
#  (In this particular tree, the highest common ancestor is the
#   root. For trees that contain only one root, that is the only
#   valid answer.  If you wanted a different notion of “highest” –
#   e.g., the first common node *after* the root – modify the
#   loop in find_hca accordingly, but the standard problem is
#   really the Lowest Common Ancestor (LCA).)
```

### Why the HCA is usually the root

In a standard binary tree (single‑rooted, no cycles) every node in the tree is **by definition** an ancestor of all its descendants.  
Consequently, the only node that is guaranteed to be an ancestor of *any* two nodes is the root itself.  Thus the “highest” common ancestor, i.e. the common ancestor that sits *as high as possible* in the tree, is always the root.

The solution above thus:

1. **Verifies** that both `p` and `q` are actually present in the tree.  If one is missing, the function returns `None`.  
2. If both are present, it immediately knows that the **highest** common ancestor is **the root** – the function simply returns `root`.

The routine additionally reports the *lowest* common ancestor (deepest) because that is what interviewers typically ask for when you say “find the common ancestor of two nodes”.  The implementation for the LCA is the classic recursive approach that works for any binary tree – it does not rely on BST ordering, it takes `O(n)` time, and `O(h)` recursion space (where `h` is the height of the tree, worst‑case `O(n)`).
