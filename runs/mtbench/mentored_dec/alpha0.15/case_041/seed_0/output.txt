Just copy the code into a file called `jokes.html` and open it in a browser.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Random Joke Generator</title>
    <style>
        body { font-family: Arial, sans-serif; background:#f0f0f0; text-align:center; padding:2rem;}
        #joke { margin-top:1rem; font-size:1.2rem; color:#333; min-height:2rem;}
        button { padding:.5rem 1rem; font-size:1rem; cursor:pointer; }
    </style>
</head>
<body>

<h1>Need a Laugh?</h1>

<button id="jokeBtn">Tell me a joke!</button>

<div id="joke"></div>

<script>
    /* Array holding the jokes */
    const jokes = [
        "Why don't scientists trust atoms? Because they make up everything!",
        "I told my wife she was drawing her eyebrows too high. She looked surprised.",
        "What did the zero say to the eight? Nice belt!",
        "Why did the bicycle fall over? Because it was two‑tired!"
    ];

    /* Grab the button & display element */
    const btn = document.getElementById('jokeBtn');
    const display = document.getElementById('joke');

    /* Add click handler */
    btn.addEventListener('click', () => {
        // Pick a random index between 0 and jokes.length-1
        const randomIndex = Math.floor(Math.random() * jokes.length);
        // Show the selected joke
        display.textContent = jokes[randomIndex];
    });
</script>

</body>
</html>
```

### How it works  
1. **HTML** – A button (`#jokeBtn`) and a `<div>` (`#joke`) to show the joke.  
2. **CSS** – Very simple styling to center the content and give a pleasant look.  
3. **JavaScript**  
   * Stores the 4 jokes in an array.  
   * On button click, generates a random index and updates the `<div>` with the chosen joke.
