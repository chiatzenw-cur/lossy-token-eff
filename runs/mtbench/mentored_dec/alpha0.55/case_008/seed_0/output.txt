## 📌 Algorithm (Boyer‑Moore)

1. **First pass** – find a candidate  
   * Keep a counter `cnt` and a candidate `candidate`.  
   * For every element `x` in the array  
     * If `cnt == 0` → set `candidate = x` and `cnt = 1`.  
     * Otherwise, if `x == candidate` → `cnt += 1`.  
     * Else `cnt -= 1`.  
   * At the end of this pass, `candidate` is the possible majority.

2. **Second pass** – (optional but recommended) confirm that `candidate` really occurs > n/2 times.  
   * Count its occurrences.  
   * If the count ≤ n/2, the array has no majority element (you can raise an exception or return `None`).

> **Why it works**  
> Every time a different element appears, it can cancel one occurrence of the current candidate.  
> If a majority element exists, it will survive this cancellation process and become the final candidate.

## 🧑‍💻 Python implementation

```python
def majority_element(arr):
    """
    Returns the majority element (appears > n/2 times) in a list of integers.
    Raises ValueError if no majority element exists.
    
    Parameters:
        arr (list[int]): Input list of integers.

    Returns:
        int: The majority element.
    """
    if not arr:
        raise ValueError("Empty array has no majority element")

    # 1st pass – find a candidate
    candidate = None
    cnt = 0
    for num in arr:
        if cnt == 0:
            candidate = num
            cnt = 1
        elif num == candidate:
            cnt += 1
        else:
            cnt -= 1

    # 2nd pass – verify candidate
    if arr.count(candidate) > len(arr) // 2:
        return candidate
    else:
        raise ValueError("No majority element found")
```

### Example usage

```python
arr = [2, 2, 1, 1, 2, 2, 2]
print(majority_element(arr))   # Output: 2
```

If the array has no majority element, the function raises a `ValueError`.

## 🗜️ Java implementation (Java 17)

```java
public class MajorityElement {
    public static int majorityElement(int[] arr) {
        if (arr == null || arr.length == 0) {
            throw new IllegalArgumentException("Empty array");
        }

        // 1st pass – find candidate
        int candidate = 0;
        int count = 0;
        for (int num : arr) {
            if (count == 0) {
                candidate = num;
                count = 1;
            } else if (num == candidate) {
                count++;
            } else {
                count--;
            }
        }

        // 2nd pass – verify
        int verify = 0;
        for (int num : arr) {
            if (num == candidate) {
                verify++;
            }
        }
        if (verify > arr.length / 2) {
            return candidate;
        } else {
            throw new IllegalStateException("No majority element found");
        }
    }

    public static void main(String[] args) {
        int[] arr = {2, 2, 1, 1, 2, 2, 2};
        System.out.println(majorityElement(arr));  // prints 2
    }
}
```

| Language | Time | Space |

**Tip:** If you’re guaranteed that a majority element exists, you can skip the second pass or just return the candidate.  
If you only need the 50 % threshold, you can test the count in a single pass by incrementally checking after each element (`if (arr[i] == candidate) count++ else ...`).
