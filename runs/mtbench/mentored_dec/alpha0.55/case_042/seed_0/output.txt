The task is to compute the median of two *already sorted* arrays  
`A` and `B` (their lengths may differ).  
The algorithm must use only a constant amount of extra memory and run in linear time.

The classic merge–step of merge‑sort gives us a “virtual” merged list without
creating a new list:

```
A:  1  3  5  7
B:  2  4  6  8  10
```

During the merge we keep a running count `k` of how many elements have
been seen.  
When `k` equals the median position(s) we can stop – no further
elements are required.  
Because we only keep two indices, the count, and a few temporary variables,
the space consumption is **O(1)**.

### Algorithm
```
median_sorted_arrays(A, B):
    n1 = len(A); n2 = len(B)
    total = n1 + n2
    if total == 0:          # optional – depends on the spec
        raise ValueError("Both arrays are empty")

    # Determine target positions (1‑based)
    #   odd : only one middle element
    #   even: the two middle elements
    if total % 2 == 1:
        target = total // 2 + 1     # middle element
    else:
        target1 = total // 2
        target2 = target1 + 1

    i = j = 0          # indices in A and B
    count = 0
    median1 = median2 = None

    while count < (target2 if total % 2 == 0 else target):
        # pick the next element in merge order
        if i < n1 and (j >= n2 or A[i] <= B[j]):
            val = A[i]
            i += 1
        else:
            val = B[j]
            j += 1

        count += 1

        if total % 2 == 1:                # odd total
            if count == target:
                return val
        else:                             # even total
            if count == target1:
                median1 = val
            if count == target2:
                median2 = val
                return (median1 + median2) / 2.0
```

Complexity  
- **Time** – Every element of the two arrays is examined at most once,
  therefore `O(n1 + n2)` (i.e., `O(n)` where `n` = total size).  
- **Space** – Only a few integer variables are used: `O(1)`.

### Python Implementation

```python
def median_sorted_arrays(A: list, B: list) -> float:
    """
    Return the median of two sorted arrays A and B.
    The algorithm runs in O(len(A)+len(B)) time and uses O(1) extra space.
    """
    n1, n2 = len(A), len(B)
    total = n1 + n2

    if total == 0:
        raise ValueError("Both arrays are empty – median undefined")

    # Determine the required position(s)
    if total % 2 == 1:
        target = total // 2 + 1      # 1‑based kth element
    else:
        target1 = total // 2
        target2 = target1 + 1

    i = j = 0          # indices in A and B
    count = 0
    median1 = median2 = None

    while count < (target2 if total % 2 == 0 else target):
        # Pick the next element from A or B
        if i < n1 and (j >= n2 or A[i] <= B[j]):
            val = A[i]
            i += 1
        else:
            val = B[j]
            j += 1

        count += 1

        if total % 2 == 1:                  # odd length
            if count == target:
                return val
        else:                               # even length
            if count == target1:
                median1 = val
            if count == target2:
                median2 = val
                return (median1 + median2) / 2.0

    # In practice we always return inside the loop, but keep the
    # function signature tidy if something goes wrong.
    raise RuntimeError("Unexpected termination of algorithm")
```
