For a *full* binary tree every internal node has *exactly* two children.  
Let  

* `n` – total number of vertices in the tree  
* `k` – number of *internal* nodes (nodes with two children)  

A full binary tree satisfies

```
       n = 2·k + 1          (1)
```

*Proof.*  
Every internal node contributes 2 children, so the total number of
edges is `2k`.  
Adding one more node (the root) gives `n = 2k + 1`.  
Consequently, `n` must be **odd** and `k = (n‑1)/2`.

The number of full binary trees with *k* internal nodes (or, equivalently,
with `2k+1` vertices) is the **k‑th Catalan number**  

```
        C_k = (1/(k+1)) * binom(2k , k)          (2)
```

So

```
B_n = 0                    if n is even (no full tree can have an even number of vertices)
B_n = C_{(n‑1)/2}          otherwise
```

---

### Recurrence

The Catalan numbers can also be computed iteratively:

```
C_0 = 1
C_{m+1} = Σ_{i=0}^{m} C_i · C_{m-i}
```

or with the closed form (2) using integer arithmetic.

---

### Python implementation

Below is a small, self‑contained function that:

1.  Returns `0` when `n` is even.  
2.  Computes the required Catalan number via the closed‑form binomial
    coefficient (Python’s `math.comb` does big‑integer arithmetic).  

```python
import math
from typing import Union

def full_binary_trees(n: int) -> int:
    """
    Return the number of full binary trees with exactly n vertices.

    Args:
        n: Integer number of vertices (must be non‑negative).

    Returns:
        B_n – number of full binary trees with n vertices.
        (0 if n is even, otherwise the Catalan number C_{(n-1)/2})
    """
    if n < 0:
        raise ValueError("n must be non‑negative")

    # A full binary tree has an odd number of vertices
    if n % 2 == 0:
        return 0

    # Number of internal nodes
    k = (n - 1) // 2

    # Catalan number C_k = binom(2k, k) // (k+1)
    # Using integer arithmetic – no overflow since Python ints are arbitrary precision
    return math.comb(2*k, k) // (k + 1)

# ------------------------------------------------------------------
# Example usage
# ------------------------------------------------------------------
if __name__ == "__main__":
    for n in range(1, 15, 2):
        print(f"B_{n} = {full_binary_trees(n)}")
```

These are the Catalan numbers

### Complexity

* Time: `O(1)` because the closed‑form uses `math.comb` which runs in
  `O(log k)` for integer arithmetic, effectively constant for most
  practical `n`.
* Space: `O(1)` apart from the result.

If you prefer the recurrence (useful when you need many consecutive
Catalan numbers), you can pre‑compute a list of `C_k`:

```python
def catalan_list(limit: int):
    """Return a list C_0 … C_limit."""
    C = [0] * (limit + 1)
    C[0] = 1
    for m in range(1, limit + 1):
        C[m] = sum(C[i] * C[m - 1 - i] for i in range(m))
    return C
```

Then `B_n = 0` if `n` is even else `C[(n-1)//2]`.
