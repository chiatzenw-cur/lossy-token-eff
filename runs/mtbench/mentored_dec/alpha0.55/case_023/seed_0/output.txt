In most textbooks the “lowest” ancestor is called the **lowest common ancestor**; the wording “highest common ancestor” is sometimes used informally because it refers to the root‑most shared ancestor.  
The algorithm below works for any binary tree (complete, sparse, unbalanced, etc.) and runs in \(O(n)\) time where \(n\) is the number of nodes.  

### 1.  Data structure

```python
class Node:
    """A node of a binary tree."""
    __slots__ = ("val", "left", "right")

    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None
```

### 2.  Recursive helper

The helper `lowest_common_ancestor` returns a triple:

| element | meaning |
|---------|---------|
| `found_p` | `True` if `p` is in the subtree rooted here |
| `found_q` | `True` if `q` is in the subtree rooted here |
| `ancestor` | the node that is the LCA, or `None` if the LCA hasn't yet been found |

It does a depth‑first search (DFS) and counts the number of target nodes it has seen so far:

```python
def _lowest_common_ancestor(root, p, q):
    """
    Returns (found_p, found_q, ancestor).

    *invariant* – once ancestor is set, it never changes.
    """
    if root is None:
        return False, False, None

    # Search left subtree
    left_found_p, left_found_q, left_ancestor = _lowest_common_ancestor(root.left, p, q)

    # Search right subtree
    right_found_p, right_found_q, right_ancestor = _lowest_common_ancestor(root.right, p, q)

    # Combine results
    found_p = left_found_p or right_found_p or root is p
    found_q = left_found_q or right_found_q or root is q

    # 1. If we already found a lower ancestor,
    #    it is the LCA.
    if left_ancestor:
        return found_p, found_q, left_ancestor
    if right_ancestor:
        return found_p, found_q, right_ancestor

    # 2. Otherwise, if the root is the split point:
    #    it means one target is in one subtree and the other in the other.
    if (left_found_p and right_found_q) or (left_found_q and right_found_p):
        return found_p, found_q, root

    # 3. If root itself is one of the targets, and the other target is already
    #    in its subtree, the root is the LCA.
    if root is p and (left_found_q or right_found_q):
        return found_p, found_q, root
    if root is q and (left_found_p or right_found_p):
        return found_p, found_q, root

    # 4. No ancestor has been found yet.
    return found_p, found_q, None
```

### 3.  Public interface

```python
def lowest_common_ancestor(root, p, q):
    """
    Return the lowest common ancestor of two nodes p and q.
    If one of the nodes is not present, the function returns None.
    """
    _, _, ancestor = _lowest_common_ancestor(root, p, q)
    return ancestor
```

### 4.  Example usage

```python
def build_example():
    """
    Build a sample tree:

           a
          / \
         b   c
        / \   \
       d   e   f
    """
    a = Node('a')
    b = Node('b'); c = Node('c')
    d = Node('d'); e = Node('e'); f = Node('f')
    a.left, a.right = b, c
    b.left, b.right = d, e
    c.right = f
    return a, d, e, f

root, d, e, f = build_example()

print(lowest_common_ancestor(root, d, e).val)   # -> 'b'
print(lowest_common_ancestor(root, d, f).val)   # -> 'a'
print(lowest_common_ancestor(root, d, d).val)   # -> 'd'
```

### 5.  Why this solves the “highest common ancestor” problem

* **Depth‑first search** ensures every subtree is examined exactly once.
* The algorithm stops propagating a discovered ancestor upward, guaranteeing that the **most recent (deepest)** shared ancestor is returned.
* When we say “highest” in the sense of “closest to the root” it’s trivially the root.  
  The more interesting query is “the deepest common ancestor”, which is what the above code returns.
* If “highest” is meant to be the other way round (i.e., the *lowest* common ancestor), the same function works because it already computes the *lowest* common node.

### 6.  Iterative alternative (no recursion stack)

If you want to avoid the recursion stack, you can implement a parent‑pointer map and work upwards, or use a stack‑based DFS that mimics the recursion.

```python
def lca_iterative(root, p, q):
    # Build parent map
    parent = {root: None}
    stack = [root]
    while stack and (p not in parent or q not in parent):
        node = stack.pop()
        if node.left:
            parent[node.left] = node
            stack.append(node.left)
        if node.right:
            parent[node.right] = node
            stack.append(node.right)

    # Mark all ancestors of p
    ancestors = set()
    while p:
        ancestors.add(p)
        p = parent[p]
    # Walk up from q until we hit an ancestor of p
    while q not in ancestors:
        q = parent[q]
    return q
```

Both implementations are **O(n)** time and `O(h)` space (or `O(n)` if you build a parent map).
