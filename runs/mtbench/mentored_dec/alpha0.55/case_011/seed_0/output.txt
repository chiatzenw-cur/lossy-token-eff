## 2. Bridge Type & Geometry Selection  

| Option | Typical Span Length | Advantages for Seismic Zones |
|--------|---------------------|------------------------------|

| **Box‑Girder (Long‑Span Composite)** | 80–400 m | Careful shear‑wall design allows for strong lateral performance. |
| **Tied‑Arch (Viaduct)** | 200–400 m | Provides stiffness to rail/road superstructures and torsion‑safety. |

## 3. Design Philosophy & Seismic Performance

| Design Concept | Key Features | Code Reference |
|----------------|--------------|----------------|

| **Source‑to‑Site Transmission (b‑factor)** | Allows local amplification (b‑factor) in seismic input |  |
| **Local Damping / Base Isolation** | Use of **energy‑dissipating devices** (e.g., viscous dampers, braces) or **base isolation bearings** on the most vulnerable components (piers, decks) |  |
| **Redundancy & Partitioning** | Each main member has a “backup” path for load‑sharing; nodes isolated via **multi‑zone isolation** |  |
