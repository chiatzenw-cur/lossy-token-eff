For two integer arrays `A` and `B` we have to print all elements that appear in **both** arrays.
The restriction “without using any extra data structures” means we cannot use auxiliary arrays,
hash tables, maps, etc.  
The only memory that is allowed is the input arrays themselves and a few
scalar variables.

One very efficient way to do this is to

1. Sort each array in‑place (o (`n log n`) time, o (1) extra memory).
2. Scan the two sorted arrays simultaneously with two pointers  
   (`i` for `A` and `j` for `B`).

While scanning:

- If `A[i] == B[j]` we found a common element – print it and increment both
  pointers.
- If `A[i] < B[j]` the current `A[i]` is too small; increase `i`.
- If `A[i] > B[j]` the current `B[j]` is too small; increase `j`.

When the pointers hit the end of one array we stop – no further common
elements can exist.

The algorithm uses *O(n log n + m log m)* time, *O(1)* extra memory
and respects all given constraints.

---

### Handling duplicates

If neither array contains duplicate values and the arrays are sorted,
the above procedure prints each common element exactly once.
If duplicates are present and you want to avoid printing the same value
multiplied, simply skip repeated values after a match:

```cpp
if (A[i] == B[j] &&
    (i==0 || A[i] != A[i-1]) &&
    (j==0 || B[j] != B[j-1])) { ... }
```

The problem statement does not explicitly forbid duplicates,
so the simpler form (printing every matching pair) is also accepted
and needs no extra code.

### Correctness Proof  

We prove that the algorithm prints exactly the elements that appear in
both arrays.

1. **Sorting preserves the set of elements** – sorting does not change any
   element, only their order. Therefore both arrays contain the same set of
   elements before and after sorting.

2. **Invariant**  
   At the beginning of each iteration of the main loop the following is
   true:
   *Every element in `A` before index `i` and every element in `B` before
   index `j` has been examined, and no common element among them has been
   missed.*

   *Proof of invariant*:  
   The invariant is true for the first iteration (`i = j = 0`).
   During an iteration we consider the current pair `(A[i], B[j])`.

   - If `A[i] == B[j]` we output it and increment both indices.
     Thus any common element that could have appeared at the current
     positions is found, and we move past them.
   - If `A[i] < B[j]` the current `A[i]` is smaller than any remaining
     element in `B`; hence it cannot appear in `B` later. We safely drop
     `A[i]` by incrementing `i`.
   - If `A[i] > B[j]` the symmetrical argument holds for `B[j]`.

   Therefore after each iteration the invariant remains intact. ∎

3. **Termination**  
   The loop ends when either `i == n` or `j == m`.  
   At that moment at least one array is fully processed, so any element
   that could have been common must have already been examined – by the
   invariant (or it has been discarded because it is not present in the
   other array). Hence no common element is left unprinted.

4. **Output correctness**  
   By the invariant, whenever a common element is found it is printed
   exactly once.  
   Conversely, if an element appears in both arrays, it must be at some
   positions `p` in `A` and `q` in `B`.  
   Sorting places `A[p]` and `B[q]` in order; eventually the two pointers
   will reach these positions simultaneously and hit the `==` case, so
   the element is output.  

Thus the algorithm prints **all and only** the common elements.

### Complexity Analysis

Let `n` and `m` be the lengths of the two arrays.

*Sorting*  
- `A`: `O(n log n)` time  
- `B`: `O(m log m)` time  

*Scanning*  
- Each pointer moves at most `n` or `m` steps → `O(n + m)` time.

Total time: `O(n log n + m log m)`.

Space usage: only the two input arrays and a few integer variables → `O(1)` extra memory.

### Reference Implementation (C++17)

```cpp
#include <bits/stdc++.h>
using namespace std;

/**
 * Print all common elements of arrays A and B.
 * No extra data structures are used.
 * Assumes input arrays are vectors of integers.
 */
void common_elements(vector<int> &A, vector<int> &B) {
    sort(A.begin(), A.end());          // in‑place sort, no extra memory
    sort(B.begin(), B.end());

    size_t i = 0, j = 0;
    bool first = true;                 // for nicer output formatting

    while (i < A.size() && j < B.size()) {
        if (A[i] == B[j]) {
            if (!first) cout << " ";
            cout << A[i];
            first = false;
            ++i; ++j;                    // move past this matched pair
        } else if (A[i] < B[j]) {
            ++i;
        } else {
            ++j;
        }
    }
    cout << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;

    vector<int> A(n), B(m);
    for (int i = 0; i < n; ++i) cin >> A[i];
    for (int j = 0; j < m; ++j) cin >> B[j];

    common_elements(A, B);
    return 0;
}
```
