Machine learning (ML) is a sub‑field of artificial intelligence in which algorithms learn patterns from data and use those patterns to make predictions or decisions without being explicitly programmed to perform the specific task.  
The core idea is that **data can be treated as a signal** and the algorithm learns how to interpret that signal to produce useful outputs.

Key characteristics:
| Feature | What it means | ML relevance |
|---------|--------------|--------------|
| **Data‑driven** | The model learns from examples rather than hand‑coded rules | ✔️ |
| **Model generalization** | The ability to perform well on unseen data | ✔️ |
| **Iterative improvement** | Models are retrained with new data or feedback | ✔️ |
| **Statistical inference** | Uses probability and statistics to estimate patterns | ✔️ |

## 2. Main Paradigms of Machine Learning

| Paradigm | Typical Goal | How It Works | Key assumptions | Typical algorithms |
|---------|--------------|--------------|-----------------|-------------------|
| **Supervised Learning** | Predict a label or value for a new input | - Train on a labeled dataset (input → target). <br>- Minimize loss between predictions and true labels. | - The mapping from input to target is reasonably stable. <br>- Labels are available and correct. | - Classification: SVM, Random Forest, CNN, RNN <br>- Regression: Linear Regression, Gradient Boosting, Neural Net |
| **Unsupervised Learning** | Discover hidden structure or patterns | - Train on unlabeled data. <br>- Optimize an objective that doesn’t require a target (e.g., reconstruction error, similarity). | - No explicit target variable; quality judged by internal metrics or downstream tasks. | - Clustering: k‑means, DBSCAN, Hierarchical clustering. <br>- Embedding: PCA, t‑SNE, Autoencoders. |
| **Reinforcement Learning (RL)** | Learn a policy to maximize cumulative reward in an environment | - The agent selects actions, receives rewards and observations. <br>- Updates a policy/value function based on the reward signal. | - Reward signal must be defined (score, profit, safety). <br>- Trade‑off between exploration and exploitation. | - Value‑based: Q‑learning, DQN <br>- Policy‑gradient: REINFORCE, PPO <br>- Actor‑Critic: A3C, DDPG |

## 3. Supervised Learning – Detailed

### 3.1 Problem Formulation
- **Dataset**: \(\{(x_i, y_i)\}_{i=1}^N\) where \(x_i\in \mathbb{R}^p\) (features) and \(y_i\) is a label (classification) or a continuous value (regression).
- **Model**: \(f_\theta(x)\) with parameters \(\theta\) that maps features to predictions.
- **Loss**: \(L(\theta) = \frac{1}{N}\sum_i \ell(f_\theta(x_i), y_i)\) (cross‑entropy for classification, MSE for regression).
- **Optimization**: Minimize \(L(\theta)\) via gradient descent or variants.

### 3.2 Real‑World Example: Email Spam Detection

| Step | What Happens |
|------|--------------|
| 1. Data | Large set of emails labeled as *spam* or *ham* (non‑spam) |
| 2. Features | Bag‑of‑words, TF‑IDF, n‑gram counts, metadata (sender, subject) |
| 3. Model | Multinomial Naïve Bayes or a deep neural network (CNN over the text) |
| 4. Training | Optimize cross‑entropy loss on labeled data |
| 5. Deployment | Classify any new email as spam/ham in real time. |

**Metrics**: Accuracy, Precision/Recall, F1‑score.

## 4. Unsupervised Learning – Detailed

### 4.1 Problem Formulation
- **Dataset**: \(\{x_i\}_{i=1}^N\) without targets.
- **Objective**: Find a mapping \(f_\theta(x)\) that captures structure (e.g., clustering, dimensionality reduction).
- **Widely used loss**: Reconstruction loss in Autoencoders, within‑cluster variance in k‑means.

### 4.2 Real‑World Example: Customer Segmentation in Retail

| Step | What Happens |
|------|--------------|
| 1. Data | Transaction logs (products purchased, amount, time). |
| 2. Feature Engineering | Frequency of purchase, basket size, recency, monetary score (RFM). |
| 3. Model | k‑means clustering to partition customers into distinct segments. |
| 4. Insights | “High‑value, frequent shoppers” vs. “Bargain hunters” vs. “One‑time browsers.” |
| 5. Action | Targeted promotions, loyalty programs, inventory planning. |

**Metrics**: Inertia, silhouette score, cluster stability.

## 5. Reinforcement Learning – Detailed

### 5.1 Problem Formulation
- **Agent** interacts with an **environment** that gives:
  - Observation \(s_t\)
  - Action \(a_t\)
  - Reward \(r_t\)
  - Next state \(s_{t+1}\)
- **Objective**: Find a policy \(\pi(a|s)\) that maximizes expected cumulative reward \(\mathbb{E}[\sum_{t=0}^T \gamma^t r_t]\).

### 5.2 Real‑World Example: Autonomous Driving

| Step | What Happens |
|------|--------------|
| 1. State | Current car’s sensor suite (camera, lidar, GPS, steering angle). |
| 2. Action | Steering wheel angle, throttle, brake. |
| 3. Reward | Positive reward for staying within the lane, maintaining speed, no collisions; negative reward for any safety violation. |
| 4. Agent | Deep RL model (e.g., Actor‑Critic with CNNs). |
| 5. Learning | Drives in a simulation (or real‑world with safety constraints) updating policy as it receives reward signals. |

**Key Challenges**: Safety, exploration vs. exploitation, simulation‑to‑real transfer.

## 6. Comparative Summary

| Feature | Supervised | Unsupervised | Reinforcement |
|---------|------------|--------------|---------------|
| **Data Required** | Labeled pairs \((x, y)\) | Unlabeled samples | Interaction logs \((s_t, a_t, r_t, s_{t+1})\) |
| **Typical Goal** | Predict labels / numeric values | Discover clusters / representations | Maximize cumulative reward |
| **Learned Signal** | Ground truth labels | Internal structure / reconstruction | Reward feedback |
| **Use Cases** | Classification, regression, segmentation | Market basket analysis, anomaly detection, dimensionality reduction | Robotics, game playing, automated trading |

---

## 7. Practical Take‑aways

- Choose **supervised** when you have a clear, well‑labelled target you want to predict.  
- Choose **unsupervised** when you have data but no labels, and you want to discover hidden structure.  
- Choose **reinforcement** when you have an *agent* that must act over time and you can define a reward that captures the desired outcome.

Keep in mind that **hybrid approaches** (e.g., self‑supervised pre‑training followed by fine‑tuning, or using RL to learn a policy that exploits unsupervised feature extraction) are increasingly common and powerful.
