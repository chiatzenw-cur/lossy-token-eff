\[
S=\{1,4\}.
\]

For each number \(n\) of tokens we can say whether the player whose turn it is
(“the current player”) can force a win.  
Let  

* \(W(n)\) = “winning position” – the current player can force a win,
* \(L(n)\) = “losing position” – the current player will lose if the opponent plays
optimally.

--------------------------------------------------------------------
### 1.  Recurrence for the positions

The usual rule for impartial subtraction games is

\[
\begin{cases}
L(n) &\text{iff all moves from } n \text{ go to a } W\text{ position,}\\[4pt]
W(n) &\text{iff at least one move from } n \text{ goes to a } L\text{ position.}
\end{cases}
\]

With \(S=\{1,4\}\) the only possible moves are to \(n-1\) or \(n-4\) (if \(n\ge4\)).

--------------------------------------------------------------------
### 2.  Compute the first few positions

| \(n\) | possible moves | result |
|-------|----------------|--------|
| 0 | none | \(L\) (no move) |
| 1 | \(n-1=0\) | \(W\) (move to \(L\)) |
| 2 | \(n-1=1\) | \(L\) (both moves, only \(1\), go to \(W\)) |
| 3 | \(n-1=2\) | \(W\) (move to \(L\)) |
| 4 | \(n-1=3,\;n-4=0\) | \(W\) (move \(n-4\) to \(L\)) |
| 5 | \(n-1=4,\;n-4=1\) | \(L\) (both moves to \(W\)) |
| 6 | \(n-1=5,\;n-4=2\) | \(W\) (move to \(L\)) |
| 7 | \(n-1=6,\;n-4=3\) | \(L\) (both to \(W\)) |
| 8 | \(n-1=7,\;n-4=4\) | \(W\) |
| 9 | \(n-1=8,\;n-4=5\) | \(W\) |
|10 | \(n-1=9,\;n-4=6\) | \(L\) |
|11 | \(n-1=10,\;n-4=7\) | \(W\) |

### 3.  Observe the pattern

The losing positions up to 15 are  

\[
0,\;2,\;5,\;7,\;10,\;12,\;15,\dots
\]

Look at the differences:

\[

Hence they repeat every \(5\) numbers.

In fact, for every \(n\ge0\)

\[
L(n)\quad\Longleftrightarrow\quad n\bmod 5\in\{0,2\}.
\]

(This can be proved inductively from the recurrence or by checking the first five

### 4.  Bob’s winning strategy

Alice moves first.  
Bob will win **iff** the initial stack size \(n\) is a losing position for the
player to move (Alice).  
Thus we need the number of positive integers \(n\le 2024\) with

\[
n\bmod 5\in\{0,2\}.

### 5.  Counting such integers

**Numbers congruent to \(0\pmod5\):**  
\[

**Numbers congruent to \(2\pmod5\):**
