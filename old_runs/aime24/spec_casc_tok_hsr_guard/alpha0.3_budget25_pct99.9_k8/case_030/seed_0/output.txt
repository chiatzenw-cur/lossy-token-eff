### 1.  What a maximal placement looks like

* If a row contains a chip, all chips in that row must have the same colour.  
  Therefore every row that contains a chip has a well‑defined colour \(R_i\in\{w,b\}\).

* The same holds for columns: every column that contains a chip has a colour
  \(C_j\in\{w,b\}\).

* For a cell \((i,j)\) which contains a chip, the colour of the chip must be
  simultaneously the colour of row \(i\) and of column \(j\); hence

\[
\text{if }(i,j)\text{ is occupied then }R_i=C_j .
\]

* Suppose an empty cell \((i,j)\) has \(R_i=C_j\).  
  Adding a chip in that cell would keep the colours of the row and the column
  unchanged, so the placement would still satisfy the two rules – contradicting
  the *maximal* condition.  
  Therefore **every empty cell must satisfy \(R_i\neq C_j\)**.

Thus the set of occupied cells is exactly the set of pairs \((i,j)\) with
\(R_i=C_j\).  
Consequently each row that contains a chip must have at least one column of the
same colour, and each column that contains a chip must have at least one row
of the same colour.

### 4.  The two homogeneous colourings

If all rows are white, all columns must also be white – otherwise a column
would have no chips and would violate the “at least one chip per column”
condition.  
Similarly, all rows black implies all columns black.

So there are two additional maximal configurations:

* all 25 cells are white,
* all 25 cells are black.
