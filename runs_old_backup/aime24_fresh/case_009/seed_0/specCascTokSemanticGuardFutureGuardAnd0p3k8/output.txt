\[
\text{P-position} \iff \text{the player to move loses with perfect play}
\]

and a P‑position is precisely the set of positions from which the second player can force a win *regardless of how the first player plays*.  
Thus we need the number of \(n\le 2024\) that are P‑positions for the subtraction set \(\{1,4\}\).

--------------------------------------------------------------------
### 1.  Determine the P‑positions

Let \(G(n)\) be the Grundy number of a heap of size \(n\).  
For \(n\ge 1\),

\[
G(n)=\operatorname{mex}\{\,G(n-1),\,G(n-4)\,\},
\]
with \(G(0)=0\).

Computing the first few values:

The Grundy number is \(0\) precisely when  
\(n\equiv 0\pmod{5}\) or \(n\equiv 2\pmod{5}\).

So the **P‑positions** (heap sizes that are losing for the player to move) are

\[
\{\,5k,\,5k+2 \mid k\ge 1\}\ \cup\ \{\,5k+2 \mid k\ge 0\}
\]

i.e. all positive integers congruent to \(0\) or \(2\) modulo \(5\).

### 2.  Count such \(n\) up to \(2024\)

\[
5,10,\dots,2020 \quad\Longrightarrow\quad \Big\lfloor\frac{2024}{5}\Big\rfloor = 404.
\]

Numbers \(\le 2024\) with remainder \(2\) modulo \(5\):

\[
2,7,12,\dots,2022 \quad\Longrightarrow\quad \Big\lfloor\frac{2024-2}{5}\Big\rfloor+1 = 405.
\]

Adding them gives

404 + 405 = 809.
