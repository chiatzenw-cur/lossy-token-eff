Straightforward but careful with edge cases.

Sample answer:
```
def kth_smallest_element(list1, list2, k):
    m, n = len(list1), len(list2)
    i, j = 0, 0
    while i < m and j < n:
        if list1[i] < list2[j]:
            k -= 1
            if k == 0:
                return list1[i]
            i += 1
        else:
            k -= 1
            if k == 0:
                return list2[j]
            j += 1
    while i < m:
        k -= 1
        if k == 0:
            return list1[i]
        i += 1
    while j < n:
        k -= 1
        if k == 0:
            return list2[j]
        j += 1
    return None
```
