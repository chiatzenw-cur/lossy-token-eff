---

### 1.  Determine the \(P\)-positions  

* \(n=0\) : no move → **P**.  
* \(n=1\) : can remove 1 → \(0\) (**P**) → **N**.  
* \(n=2\) : only move to \(1\) (**N**) → **P**.  
* \(n=3\) : move to \(2\) (**P**) → **N**.  
* \(n=4\) : move to \(3\) (**N**) or \(0\) (**P**) → **N**.  
* \(n=5\) : move to \(4\) (**N**) or \(1\) (**N**) → **P**.  

Continuing in this way gives the sequence of \(P\)-positions

\[
0,\; 2,\; 5,\; 7,\; 10,\; 12,\; 15,\; 17,\; 20,\; 22,\; 25,\; 27,\; 30,\dots
\]

The differences alternate \(2,3,2,3,\dots\).  
Hence the pattern repeats every 5 numbers:

\[
n \text{ is a } P\text{-position } \iff n \equiv 0 \pmod{5}\ \text{or}\ n \equiv 2 \pmod{5}.
\]

---

### 2.  Winning condition for Bob  

The game starts with a stack of \(n\) tokens and Alice moves first.  
Bob will win iff the initial position is a \(P\)-position, because then the player to move (Alice) is in a losing position.

So Bob has a winning strategy iff  

\[
n \equiv 0 \pmod{5}\quad\text{or}\quad n \equiv 2 \pmod{5}.
\]

---

### 3.  Count such \(n\) with \(1\le n\le 2024\)

* Numbers \(\le 2024\) that are \(0 \pmod{5}\):  
  \(\displaystyle \left\lfloor\frac{2024}{5}\right\rfloor = 404\).

* Numbers \(\le 2024\) that are \(2 \pmod{5}\):
