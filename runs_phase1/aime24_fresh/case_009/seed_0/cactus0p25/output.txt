---

### 1.  Winning–losing table

Let  

* \(L\)  = a position from which **the player to move will lose** (losing position);
* \(W\)  = a position from which **the player to move will win** (winning position).

The terminal state is empty stack – all moves are impossible and the player to the move loses.  
By definition  

\[
L(0)=\text{losing state} .
\]

For any \(n\ge 1\)

\[
\begin{cases}
W(n)&\text{if there exists } a \in \{1,4\} \text{ with } 0\le n-a \le n\text{ and }L(n-a)=\text{loss}\\
L(n)&\text{if every move }a\in\{1,4\}\text{ satisfies }W(n-a)=\text{win}.
\end{cases}
\]

---

### 2.  Compute a few values

| \(n\)  | \(L(n)\) | reasoning |
|-------|----------|-----------|
| 0 |  \(L\) | terminal |
| 1 |  \(W\) | remove 1 → \(0\) (losing) |
| 2 |  \(L\) | remove 1 → \(1\) (winning) |
| 3 |  \(W\) | remove 1 → \(2\) (losing) |
| 4 |  \(W\) | remove 4 → \(0\) (losing) |
| 5 |  \(L\) | both moves produce \(4\) or \(1\) (winning) |
| 6 |  \(W\) | move to 5 (losing) |
| … |  | … |

The pattern that emerges after the first five values is:

\[
\boxed{\,L \text{ (ranks: }0,2,5,7,10,12,\dots) } .
\]

That is, if \(n\equiv 0\) or \(2\pmod 5\) then the position is losing.

---

### 3.  Proof of the pattern

Assume that the pattern holds for all positions less than \(n\).  
A consequence of the recurrence is

* If \(n\equiv 0\pmod 5\):  
  \(n-1\equiv 4\pmod 5\) and \(n-4\equiv 1\pmod 5\).  
  Both are winning.  
  Hence there is no right move for the player to move → \(n\) is losing.

* If \(n\equiv 2\pmod 5\):  
  \(n-1\equiv 1\pmod 5\) and \(n-4\equiv 3\pmod 5\).  
  Both are winning, so \(n\) is losing.

The other two residues \(1,3,4\) always have a move to a losing position, hence are winning.

By induction the pattern is valid for all \(n\ge 0,\) thus every remaining \(n\) is a winning position for the player to move.

---

### 4.  Bob’s advantage

- Alice moves first.
- Therefore Bob will win *iff* the initial position is **to the opposition solvable** only for the player to move – i.e. Bob has a forced win iff the initial position is a losing position for the player to move (Alice).

Hence the measurable set of “Bob‑winning” initial values is

\[
n\equiv 0\text{ or }2\pmod 5 .
\]

---

### 5.  Counting \(n\le 2024\)

Positive integers \(n\le 2024\) with \(n\equiv 0\pmod 5\):

\[
5,\;10,\;15,\dots ,2020 .
\]

There are \( \displaystyle \left\lfloor \frac{2024}{5}\right\rfloor = 404\) such numbers.

Positive integers \(n\le 2024\) with \(n\equiv 2\pmod 5\):

\[
2,\;7,\;12,\dots ,2022 .
\]

There are \( \displaystyle \left\lfloor \frac{2024-2}{5}\right\rfloor + 1 = 404+1 = 405\) such numbers.

Adding the two classes:

\[
404 + 405 = 809 .
\]

---

\[
\boxed{809}
\]

Thus there are **809** positive integers \(n\le 2024\) that allow Bob to guarantee a win irrespective of Alice's play.
