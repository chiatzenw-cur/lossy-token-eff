--------------------------------------------------------------------

### 1.  What does “change direction exactly four times’’ mean?

A change of direction occurs when a \(R\) is followed by a \(U\) or
a \(U\) is followed by a \(R\).  
If the path changes direction \(4\) times, the sequence of moves is
broken into

\[
\underbrace{[\text{run}\ 1]}_{\text{same direction}}
\underbrace{[\text{run}\ 2]}_{\text{different}}
\underbrace{[\text{run}\ 3]}_{\text{same as run 1}}
\underbrace{[\text{run}\ 4]}_{\text{different}}
\underbrace{[\text{run}\ 5]}_{\text{same as run 1}}
\]

so there are \(5\) consecutive runs of identical directions.
Each run must contain at least one step.

--------------------------------------------------------------------

### 2.  Splitting the \(R\)’s and \(U\)’s among the runs

Let \(r_1,r_2,r_3,r_4,r_5\) be the lengths of the five runs  
(\(r_i\ge 1\)).  
If the first run is a right run, the runs 1,3,5 are right moves
and runs 2,4 are up moves; if the first run is an up run the
roles are swapped.  
In either case the total numbers of rights and ups are

\[
r_1+r_3+r_5 = 8 , \qquad r_2+r_4 = 8 .
\]

The second equality follows automatically from  
\(r_1+r_2+r_3+r_4+r_5 = 16\).

Hence we need the number of positive integer solutions of

\[
r_1+r_3+r_5 = 8, \qquad r_2+r_4 = 8 .
\]

--------------------------------------------------------------------

### 3.  Counting the solutions

* For the three right runs \(r_1,r_3,r_5\) we need
  the number of positive solutions of \(x_1+x_2+x_3 = 8\):

\[
\binom{8-1}{3-1}= \binom{7}{2}=21 .
\]

* For the two up runs \(r_2,r_4\) we need
  the number of positive solutions of \(y_1+y_2 = 8\):

\[
\binom{8-1}{2-1}= \binom{7}{1}=7 .
\]

Thus there are \(21\times 7 = 147\) ways to assign the run lengths.

--------------------------------------------------------------------

### 4.  Beginning direction

For each run-length assignment we can start the path with a right
move or with an up move.  
Both give a valid path because the sums \(r_1+r_3+r_5=8\) and
\(r_2+r_4=8\) are satisfied in either orientation.

Hence each set of run lengths yields **two** distinct paths.
