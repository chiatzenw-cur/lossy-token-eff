### 1.  Pattern of directions

If a path changes direction exactly \(4\) times, then it has \(5\) straight segments:

\[
\underbrace{R}_{\text{segment 1}}\,
\underbrace{U}_{\text{segment 2}}\,
\underbrace{R}_{\text{segment 3}}\,
\underbrace{U}_{\text{segment 4}}\,
\underbrace{R}_{\text{segment 5}}
\]

or the opposite starting with \(U\):
\[
U\,R\,U\,R\,U .
\]

Thus there are two possible direction patterns.

---

### 2.  Counting the segment lengths

For the pattern \(R\,U\,R\,U\,R\):

* The three \(R\)-segments contain a total of 8 steps:  
  \(x_1+x_3+x_5 = 8\) with each \(x_i\ge 1\).

  The number of positive integer solutions is  
  \(\displaystyle \binom{8-1}{3-1}=\binom{7}{2}=21\).

* The two \(U\)-segments contain a total of 8 steps:  
  \(y_2+y_4 = 8\) with each \(y_i\ge 1\).

  The number of solutions is  
  \(\displaystyle \binom{8-1}{2-1}=\binom{7}{1}=7\).

Hence the number of paths with this pattern is  
\(21 \times 7 = 147\).

For the pattern \(U\,R\,U\,R\,U\) the counting is symmetric:  
\(U\)-segments \(=\) 3 parts, \(R\)-segments \(=\) 2 parts, giving again
