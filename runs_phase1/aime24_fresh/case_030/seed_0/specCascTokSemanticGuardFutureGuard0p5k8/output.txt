### 1.  Consequences of the colour conditions

* If a row (or a column) has at least one chip, all its chips have the
  same colour – **row–col colour** is a property of the *vertex*.
* If a row and a column are connected by a chip, their colours must be
  equal.  
  Hence all vertices that belong to the same connected component of the
  graph must have the same colour.

So each connected component of the graph is a complete bipartite
subgraph \(K_{p,q}\) (otherwise a missing edge could be added without
violating the colour conditions).

--------------------------------------------------------------------
### 2.  Maximality condition

The phrasing “any additional chip would violate one or more of the
previous two conditions’’ means that the graph is *maximal*:
every missing edge would break the colour rule.

Consider a missing edge \((r,c)\) where \(r\in R\) and \(c\in C\).

* If either \(r\) or \(c\) is isolated (degree \(0\)), we could add the
  edge by giving the isolated vertex the colour of the other one.
  Therefore **no vertex may be isolated**; every row and every column
  must contain at least one chip.

* If \(r\) and \(c\) belong to two different components, adding the edge
  would force the two components to have the same colour (otherwise the
  added edge would contradict the colour rule).  
  Thus **no two components may share the same colour** – otherwise a
  missing edge between them would be allowed.

Consequently the graph can contain

* either **one** component, or  
* exactly **two** components, one white and one black.

### 3.  Counting the configurations

#### 3.1 One component

#### 3.2 Two components

Let the first component be white.  
Let  

* \(R_W\subseteq R\) be the set of rows that contain white chips,
* \(C_W\subseteq C\) be the set of columns that contain white chips.

The white component is the complete bipartite graph
