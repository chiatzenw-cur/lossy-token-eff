So set C has size 900, essentially the universal set. So every person owns candy hearts. Thus anyone who owns any subset must include them in candy hearts. So the question about owning all four means owning all the other types too.

We have counts: |D|=195, |G|=367, |S|=562. |C|=900.

We know number of residents who own exactly two of these things: 437. Number of residents who own exactly three: 234. We need number who own all four: x.

Let’s denote:

Let a = number of people who own exactly one of the four things.
Let b = number of people who own exactly two of the four things = 437.
Let c = number who own exactly three = 234.
Let d = number who own all four = what we want.

We also know total number of residents: |U| = 900 = a + b + c + d.

Also from inclusion-exclusion, we can compute the sum of cardinalities of the sets: |D|+|G|+|S|+|C| = 195+367+562+900 = 2024.

But the sum of cardinalities is also equal to sum over all elements of the number of sets they belong to. i.e., each person contributes 1 for each set they belong to. So total contributions = a*1 + b*2 + c*3 + d*4.

Thus: a + 2b + 3c + 4d = 2024.

We know b=437, c=234. Unknowns: a, d.

Also we have 900 = a + b + c + d → a + d = 900 - b - c = 900 - 437 - 234 = 900 - 671 = 229.

Thus a + d = 229.

Now we also have equation for sum of memberships: a + 2b + 3c + 4d = 2024.

Plug b and c: a + 2*437 + 3*234 + 4d = 2024.

Compute: 2*437 = 874. 3*234 = 702. Sum 874+702 = 1576. So a + 1576 + 4d = 2024 → a + 4d = 2024 - 1576 = 448.

Thus a + 4d = 448.

We also have a + d = 229.

Subtract second from first: (a + 4d) - (a + d) = 448 - 229 → 3d = 219 → d = 219 / 3 = 73.

Thus x=73.

Check: a = 229 - d = 229 - 73 = 156.

Thus answer 73.

* \(D\) be the set of residents who own a diamond ring  
* \(G\) the set who own a set of golf clubs  
* \(S\) the set who own a garden spade  
* \(C\) the set who own a bag of candy hearts  

Every resident owns a bag of candy hearts, so \(|C|=900\).

---

### 1.  Use the given counts

\[
|D|=195,\qquad |G|=367,\qquad |S|=562,\qquad |C|=900
\]

Number of residents who own exactly two of the items: \(b=437\).  
Number who own exactly three of the items: \(c=234\).  
Let \(d\) be the number who own all four items – this is what we want.  
Let \(a\) be the number who own exactly one item.

The total number of residents is

\[
a+b+c+d = 900 \quad\Longrightarrow\quad a+d = 900-437-234 = 229
\tag{1}
\]

---

### 2.  Count set‑membership total

Each resident contributes to the left–hand side of the inclusion–exclusion principle the number of sets they belong to.  
Thus

\[
a(1)+b(2)+c(3)+d(4)=|D|+|G|+|S|+|C| \\
\]

Compute the right side:

\[
|D|+|G|+|S|+|C| = 195+367+562+900 = 2024
\]

Hence

\[
a+2b+3c+4d = 2024
\]

Substitute \(b=437,\; c=234\):

\[
a+2(437)+3(234)+4d = 2024
\]
\[
a+874+702+4d = 2024
\]
\[
a+4d = 448
\tag{2}
\]

---

### 3.  Solve for \(d\)

From (1) \(a = 229-d\).

Insert into (2):

\[
(229-d)+4d = 448
\]
\[
229 + 3d = 448
\]
\[
3d = 219 \quad\Longrightarrow\quad d = 73
\]
