### 1.  Existence of a solution modulo \(p\)

If a solution exists mod \(p^{2}\), it certainly exists mod \(p\).  
Hence we need a prime \(p\) for which  

\[
n^{4}\equiv-1 \pmod p
\]

holds.  
For a prime \(p>2\) this requires that \(-1\) be a quartic residue mod \(p\).
A necessary condition is that \(-1\) is a quadratic residue, so \(p\equiv1\pmod4\).

Checking the primes \(\equiv1\pmod4\):

* \(p=5\): The fourth powers mod \(5\) are only \(\{0,1\}\).  \(-1\equiv4\) is not a fourth power → no solution.  
* \(p=13\): Fourth powers mod \(13\) are \(\{0,1,3,9\}\); \(-1\equiv12\) is not among them.  
* \(p=17\): Fourth powers mod \(17\) are \(\{0,1,4,13,16\}\).  \(-1\equiv16\) is present, for instance \(2^{4}=16\).

Thus \(p=17\) is the least prime with a solution modulo \(p\).

---

### 2.  Lifting the solution to \(p^{2}=289\)

Let \(a\) be a solution of \(a^{4}\equiv-1\pmod{17}\).
The solutions mod \(17\) are  

\[
a\equiv 2,\;8,\;9,\;15 \pmod{17}.
\]

Because \(p\neq2\), the derivative \(f'(x)=4x^{3}\) is not \(0\) mod \(p\) at any of these points, so each solution lifts uniquely to a solution modulo \(17^{2}\) (Hensel’s Lemma).

For a lift \(n=a+17k,\; 0\le k<17\):

\[
n^{4}\equiv a^{4}+4a^{3}\cdot 17k \pmod{289},
\]

hence \(n^{4}+1\equiv0\pmod{289}\) iff

\[
\bigl(\frac{a^{4}+1}{17}\bigr)+4a^{3}k\equiv0\pmod{17}.
\]

Solving for \(k\) for each choice of \(a\):

| \(a\) | \(a^{4}+1\) | \(\frac{a^{4}+1}{17}\) | \(4a^{3}\pmod{17}\) | Solution \(k\) | \(n=a+17k\) |
